# 朝の自分に決めさせない — Product Spec

## Exact use moment
明日の朝は起きたいと分かっているのに、アラーム後の「あと5分」「今日はいいか」で布団に残りやすい人が、前夜に30秒で朝の行動順を固定し、翌朝は判断せず1個ずつ実行してベッドの外へ出るために使う。

## Central benefit
朝の起床直後にする判断を減らし、前夜に決めた行動列をそのまま再生して離床まで進みやすくする。

## Problem / design rationale
このアプリは「朝の自分は弱い」といった心理学的断定をしない。設計上の前提はもっと単純で、アラーム直後に「起きるか」「何から始めるか」「今日は例外にするか」という判断を増やさず、元気な時間帯に決めた具体的な行動を翌朝に再生する方が、少なくとも操作上は迷いを減らせるというもの。

標準の目覚まし機能そのものを置き換えるアプリではない。スマホ標準のアラームが鳴った後に開き、最初の数分をオートパイロット化する。

## Core interaction
夜モードでは、起床時刻と5つの具体行動を確認し、「朝の編集権をロック」する。朝モードでは選択肢を出さず、画面中央に今やる1行動だけを大きく表示し、実行したら「やった」を押して次へ進む。途中でやめる場合だけ「命令を破る」を選び、予定との差分を記録する。

この操作がターゲット行動と一致する理由は、ユーザーに朝の最適解を考えさせるのではなく、「前夜に決める → 朝は順番どおり実行する」という型そのものを体験させるから。

## First 10 seconds
初回は「目覚ましの次に開く。朝は考えない。」という1文、起床時刻、5ステップのタイムライン、そして「朝の編集権をロック」ボタンだけを主役にする。長い説明を読まなくても、今夜設定して明朝実行するアプリだと分かる。

## Success condition
朝モードで5ステップを完了し、予定時刻から実際の完了までの差分が記録されること。翌日以降は前回との差が表示され、ベッド滞在の延長時間が縮んだかを確認できる。

## Uniqueness
既存の「まだ寝てていい。」は朝その場で心理的な段差を小さくして「今できそうな1個」を選ぶ体験、既存の「睡眠を削らず、朝時間をつくる7日間」は夜の生活リズムを7日で整える体験。本アプリは、前夜に朝の行動列をロックし、翌朝の選択肢を消して同じ列を再生する「意思決定の前倒し」に特化しているため代替できない。

## Repeat-use strategy
毎晩同じ計画を再利用でき、翌朝の予定との差分を履歴化する。前回より1分でも短くなれば変化として表示する。習慣が定着したらアプリを開かなくても同じ順番で動けることを最終的な成功とみなす。

## Title rationale
- Main user benefit/motive: 明日の朝に起きたい／朝の迷いを減らしたい
- Why this title is direct and specific: 「朝」「自分」「決めさせない」で、朝に意思決定をさせない中心体験をそのまま表している
- How it matches the actual app: 夜にロックし、朝は編集や選択をせず実行だけする
- Market/uniqueness checks actually performed (if any): 今回は市場調査によるタイトル発見ではなく、ユーザーとの企画会話から中心体験を直接表す仮タイトルとして採用。外部の商標・Amazon検索結果は未確認のため独自性は主張しない
