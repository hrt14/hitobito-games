# RECOVERY MAP — Product Spec

## Exact use moment
疲れているのに「考えるのを止めるべきか、身体を休めるべきか」が分からず、そのまま無理を続けそうな人が、その場で約90秒使う。終了時には診断名ではなく、いま強く出ている疲れのサインを「頭・気持ち寄り」「身体寄り」「両方」に整理し、次の10分にやる低リスクな回復行動を1つ決める。

## Central benefit
疲れの正体を決めつけず、いまの自分に合う休み方を1つ選べる状態にする。

## Problem / design rationale
疲労は単一の原因を示すものではなく、睡眠不足、身体活動、ストレス、気分、生活習慣、病気や治療など多くの要因で起こり得る。MedlinePlusは疲労を「疲れ・消耗・エネルギー不足の感覚」とし、身体活動、感情的ストレス、睡眠不足などへの通常の反応である一方、身体的・精神的な問題のサインにもなり得るとしている。NHSも疲労には睡眠、生活習慣、ストレス、病気、治療など複数の原因があり、自己診断せず、長引く・生活に影響する場合は医療相談を勧めている。

このためアプリは「心の疲れ／身体の疲れ」を医学的に判定しない。ユーザーが今感じているサインの強さを2つのメーターへ可視化し、偏りが小さい場合は「両方」と明示する。結果はあくまで休み方を選ぶためのチェックインとして扱う。

Sources:
- MedlinePlus, Fatigue: https://medlineplus.gov/fatigue.html
- NHS, Tiredness and fatigue: https://www.nhs.uk/symptoms/tiredness-and-fatigue/

## Core interaction
「頭・気持ち」と「身体」に分けて並んだ8個の短いサインカードから、今当てはまるものをタップする。1回で「当てはまる」、2回で「強く当てはまる」、3回で解除できる。タップするたびに2つのメーターがその場で伸びる。

正解クイズではなく、本人の今の感覚を強さごとに外へ出すチェックインである。最後に2つのメーターの分布から「頭・気持ち寄り」「身体寄り」「両方」を示し、次の10分の回復行動を1つだけ選ぶ。操作そのものが「曖昧な疲れを分解して見る」行動になる。

## First 10 seconds
最初の画面に「疲れを分けて、休み方を決める」「約90秒」「診断ではない」「両方でもOK」を短く表示し、主要CTAは「今の疲れを分ける」の1つ。開始後はサインカードをタップすればメーターが伸びるため、長い説明を読ませない。

## Success condition
当てはまるサインを選んだ後に「今は身体寄り／頭・気持ち寄り／両方」と分布が見え、ユーザーが次の10分に実行する回復行動を1つ選択して「これをやる」で確定できること。

## Uniqueness
既存の「疲れたの正体」が質問から疲れの負荷源を絞って言語化する入口なのに対し、このアプリは原因推定をせず、今感じているサインを頭・気持ち／身体の2メーターへ直接可視化して、その場の休み方を1つ決めることに特化する。

## Repeat-use strategy
同じ疲れでも日によって分布が変わるため、疲れ方が分からなくなった瞬間に再利用できる。直近3回の「頭・気持ち／身体／両方」と選んだ回復行動だけを端末内に保存し、傾向を短く見返せる。活動量を競うポイントや連続日数は使わない。

## Title rationale
- Main user benefit/motive: 楽になる / 休み方を間違えない / 状態を理解する。
- Why this title is direct and specific: 「RECOVERY」と「MAP」で、回復のために現在地を整理する役割を短く表す。
- How it matches the actual app: 疲れのサインを2つのメーターへ可視化し、現在の分布から次の回復行動を決める。
- Market/uniqueness checks actually performed (if any): 市場での名称独自性は断定しない。アプリ内では日本語副題「疲れを分けて、休み方を決める」を併記する。
