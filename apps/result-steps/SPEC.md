# 結果が出るまで、あと○歩 — Product Spec

## Exact use moment
努力を続けているのに目に見える結果がまだ出ず、「このままやって意味があるのか」「やめた方がいいのか」と感じた人が開き、見えない積み上げと今日できる最小の一手を確認して「今日は1歩だけ進めばいい」に戻るためのアプリ。

## Central benefit
結果が見えない期間でも、自分の積み上げを見失わず、今日の具体的な1歩を選んで継続できる。

## Problem / design rationale
努力と結果は同時には見えないことが多く、結果だけを観察すると「進んでいない」と感じやすい。このアプリは実際の能力や将来の成果を科学的に予測するものではなく、継続のためのゲームモデルとして「積み上げ」と「勢い」を分けて可視化する。

- 積み上げ: 実行した行動の記録。基本的に減らない。
- 勢い: 最近の連続性。空白日で下がるが、過去の積み上げは消さない。
- 現在地: 積み上げ + 勢いを成長カーブ上に表示する。
- 突破ライン: 目標ごとに設定したゲーム上の節目。実際にその日数・歩数で成果が保証されるという意味ではない。

「休んだら全部ゼロ」という罰ゲームにせず、空白日は勢いだけを下げる。これにより、継続の大切さと再開可能性を同時に体感させる。

## Core interaction
1. 伸ばしたいものを1つ選ぶ（英語・運動・お金・仕事・創作）。
2. 画面中央の成長カーブで現在地と突破ラインまでの残り歩数を見る。
3. 「今日の1歩」から、実際にやった具体的な行動を1つタップする。
4. カーブ上の現在地がその場で前進し、積み上げ・勢い・残り歩数が変化する。
5. 空白日があれば次回起動時に勢いだけが後退し、「積み上げは残っている」と明示する。

操作そのものを「今日の具体行動を選ぶ → 見えない前進が見える」に一致させ、単なる解説・三択問題にはしない。

## First 10 seconds
初回は「何を伸ばしたい？」と5つの大きな選択肢だけを表示する。選択後はすぐに、成長カーブ・現在地・「突破まであと○歩」・今日の行動ボタンを同じ画面に出す。長いチュートリアルは置かない。

## Success condition
ユーザーがセッション終了時に、

- 自分の現在地を確認できた
- 今日の具体的な行動を1つ記録できた
- 残り歩数が減った、または空白日後でも積み上げが残っていることを確認できた

の3つを満たし、「結果がまだでも今日は進んだ」と認識できること。

## Uniqueness
既存LEVEL UPが判断・感情・行動の特定反射を鍛えるのに対し、本アプリは複数領域の長期努力について「結果が見えない期間そのもの」を成長カーブと二層進捗で可視化し、毎日の継続判断を支える点が固有。

## Repeat-use strategy
毎日1回、実際にやった行動を記録すると積み上げと勢いが更新される。再訪時には前回位置、連続日数、空白日の勢い変化が反映され、同じ目標を続ける意味がある。突破後は同じ行動の表示倍率を上げ、初期の積み上げが後半の伸びにつながった感覚を演出する。

## Title rationale
- Main user benefit/motive: 努力が無駄かもしれない不安から抜け、継続しやすくなること。
- Why this title is direct and specific: ユーザーが最も知りたい「結果までどれくらい進んだか」を「あと○歩」で直接示す。
- How it matches the actual app: メイン画面で常に「突破まであと○歩」を表示し、今日の行動で数字とカーブが実際に動く。
- Market/uniqueness checks actually performed (if any): 今回は市場検索をタイトル決定の根拠には使用していない。アプリ内容との一致を優先した仮採用タイトル。
