# 機嫌は自分で取る — LEVEL UP

外部条件を変えず、自分の状態を整える一手を選ぶ反射ゲーム。

## Core loop

1. 予定外の出来事で機嫌ゲージが下がる
2. 10秒以内に4枚の手札から1枚を選ぶ
3. 「外部条件を変える」罠は回復しない
4. 状況に合う自己調整アクションほど大きく回復する
5. 8シーン後に、使えた調整手札とREGULATIONスコアを返す

## 学習設計

- 「嫌な気持ちを消す」ことは成功条件にしない
- 低い状態からでも、回復方向へ1手動けば成功
- 身体 / 感覚 / 注意 / 言葉 / 小さな行動 / 距離 / 回復 / ユーモアの8カテゴリを反復
- 合言葉は「で、自分に何してあげる？」
- 外部条件を操作する選択肢を毎ラウンド1枚混ぜ、課題の切り分けを即時フィードバックする

## コンテンツ

- 16イベントから毎回8シーンをランダム出題
- 自己調整アクション16種
- 外部条件を変えようとする罠6種
- 10秒タイマー
- RESET COMBO
- REGULATIONスコア
- 手札カテゴリ集計
- BEST / 連続プレイをlocalStorage保存
- 結果コピー
- サウンドON/OFF
- prefers-reduced-motion対応

## 実装

依存なしの静的HTML/CSS/JavaScript。`games.hitobito.jp/apps/levelup-mood/` 配下でそのまま配信可能。
