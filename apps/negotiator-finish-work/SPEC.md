# 仕事を終わらせる5手 — Product Spec

## Exact use moment
仕事をやめる時間なのに「あと少しだけ」と続けてしまう人が、退勤・就寝・休憩の直前に開き、2分以内に仕事を安全に閉じて身体を仕事から離す。

## Central benefit
終わらせる判断を考えずに、5つの終了動作へ分解して仕事を閉じる。

## Problem / design rationale
「仕事を終える」は1つの大きな判断に見えるため、未完了感や明日の不安があると延長しやすい。そこで終了を「保存→明日の最初の一手→タブを閉じる→連絡を閉じる→身体を離す」の小さな実行列にする。NEGOTIATORの原則どおり、拒否しにくい最小要求へ落とし、各手を実際に完了させる。

## Core interaction
5枚の終了カードを1枚ずつ下へスライド/タップして「閉じる」。各カードを閉じるほど画面上の仕事机が暗くなり、最後に完全消灯する。単なる質問ではなく、画面を閉じる操作が現実の終了行動と対応する。

## First 10 seconds
「まだ仕事してる？」→「5手で閉じる」の一文と、最初のカード「保存する」が即表示される。説明書は置かない。

## Success condition
5手を完了し、最後に「仕事は閉じた。次は明日の自分の担当。」と表示される。途中で明日の最初の一手を1つだけ保存できる。

## Uniqueness
`nou-keshigomu`は頭に残った仕事を手放す切替、`two-tasks-only`は今日抱える仕事を減らす。これは「いま仕事を物理的に終了する一連の動作」を最後まで実行させるアプリ。

## Repeat-use strategy
終業時に毎回使える。前回の「明日の最初の一手」を次回開始時に表示し、終了儀式として定着させる。

## Title rationale
- Main user benefit/motive: 時間を取り戻し、仕事を終える
- Why this title is direct and specific: 目的と手数がそのまま分かる
- How it matches the actual app: 必ず5つの終了動作を行う
- Market/uniqueness checks actually performed: Web/Amazon検索で候補語を確認。「仕事を終わらせろ」は一般的な表現として既存コンテンツ内に見つかったため、より具体的な「仕事を終わらせる5手」を採用
