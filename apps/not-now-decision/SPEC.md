# いま決めなくていい — Product Spec

## Exact use moment
新しい仕事・依頼・アイデア・買い物・企画などが目の前に来るたび、その場で「やる／やらない」を決めようとして判断WIPまで増やしてしまう時に使う。

## Central benefit
重要な判断を雑に先延ばしするのではなく、**「今日決める必要があるか」だけを先に判定し、不要なら再検討日を決めて判断そのものを頭から降ろす。**

## Core mechanic — DECISION GATE
判断したいことを1件入力し、3問だけ答える。
1. 今日が実際の締切？
2. 今日決めないと誰か・何かが止まる？
3. 待てば判断材料が増える？

- 1または2がYES → `今日決める理由あり`。その場で結論を迫らず「決める時間を1枠取る」へ。
- 1と2がNO → `いま決めなくていい`。明日 / 3日後 / 1週間後から再検討日を選び、保留庫へ入れる。
- 3がYESなら保留をさらに推奨するフィードバックを出す。

## Why game
「決断する」ことではなく、判断案件をゲートへ通し、NOWかLATERへ仕分ける。判断を抱え続けず、保留に正式な置き場所を与える。

## Persistence
保留案件を最大10件localStorageへ保存。再検討日とともに一覧表示し、済んだ案件は削除できる。

## Uniqueness
優柔不断の克服ではない。**即断しすぎて判断WIPが増えることを防ぐ**アプリ。

## Quality target
分かりやすさ9 / 役立ち度9 / 操作8 / 独自性9 / 継続性9。
