# 言いたいことを、ちゃんと言える。 — Product Spec

## Exact use moment
仕事・家族・友人・取引先などとの会話で、「本当は断りたい／頼みたい／反対したい／やめてほしい」と思っているのに、相手が不機嫌になりそうで飲み込みそうな人が、実際の会話の直前または日常練習として開く。開始時の「揉めたくない」「嫌われたくない」「でも我慢もしたくない」という状態から、終了時には、相手を攻撃せず自分も引っ込めずに、短い言葉で自分の線を示せる状態になる。

## Central benefit
相手の反応が怖い場面でも、攻撃にも迎合にも逃げず、自分の要望・NO・異論・境界線を落ち着いて言葉にできる反射を作る。

## Problem / design rationale
言いたいことがある場面では、内容を考える前に「相手を怒らせたくない」「悪く思われたくない」という圧がかかり、受け身に飲み込むか、我慢の反動で攻撃的になるかに振れやすい。そこで本アプリでは、アサーティブな返答を「正解文を読む知識」にせず、①受け身／攻撃の反射を見抜いて捨てる、②事実・自分の立場・具体的な要望／境界を自分の手で組む、③相手から押し返されても短く再主張する、という実際の会話に近い順序で反復する。

## Core interaction
1セッションは複数の具体的な会話場面で進む。まず「飲み込む」「攻撃する」という2つの反射カードをスワイプ／タップで退場させる。次に、複数の言葉の断片から「事実」「自分の立場」「要望・境界」の3つを選んで返答レーンへ組み立てる。誤った断片は、なぜ受け身／攻撃／曖昧さにつながるかを短く返し、選び直せる。返答を組めたら相手から抵抗・不機嫌・再要求が返り、最後に「受け止める + 線を繰り返す + 必要なら代案」の押し返しラウンドを行う。

操作そのものが、現実の会話で必要な「反射を止める → 自分の言葉を組む → 押し返されても線を保つ」の練習になるため、一般的な3択クイズにはしない。

## First 10 seconds
最初の画面に大きく「言いたいことを、ちゃんと言える。」、直下に「断る・頼む・反対する・やめてほしいを、攻撃せず我慢せず練習」と表示する。主ボタンは「1分練習を始める」だけを強く見せる。開始後すぐ実際の会話が表示され、「まず、飲み込む／攻撃する反射を外へ」の指示と動かせる2枚の反射カードが出る。長いチュートリアルは置かない。

## Success condition
セッション終了時、ユーザーが少なくとも3つの場面で、受け身／攻撃の反射を避け、事実・立場・要望／境界を組み、さらに相手の押し返し後も線を保てていること。結果画面では「断る／頼む／異論／境界／押し返されても崩れない」の実績を今回の行動に基づいて表示し、次に練習すべき弱い場面を1つ返す。

## Uniqueness
`hard-request` は「揉めそうでも必要なお願いをする」場面に特化し、`kotowaru` は断る力に特化している。本アプリは、頼む・断る・異論を言う・やめてほしいと伝える・交渉するという複数の自己主張を同じ基本フォームで組み、さらに相手の不機嫌や再要求を受けた後の再主張まで反射練習する点が独自で、既存1アプリでは代替できない。

## Repeat-use strategy
日ごとに開始シナリオを変え、仕事・家族・友人・取引先・SNS・お金などの場面をローテーションする。ローカルに技能別の成功履歴を保存し、再訪時は前回弱かった「断る／頼む／異論／境界／押し返し」の場面を優先して混ぜる。単なる連続記録ではなく、苦手な自己主張を反復すること自体を再訪理由にする。

## Title rationale
- Main user benefit/motive: 嫌われる・揉める怖さから逃げずに、自分を守りながら言いたいことを伝えられるようになる。
- Why this title is direct and specific: 専門語「アサーティブ」を前面に出さず、ユーザーが欲しい変化そのものを「言いたいことを、ちゃんと言える」と表現する。
- How it matches the actual app: 実際に複数の会話場面で、受け身／攻撃を避けながら返答を組み、押し返しにも再主張する体験になっている。
- Market/uniqueness checks actually performed (if any): 2026-08-22にWeb検索で完全一致に近いフレーズと「アサーティブ／断る／頼む／反対する」を確認。完全一致のAmazon商品タイトルは検索結果で確認できなかった。検索結果には一般的な「言いたいことを言える」表現が存在するため、固有表現としての独占性は主張しない。
