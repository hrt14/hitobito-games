# 思い定める。 — 品質レビュー

## 固有評価基準
- 10秒以内に「思い通りにいかなかった現実を受け止めるアプリ」と分かる
- 主要操作が上スワイプで直感的に分かる
- 「受け入れる = 何もしない」にならず、動かせる場合は次の一手へ進む
- 12問の反復で「事実→CONTROL」の順番が崩れない
- 現実モードで入力本文を保存しない
- iPhone幅で主要操作が1画面内に収まり、ボタンが十分大きい

## 実装時チェック
- 進行不能なし
- pointer / keyboard 両対応
- prefers-reduced-motion 対応
- localStorage失敗時もプレイ可能
- AudioContext失敗時もプレイ可能
- 自由記述のHTML挿入をしない（textContentのみ）
