# ご機嫌ミリオネア — Product Spec

## Exact use moment
一日の途中や終わりに「今日は大した良いことがなかった」と感じている人が開き、今日の小さな楽しかったことを1〜3個拾って、自分で値段をつけ、終わるころには「今日にもちゃんとプラスがあった」と目で確認できるようにする。

## Central benefit
今日の小さな「楽しい」を見逃さず、価値として認識できる。

## Problem / design rationale
このアプリは、嫌な出来事や未完了のことばかり数えて、小さな楽しい出来事を数えずに一日を終えそうな瞬間を対象にする。「思い出す→具体化する→値段をつける→資産として残す」という短い操作で、その日に実際にあった快い出来事を意図的に捕まえる。ポイントは活動量の報酬ではなく、ユーザー自身が見つけた出来事の価値ラベルとして使う。

## Core interaction
1. 今日の楽しかったことを1行で記録する。
2. 10G / 100G / 1,000G / 10,000Gから「自分にとっての値段」を選ぶ。
3. 選んだ金額がコインとして金庫に落ち、ご機嫌資産へ加算される。
4. 翌日以降、過去の1件を思い出して今も少し嬉しければ10%の「思い出し配当」を受け取る。

「値段をつける」操作そのものが、その出来事を一度立ち止まって味わう行為になる。再訪時の配当は過去の良い出来事を再体験する理由になる。

## First 10 seconds
最上部に現在のご機嫌資産と100万G目標を大きく表示。その直下に「今日、何がちょっと楽しかった？」と1行入力欄、さらに「おいしかった」「笑った」「ほっとした」などのきっかけチップを置く。説明を読まなくても、楽しかったことを入れて「値段をつける」を押せば進める。

## Success condition
1セッションで最低1件の楽しい出来事に値段をつけて金庫へ入れられる。3件入れた場合は「今日はもう○Gぶん楽しかった」と今日の資産増分と最高値の出来事が表示される。

## Uniqueness
「ありがとう探し」が日常を支えるものを観察するゲーム、「機嫌は自分で取る」が機嫌を整える選択肢を増やすゲームなのに対し、本アプリは「実際に今日起きた楽しい出来事へ自分で値段をつけ、長期資産として蓄積・再体験する」個人台帳であり、代替できない。

## Repeat-use strategy
毎日、新しい楽しい出来事を資産化できる。過去の出来事から1日1回だけ「思い出し配当」が出るため、入力がない日でも過去の良い出来事を味わい直す理由がある。累計100万Gを長期目標にする。

## Title rationale
- Main user benefit/motive: 楽しむ / 幸せになる / 心地よくなる
- Why this title is direct and specific: 「ご機嫌」「ミリオネア」で、小さな楽しい出来事を資産として貯めるゲームだと短く伝える。ページタイトルでは「今日の楽しいことを貯める」を補足する。
- How it matches the actual app: 楽しい出来事をGへ換金し、100万Gまで累積する体験そのものを表す。
- Market/uniqueness checks actually performed: 2026-08-25にWeb検索で「ご機嫌ミリオネア」「ご機嫌ポイントでミリオネア」のAmazon.co.jp完全一致候補を確認し、検索結果は0件だった。「ご機嫌ポイント」「ご機嫌貯金」という一般的な周辺表現はWeb上に存在するため、完全な一般語独占は主張しない。
