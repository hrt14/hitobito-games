# 聴く力。— Product Spec

## Exact use moment
家族・友人・同僚が悩みや迷いを話した時、すぐ助言・自分語り・質問攻めをしてしまい、もっと自然に相手の話を聴けるようになりたい人が、会話前後の3分で「受け取る最初の一言」を反射化する。

## Central benefit
相手が続きを話しやすい返しを、無意識に近い速度で出せるようにする。

## Problem / design rationale
傾聴は黙って聞くだけではなく、言い換え・明確化・理解確認などで相手の意味を確かめる技能を含む。そこで説明暗記ではなく、具体的な発話の直後に「要約→気持ちを決めつけず確認→開いた質問」を選ぶ反復にする。

## Core interaction
6つの現実的な会話を、3手ずつ連続して処理する。各手で「助言」「自分語り」「決めつけ」などの典型的な早すぎる反応を避け、相手が訂正できる余白を残す返答を選ぶ。会話の最初の一言を選ぶ操作そのものが傾聴行動の練習になる。

## First 10 seconds
「話すより先に、受け取る。」と目的を示し、すぐ6会話トレーニングか実戦用3手作成を選べる。

## Success condition
要約・気持ち確認・開いた質問の3領域で6会話を終え、どの領域が弱いかを結果で確認できる。

## Uniqueness
`jinshin-shoaku` は協力を引き出す対人コミュニケーション、`hard-request` は必要なお願いを伝える技能。このアプリは「自分が話す」前の受容・理解確認に限定し、相手の発話直後の反射を鍛えるため置き換えられない。

## Repeat-use strategy
会話パターンを反復して弱い段階を改善し、実際の大事な会話の直前にはREAL MODEで3手を準備する。

## Title rationale
- Main user benefit/motive: 人の話を自然に聴けるようになる。
- Why this title is direct and specific: 「傾聴」という専門語より利用者の欲しい結果を短く示す。
- How it matches the actual app: 会話の受け取り方を反復する内容そのもの。
- Market/uniqueness checks actually performed: LEVEL UP既存カタログで対人系 `jinshin-shoaku`, `hard-request`, `assertive` 等を確認し、傾聴そのものの反射訓練は重複していないことを確認。
