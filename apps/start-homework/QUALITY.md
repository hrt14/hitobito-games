# START — 固有品質基準

- 主役: 宿題そのものではなく、着手を止める「START BLOCKER」。行動するたび画面上で小さくなる。
- ゲームループ: 課題を選ぶ → BLOCKERを選ぶ → 現実の行動を5段階まで小さくする → START成立 → 3分だけ続けるか自分で決める。
- 到達目標: 使うほど「全部やる」ではなく「最初だけやる」が反射になり、最終的にはゲームなしで着手できる。
- 高校2年生向けトーン: 子ども向けの褒め言葉・星・保護者監視を避け、本人が自分の状態を攻略するミニマルUIにする。
- 成功条件: 学習量ではなく着手。中断は失敗にせず、戻った行動をRESTARTとして扱う。
