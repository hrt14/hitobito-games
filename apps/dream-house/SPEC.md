# DREAM HOUSE — 川から宇宙まで / 仕様書 v1

## コンセプト
川・海・山が隣接する特殊な土地に建つ洋風邸宅を、地下の海底洞窟から屋上の宇宙エレベーターまで増築していく「絶景増築ゲーム」。

単なる数値型の放置ゲームではなく、投資するたびに家の断面・景色・客・魚・動線・演出が増え、画面そのものが豪華になることを主役にする。

## コアループ
1. 時間経過と画面上の「ひらめき」でDREAMを得る
2. 建築カードを選ぶ
3. その場で家の断面が変化する
4. 来訪者・生き物・背景演出が増える
5. 複数設備の組み合わせで「絶景コンボ」が発生する
6. 次の未完成施設を目指す

## 増築
1. 川辺のカフェ
2. プライベート映画館
3. 山のガラスラウンジ
4. 海底ガラスフロア
5. 海底洞窟ドック
6. 屋上スカイリフト
7. 宇宙ラウンジ

## 絶景コンボ
- 川辺のカフェ + 山のガラスラウンジ = 川音ブランチ
- 海底ガラスフロア + 海底洞窟ドック = 青の回廊
- 映画館 + スカイリフト = 夜から宇宙へ
- 川・山・海・宇宙の主要設備 = 川・山・海・宇宙

## 成長表現
数値だけのレベルアップは禁止。増築のたびに部屋、光、客、魚、背景、移動物、エレベーター、宇宙演出などを実際に変える。

## テンポ
最初の増築は開始時資金で即実行可能。資金不足時も「ひらめき」を触って建築を早められる。待つだけにしない。

## 保存
localStorageへ自動保存し、再訪時には最大2時間分のオフライン収益を加算する。

## 最終到達
宇宙ラウンジ完成時に専用演出を表示する。到達メッセージは「川から宇宙まで、ひとつの家になった。」。終了後も家を眺め続けられる。

## 完成条件
- 開始10秒以内に増築ゲームだと分かる
- 最初の30秒以内に画面が大きく変わる
- 川・海・山・家・地下の関係が1画面で分かる
- カフェ、映画館、水族館、洞窟、宇宙が見た目で区別できる
- 投資前後の画面だけで成長が分かる
- スマホで主要操作が片手で完結する
- 次に作りたい施設を見失わない
- 最終増築が通常購入より大きなご褒美になる
