# 助けて

LEVEL UPシリーズの「抱え込まない反射」を鍛えるスマホ向けブラウザゲーム。

## コアループ

1. 仕事カードが届く
2. 自分 / 田中 / AI / 上司 / 外注 の担当先をタップ
3. 各担当のWIPが並列で進む
4. 自分に積みすぎると疲労・信用・処理速度が悪化
5. 曖昧な仕事は相談、巨大タスクは分解すると強い
6. 18判断後に「抱え込み度」「委任率」「AI活用」「相談」「分解」を振り返る

## 実装

- 外部依存なし（HTML/CSS/Vanilla JS）
- スマホ縦画面ファースト
- タップのみで主要操作が完結
- `prefers-reduced-motion` 対応
- WebAudioはユーザー操作後のみ使用
- localStorageは最後の結果のみ保存

## 配置

`hitobito-games/apps/help-me/` に置けば静的配信可能。
