# 『助けて』品質基準

## 主役

画面の主役は「仕事カード」と「机のWIP」。説明文ではなく、仕事が自分の机に積もる / 他者へ飛ぶ / 机が空くことで、抱え込むことのコストと委任の快感を見せる。

## 初見導線

- 10秒以内に「仕事を誰かへ振るゲーム」と理解できる
- 1件目は自分で処理して成功体験
- 2件目で田中を解放し、並列処理の速さを体験
- 4件目でAIを解放し、下書き・整理を逃がせる
- WIP 5超過で画面が散らかり、助けてボタンが強調される

## 因果関係

- 自分へ振る → 自分WIP増加 → 紙・付箋が増える → 疲労増 → 処理速度低下
- 得意な人へ振る → カードが飛ぶ → 相手のload表示が増える → 並列処理
- 苦手な人へ振る → 即時フィードバック + 完了時信用低下
- 上司へ相談 → 曖昧な巨大タスクが消える / 小さくなる
- 分解 → 巨大カードが3つの小タスクへ変わる

## 完了条件

- 18判断を最後まで進行できる
- 主要ボタンが44px前後以上のタップ領域を持つ
- 390px幅で横スクロールしない
- WIP / 信用 / 疲労 / 担当loadが毎手更新される
- 最終リザルトに行動傾向が反映される
- リトライで完全に初期化される
- JSコンソールエラーなし
