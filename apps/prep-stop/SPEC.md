# 準備はここまで — Product Spec

## Exact use moment
会議・商談・コンサル・プレゼンの前に、必要な準備はかなり済んでいるのに「これも調べた方がいい」「もう少し資料を直した方がいい」が増え続け、本番まで仕事を膨らませてしまう時に開く。

## Central benefit
準備量を増やすのではなく、**本番を成立させる最低限の4条件を満たした瞬間に「準備完了」を宣言し、それ以上の追加準備を止める。**

## Core mechanic — READY LINE
準備は100点を目指さない。以下4ロックだけを解除する。
1. `目的` — 終わった時どうなれば成功かを1文
2. `見る` — 必ず確認する数字・資料を1つ
3. `聞く` — 相手に必ず聞くことを最大3つ
4. `次` — 最後に決める／提案する次の一手を1つ

4/4になったら画面を「SEALED」に切り替え、`準備完了。もう調べない。` と表示する。

## After-seal urge breaker
完了後に「まだ何か調べたい」を押すと、追加作業を入力させ、ただ1問だけ聞く。

`これがなくても本番は進められる？`
- `はい` → `それは本番の必須条件ではない。今日はやらない。`
- `いいえ` → 追加作業を「最後の1件」に登録できる。ただし追加枠は1つだけ。2件目を入れるなら既存の追加1件と入れ替える。

つまり「不安だから無限追加」をできないUIにする。

## Why this is a game
準備チェックリストではなく、4つのロックを解除してゲートを閉じるゲーム。完了後は追加作業を通すために「本番を止めるほど必要か」という関門を突破しなければならない。

## End state
- 4つの最低条件が言語化されている
- 追加必須作業は最大1件
- 画面に `準備完了。もう調べない。` が残る
- 同じ日の再訪でSEALED状態を復元する

## Uniqueness
一般的なタスク管理や会議準備アプリは「何を足すか」を扱う。本作は**準備の終了条件を作り、追加準備を止める**ことだけを扱う。

## Quality target
分かりやすさ9 / 役立ち度9 / 操作8 / 独自性9 / 継続性8。
本番Firebase Hostingでスマホ幅の「4ロック解除→SEALED→追加作業判定」まで自動プレイして完成。
