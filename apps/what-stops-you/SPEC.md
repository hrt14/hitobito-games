# あなたを止めているもの診断 — SPEC

## Exact user / use moment

「やった方がいい」「動きたい」と本人も分かっているのに、仕事・返信・挑戦・片付け・意思決定などの場面でなぜか着手できず、原因を短時間で整理したい人が開く。

## One central benefit

12の具体場面への回答から、今の自分に出やすい「行動のブレーキ」を5タイプで可視化し、その場で使える最小の解除行動を1つ持ち帰れる。

## Positioning / safety

医療・心理検査ではない。診断名や性格の固定ラベルを付けず、回答時点で出やすかった行動パターンを整理する自己理解ツールとして扱う。

## Five brake types

1. 失敗恐怖型 — 失敗・損失・後悔を避けたくて止まりやすい
2. 他人評価型 — 嫌われる・変に思われる・期待を外すことを避けたくて止まりやすい
3. 完璧主義型 — 不十分な状態で出すことを避けたくて止まりやすい
4. 面倒回避型 — 開始時の負荷・工程の多さ・億劫さを避けたくて止まりやすい
5. 考えすぎ型 — 選択肢・情報・先の展開を考え続けて止まりやすい

## Design rationale

「何が正しいか」を問う知識テストではなく、現実の場面で最初に浮かぶ反応を選ばせる。抽象的な自己評価だけではなく、仕事・返信・新しい挑戦・SNS・買い物・勉強・依頼・締切・片付け・誘い・失敗後・個人プロジェクトなど場面を変えることで、同じブレーキが繰り返し現れるかを見えるようにする。

## Core interaction

1問ずつ具体場面を提示し、「そのとき一番近い反応」を5つから直感で選ぶ。選択すると画面上部の5本の細いブレーキメーターが即時に変化するが、タイプ名は回答中は伏せる。12問後に主ブレーキ・副ブレーキ・5タイプ比率を開示する。

この操作は、本人が普段は一塊に感じている「動けない」を、繰り返し出る回避パターンへ分解する目的と一致する。

## First 10 seconds

- タイトル: 「あなたを止めているもの診断」
- 一文: 「やればいいのに動けない。その“止まり方”を12問で見つけます。」
- 所要時間: 約2分
- CTA: 「診断する」
- 共有経由では「友だちは○○型。あなたは？」を先頭に表示し、すぐ開始できる。

## Scoring

各回答は5タイプのいずれかに1点。12問合計で最多を主ブレーキ、2位を副ブレーキとする。同点時は後半6問で多く選ばれたタイプを優先し、それでも同点なら最後に選ばれた方を優先する。結果画面では点数だけでなく全タイプの比率を表示する。

## Result experience

- 主ブレーキ名
- 「止まりやすい瞬間」3例
- 回答から見える短い説明
- 30秒でできる解除行動
- 副ブレーキ
- 5タイプの比率
- 結果別の既存LEVEL UPアプリ推薦
- Web Share APIによる結果共有（非対応環境はクリップボード）
- 共有URLには回答内容を含めず、結果タイプだけを `?from=share&type=...` で付与

## Recommended LEVEL UP mapping

- 失敗恐怖型 → `fail-forward`
- 他人評価型 → `approval-off`
- 完璧主義型 → `fail-forward`
- 面倒回避型 → `3sec-action` / `ato-5min`
- 考えすぎ型 → `extra-load`

## Success condition

ユーザーが終了時に「自分は単に怠けているのではなく、こういう場面でこのブレーキが出やすい」と具体的に説明でき、次に止まった瞬間に使う解除行動を1つ選べている。

## Why existing LEVEL UP apps cannot replace it

既存アプリは個別のブレーキを外す練習をする。このアプリはその前段で、複数の止まり方から「今の自分はどれが強いか」を判定し、適切な既存アプリへ分岐させる入口である。

## Repeat-use / share strategy

自己理解の入口なので基本はワンショット。ただし最新結果を端末内に保存し、再訪時に前回タイプを表示する。状況が変わったと感じたときに再診断できる。結果カードは「私を止めていたのは○○型。あなたは？」という比較・会話のきっかけとして共有でき、共有相手が同じ診断を開始できる。
