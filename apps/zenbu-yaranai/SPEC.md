# 全部やらなくていい — Product Spec

## Exact use moment

仕事・締切・会議・移動・複数案件が重なり、「全部ちゃんとやらなければ」と考えているのに処理時間が足りず、ミスも増え、何から手を付けるか分からなくなった人が開く。終了時には「全部終わっていない」ではなく、「今はこの一件だけ。最低限はここ。これはやらない」と言える状態に変える。

## Central benefit

高負荷時に、今処理する一件だけへ注意を戻し、最低成立ラインまで前へ進める。

## Problem / design rationale

このアプリでは、高負荷時に「もっと頑張る」「全部終わらせる」「ちゃんとする」を目標にしない。抱えている仕事を外へ出し、今先に処理すると被害が減る一件を選び、その一件の最低成立ラインと今回やらないことを明示してから短い作業時間へ入る。

重要な設計原則は、能力や速度で押し切るのではなく、順番と終了条件と捨てるものを先に決めること。

## Core interaction

1. 8問の仕事負荷セルフチェックを1問ずつ処理する。
2. 頭に残っている仕事をすべて外へ書き出す。
3. 一覧から「今先に処理すると被害が減る一件」を1つだけタップする。
4. その一件の最低成立ラインを一行で決める。
5. 「今回はやらない」ものを複数選択して固定する。
6. 他タスクを画面から消し、選んだ一件・最低成立ライン・捨てたもの・残り時間だけを見ながら25分進める。
7. 終了後に「最低ライン達成 / もう25分必要 / 今日はここまで」の一判断だけを行う。

操作そのものが、全体を抱える状態から「一件を選ぶ → 小さく成立させる → 明示的に捨てる → 一件だけ実行する」状態への切り替えになっている。

## First 10 seconds

初期画面には説明用イントロを置かない。最初から「全部やらなくていい」「高負荷のときほど、一個ずつ。」とセルフチェック1問目、その3つの回答ボタンを表示する。ユーザーは説明を読まずにすぐ1判断できる。

## Success condition

セッション終了時に以下が成立すること。

- 今処理する一件が1つに限定されている。
- 100点ではなく最低成立ラインが文章で決まっている。
- 今回やらないことが最低1つ明示されている。
- 25分セッションを実行し、完了・継続・今日は停止のいずれかを自分で選べる。
- 完了時は「1件、減った。」、停止時は「今日はここまで。」と、未処理全体ではなく処理した一件へ視点が戻る。

## Uniqueness

既存の即着手・先延ばし系アプリと違い、このアプリは「行動を速く始める」ことではなく、高負荷時に複数仕事を外在化し、今の一件・最低成立ライン・明示的な捨て項目・終了判断までを一つの実務フローとして作るため、別アプリで置き換えない。

## Repeat-use strategy

高負荷は繰り返し発生するため、その都度使える実戦ツールとする。ローカル履歴に加え、Googleログイン時はFirestoreにも履歴を保存し、過去7日についてREDだった日、入力タスク数、完了した一件数、よく捨てた項目、連続RED日数を見る。履歴分析を主役にはせず、「また詰まったら一個に戻す」ための文脈だけ残す。

## Data / persistence

- セッション途中: localStorageへドラフト保存し、リロード後も同じ段階へ戻る。
- 完了履歴: localStorageへ保存する。
- Googleログイン時: `levelupUsers/{uid}/history/{recordId}` へ同じ履歴をFirestore保存する。
- 保存項目: 日付、負荷レベル、入力タスク数、選んだ一件、最低成立ライン、諦めたもの、25分セッション回数、完了したか。
- 未ログイン時の入力内容を公開データに送らない。

## Workload check classification

8問を「いいえ=0 / 少し=1 / かなり=2」で自己評価する。合計0–4をGREEN、5–9をYELLOW、10–16をREDとする。これは医療診断ではなく、このアプリ内で作業モードを切り替えるための仕事負荷セルフチェックである。

## Title rationale

- Final title: **全部やらなくていい**
- Subtitle: **高負荷のときほど、一個ずつ。**
- Main user benefit/motive: 時間と処理能力が足りないときに、全部を抱えず今の一件へ絞れること。
- Why this title is direct and specific: 「全部ちゃんとやらなければ」という開始時の認知へ、そのまま短く反対命題を返している。
- How it matches the actual app: タスクを一件に絞り、最低成立ラインを決め、やらないものを明示する機能と一致する。
- Market/uniqueness checks actually performed: 2026-08-25にWeb検索で「全部やらなくていい」の完全一致語を確認。2025年刊『自立した子どもになるための やらない子育て』の商品説明などに同じ文言は存在したため、この日本語表現自体を固有・独占的とは扱わない。一方、検索結果では「全部やらなくていい」を書名そのものとする明確な同名書籍は確認できなかった。Amazon.co.jpドメイン限定検索でも明確な同名商品は取得できなかったが、Amazon内サジェストそのものはこの環境では直接検証できていないため、タイトルの法的・商標上の独占性は主張しない。
