# 1日アンチビジョン — SPEC

## Exact user / use moment
今の生活や仕事に不満はあるが、目標を書くだけでは行動が変わらず、「このまま数年続くのは嫌だ」と感じている日に、朝から夜まで1日かけて方向を切り替えたい人が使う。

## One central benefit
「このまま続いた未来」と「選びたい未来」を同じ日に具体化し、日中の自動運転を5回止め、最後に明日の具体的な一手まで決める。

## Why the problem occurs / design rationale
理想だけを考えると現在の惰性との距離が曖昧なままになりやすい。このアプリでは先に避けたい未来を具体化して現在の延長線を可視化し、その直後に反対側の未来と新しい行動基準を作る。さらに日中の5回のチェックインによって、その日の実際の行動がどちらの未来へ向かっているかを観察する。

## Core interaction
朝は13問を1問ずつ書く。前半で現在地、次に5年・10年先のアンチビジョン、最後に理想の平日・新しい自己定義・今週の行動を作る。昼は11時・13時・16時・19時・21時の5地点で現在の行動を判定する。夜はアンチビジョンとビジョンを各1文に圧縮し、1年・1か月・明日の行動へ落とす。

書く操作そのものが目的ではなく、「未来の分岐を具体化 → 現在の行動の向きを判定 → 明日の行動を決める」という判断を1日の実生活の中で行うことが訓練対象。

## First 10 seconds
最初の画面で「今日は、未来を2本つくる」「朝20–30分 / 昼5回 / 夜10分」と全体像が見える。「朝を始める」ボタンから即開始できる。

## Success condition
朝13問、昼5回、夜5項目を完了し、最後に「明日、理想の自分なら当然やる具体的行動」が1つ決まっている。

## Why existing LEVEL UP apps cannot replace this
既存の多くは数十秒〜数分で特定の思考反射を鍛える。このアプリは1日の実生活そのものを舞台に、朝の未来設計・日中の自己観察・夜の行動決定を時間でつなぐ点が異なる。

## Repeat-use strategy / one-shot rationale
基本は常用ではなく、停滞感が強い日や方向を立て直したい日に使う「一日プログラム」。同じ日に何度も繰り返す必要はない。必要なときに新しい1日としてリセットして再実行できる。
