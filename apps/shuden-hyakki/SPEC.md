# 都電 百鬼夜行 — 終電のあと — / SPEC

## コンセプト
終電後の都電を運転し、停留場に現れる「妖怪だけ」を乗せる3分間の判断ホラー。

## 1プレイ
- 12停留場
- 妖怪7体 + 人間5人をランダム配置
- 妖怪なら「停まる」、人間なら「通過」
- 3回間違えると線路が「あちら側」へ侵食され運行失敗
- 朝まで走り切ると運行評価 S / A / B / C

## 主役
運転席のフロントガラス。プレイヤーの判断結果が、乗客の増加・手形・霧・ひびとしてガラス周辺に残る。

## ループ
接近 → 停留場を観察 → 車掌メモ + 見た目の違和感 → 停車/通過 → 即時結果 → 次停留場。

## 継続
- 8種の妖怪図鑑
- 妖怪は1回ですべて出ない
- 図鑑はlocalStorage保存
- 毎回ランダムな順番

## モバイル
- 主要判断は画面下の2ボタンのみ
- タップ領域64px以上
- 360px幅から成立
- WebAudioはユーザー操作後のみ
- vibration APIは対応端末のみ
