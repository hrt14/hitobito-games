# 目先に振り回されない — 坂本龍馬に学ぶ「大きく考える」練習 — Product Spec

## Exact use moment
目先の失敗・対立・競争・数字悪化が起きて、すぐ言い返す／取り返す／施策を増やすなど「今この場の勝敗」に反応したくなっている人が開き、約3〜5分で **目的・時間・人・手段** の4方向へ盤面を広げたうえで、当面の勝敗より大きな一手を選べる状態へ戻る。

## Central benefit
目の前の問題に小さく反応する前に、**盤面そのものを広げて一手を選ぶ癖**を反射化する。

## Problem / design rationale
問題が起きた直後は、目の前の相手、今日の損得、最初に思いついた手段だけで考えやすい。本アプリは「気宇の大きさ」を性格・豪胆さ・名言への共感として扱わず、意思決定の前にフレームを広げる操作へ変換する。

坂本龍馬については俗説や創作名言を教材にしない。国立国会図書館が確認できる行動史実として、1862年の脱藩後に勝海舟門下となり神戸海軍操練所建設に尽力したこと、1865年に長崎で亀山社中を開いたこと、薩長連合締結に努力し1866年の盟約に立ち会ったことを採用する。また、国立国会図書館所蔵の1867年「新政府綱領八策」を、個別の対立処理より制度・政体へ視野を広げた史料として扱う。

史実と現代への抽象化は必ず画面上で分離し、「龍馬ならこう考えた」と心情を断定しない。

一次・公的資料:
- 国立国会図書館「坂本竜馬｜近代日本人の肖像」 https://www.ndl.go.jp/portrait/datas/89
- 国立国会図書館「坂本龍馬の政体構想」 https://www.ndl.go.jp/modern/cha1/description02.html

## Core interaction
中央に「今見えている問題」を置き、その周囲に4つのレンズを配置する。

1. **目的** — そもそも何を実現したい？
2. **時間** — 今日ではなく、半年後／数年後なら？
3. **人** — 敵と味方の二択以外に誰がいる？
4. **手段** — 戦う／我慢する以外の打ち手は？

ユーザーは各レンズをタップして盤面を物理的に広げる。レンズを開くほど中央の盤面が拡張し、最低3方向を開くまで「一手」は選べない。これにより、読むだけでなく **視野を広げてから決める順序そのもの**を反復する。

その後、現実的な3つの打ち手から一つを選ぶ。選択肢そのものの知識テストではなく、レンズを開いた後に「目先の一手／一歩広い一手／盤面を変える一手」の差を体感する構造にする。

回答後は、
- 自分の一手がどのスケールだったか
- 現実へ持ち帰れる1文
- 関連する確認済みの龍馬史実
- 史実から本ゲームが抽出した現代向け原則
を短く返す。

## First 10 seconds
最初の画面には以下だけを強く出す。
- タイトル「目先に振り回されない。」
- 何をするか: 「目的・時間・人・手段を広げてから、一手を選ぶ」
- 4つのレンズの短い問い
- 主CTA「今日の5航路をはじめる」

長いチュートリアルは置かない。開始直後の1問目で、閉じた盤面と4レンズが見え、タップすると盤面が広がることで操作を理解できるようにする。

## Success condition
1セッション5場面で以下を可視化する。
- 「盤面を変える一手」を選べた回数
- 4視点すべてを開けた回数
- 目的／時間／人／手段の各レンズを開いた回数
- 最も開く回数が少なかった「次に意識するレンズ」

セッション成功の目安は、5問中4問以上で「盤面を変える一手」を選び、少なくとも3問で4レンズすべてを開くこと。ただし結果画面では説教せず、次に忘れやすい視点を1つ返す。

## Uniqueness
既存の `uchite` は「打ち手の種類を増やす」訓練、`viewpoint-exam` は「出来事の別解釈」、`main-character` は「自己決定」、`reflex-7` は複数原則の反射選択。本アプリはそのどれとも違い、**意思決定の直前に「目的・時間・人・手段」という4軸で戦略的フレームを拡張してから一手を選ぶ順序**を一つの身体操作として訓練する。

また、歴史人物をクイズや名言集として消費せず、確認済み行動史実と現代への抽象化を分離して提示する点も固有。

## Repeat-use strategy
- 10場面以上から日付で5場面をローテーションする。
- 前回までの自己ベスト（盤面を変える一手の回数）を端末内に保存する。
- 各セッションで「最も開かなかったレンズ」を返す。
- 結果を共有でき、共有文には個人入力を含めない。

繰り返しの価値はポイント収集ではなく、違う現実場面でも「まず盤面を広げる」順序が出るようになること。

## Title rationale
- Main user benefit/motive: 目先の対立・損得・焦りから抜け、より大きな判断をしたい。
- Why this title is direct and specific: 「気宇の大きい人になる」だけでは抽象的なので、ユーザーが得る変化を「目先に振り回されない」と先頭で明示し、教材の由来として坂本龍馬を後段に置く。
- How it matches the actual app: ゲームの中心操作が、目先のフレームから4方向へ視野を広げることそのもの。
- Market/uniqueness checks actually performed (if any): Amazon.co.jpを対象に「坂本龍馬」「大きく考える」の完全一致に近い組合せをWeb検索したが、本タイトルと同一の明確な商品名は確認できなかった。これは商標・法的な利用可能性を保証する調査ではない。
