# Historical sources

## 国立国会図書館「坂本竜馬｜近代日本人の肖像」
https://www.ndl.go.jp/portrait/datas/89

本アプリで使う範囲:
- 1862年に脱藩して江戸へ出たこと
- 勝海舟の門下生となり神戸海軍操練所建設に尽力したこと
- 1865年に長崎の亀山に社中を開いたこと
- 薩長連合締結に努力し、1866年に西郷隆盛と木戸孝允の盟約に立ち会ったこと

## 国立国会図書館「坂本龍馬の政体構想」
https://www.ndl.go.jp/modern/cha1/description02.html

本アプリで使う範囲:
- 1867年11月の「新政府綱領八策」
- 国立国会図書館が、これを「船中八策」をもとに龍馬が起草して土佐藩重役に示した政体案として紹介していること

## App rule
史実から導く「現代への抽象化」は史実そのものではない。画面上でも別枠で表示し、龍馬の内心や性格の断定には使わない。
