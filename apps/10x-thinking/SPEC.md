# 目の前を10倍にする。— Product Spec

## Exact use moment
目の前の仕事・企画・顧客対応・学習を「いつものやり方で終わらせよう」としている人が、着手前や途中でこのアプリを2〜3分開き、「これを10倍にしたら？」という問いから量・質・波及の3方向へ視野を広げ、同じ延長線ではない一手を1つ持ち帰る。

## Central benefit
目の前の小さな仕事を、より大きな成果につながるチャンスとして捉え直す反射を身につける。

## Problem / design rationale
人は目の前の課題を与えられたサイズのまま解こうとしやすい。すると「1件に返信する」「資料を1本作る」「商品ページを1つ直す」のような局所最適になり、同じ労力の延長線でしか考えなくなる。

このアプリでは「10倍」を根性や長時間労働の意味にしない。倍率を上げるほど、単に作業量を増やすのではなく、次の3方向へ発想を切り替える。

- 量：1人・1回・1件ではなく、より多くへ届く形にできないか
- 質：同じものを磨くだけでなく、体験や判断材料そのものを変えられないか
- 波及：今回だけで終わらず、仕組み・再利用・他者への展開につなげられないか

10倍という大きな倍率を置くことで「今の方法を10回繰り返すのは無理だ」と気づかせ、方法そのものを変える設計にする。

## Core interaction
各ラウンドで、まず「1X：普通ならこうする」という目の前の仕事が表示される。

ユーザーは3つのレンズ（量・質・波及）をタップして盤面を広げる。各レンズには、その場面固有の問いと、見える世界が1段広がる具体例が出る。

その後、1X〜10Xの倍率スライダーを自分の指で押し上げる。倍率に応じて打ち手のプレビューが「同じ延長線」→「広げた一手」→「仕組みを変える一手」へ変化する。8X以上かつ2レンズ以上を開くまで「10X LAUNCH」は成立しない。

物理的に倍率を上げ、同時に視野を広げる操作そのものを、「目の前のことを与えられたサイズのまま受け取らない」反射訓練にする。

## First 10 seconds
最初の画面で大きく「目の前を10倍にする。」と表示し、その直下に「10倍働くのではない。量・質・波及のどこかで桁を変える。」を表示する。

3つのレンズが1画面内に見え、メインボタン「今日の5つを10倍にする」が表示される。説明を読まなくても、「普通の仕事を10倍に見直す短い練習」だと理解できる。

## Success condition
5場面を終えた時点で、以下が可視化される。

- 8X以上まで引き上げた回数
- 3レンズをすべて開いた回数
- 「同じことを増やす」ではなく、仕組み・再利用・波及まで変えた回数
- 最も使えていないレンズと、次に現実で使う1文

セッション後に「目の前の仕事を10倍に見る問い」を1つ持ち帰れれば成功。

## Uniqueness
「打ち手を増やせ。」や「発想筋40」が選択肢の数・発想の切り口を増やすアプリなのに対し、このアプリは、目の前の仕事の“サイズそのもの”を1Xから10Xへ引き上げ、量・質・波及のどこで桁を変えるかを反射化するため独立している。

## Repeat-use strategy
毎回5場面をランダムに出し、ラウンドごとのレンズ使用数・到達倍率・構造的な一手を記録する。ローカルにセッション数とベスト記録を保存し、次回は弱いレンズを結果画面で再提示する。

現実で大きくしたい仕事があるたびに2〜3分開く用途を想定する。ログインボーナスではなく「今日の目の前を大きく見る」こと自体を再訪理由にする。

## Title rationale
- Main user benefit/motive: 目の前の仕事から、より大きな成果・機会を引き出すこと。
- Why this title is direct and specific: 「目の前」と「10倍」を入れ、何をするアプリかを一読で伝える。
- How it matches the actual app: 実際に1X〜10Xの倍率を動かし、目の前の具体的な場面を量・質・波及で拡張する。
- Market/uniqueness checks actually performed (if any): 2026-08-23にWeb検索で「10倍思考」を確認し、同語を含む既存書籍（2016年『ドナルド・トランプ 奇跡を起こす10倍思考』、2024年『10x 同じ時間で10倍の成果を出す仕組み』）が存在することを確認。固有タイトルを単に「10倍思考」とせず、「目の前を10倍にする。」を主タイトルにした。
