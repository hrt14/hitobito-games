# もう払った。 — 代償先払い反射トレーニング

## 目的
嫌な出来事が起きた瞬間に、アプリを開く前に「代償先払い」と思い出せる反射を作る。

## コアループ
嫌な出来事 → 自力で合言葉を想起 → タップ → PAID / 支払い済み → 「じゃあ次。」

## 主要モード
- 30秒だけ練習: 5問。習熟度に応じて答え表示を減らし、想起中心に移行する。
- 今、起きた: 現実で嫌なことが起きたとき、詳細入力なしで「嫌だった → でも、もう払った → 次」を30秒以内に行う。

## 成功指標
- 累計反射回数
- 想起までの反応時間
- 現実で思い出せた自己申告回数

ストリーク、コイン、ランキングは使わない。休んでも記録は失われない。

## 安全上の位置づけ
「嫌な出来事の後には必ず良いことが起きる」という因果法則を教えるものではない。嫌な出来事を引きずり続けないための意味づけの切り替えとして扱う。事故、犯罪、健康、安全、重大な対人問題などで必要な現実対応をこの考え方で置き換えない。
