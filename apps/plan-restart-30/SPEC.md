# 予定が崩れたら30秒 — SPEC

## Exact use moment
予定どおりに進まなかった直後、残りの作業へ移る勢いが落ちたときに開き、30秒以内に「過ぎた区間」から「残っている時間」へ注意を戻して、小さい次の一手を始める。

## Central benefit
予定が崩れた後でも、やる気の回復を待たずに次の一手へ再始動できる。

## Problem / design rationale
予定との差に注意が固定されると、残り時間の再評価より「取り返す」「原因を考える」「今日はもうだめだ」という反応が先に起きやすい。本アプリは原因分析や精密な再計画を増やさず、毎回同じ短い順序で「過去区間を切る → 残り時間を見る → 次の作業サイズを縮める → 長押しで開始を確定する」を反復する。狙いは計画精度ではなく、計画逸脱後の再始動手順を固定すること。

## Core interaction
1. 「ここまでを切る」で予定との差を画面外へ退場させる。
2. 残り時間を 10分以下 / 30分前後 / 60分以上 の3段階で選ぶ。
3. 残り時間に応じて 3分 / 10分 / 20分の着手サイズへ自動的に縮小する。
4. 2秒長押しして「始める」を身体操作として確定する。

注意対象を過去から残りへ移し、作業サイズを縮め、開始を身体操作で確定する一連の操作そのものを再始動の練習にする。

## First 10 seconds
最初の画面で「ここまでを切る → 残りを見る → 1個だけ始める」と全手順が見える。開始後すぐに、崩れた予定を表すカードを切る操作へ入る。

## Success condition
ユーザーが残り時間を選び、提案された小さい着手サイズを確認し、2秒長押しを完了して再始動を確定する。

## Uniqueness
予定や余力を整理する一般的なツールではなく、「計画が崩れた直後」という失速ポイントに限定し、過去区間の切断から開始確定までを30秒の固定手順として反復する。

## Repeat-use strategy
再始動を完了した実回数だけをローカル保存し、当日回数と直近7日回数を表示する。「崩れても戻れた」という実際の再始動経験の証拠として使い、同じ失速が起きるたびに同じ30秒手順を再利用できる。
