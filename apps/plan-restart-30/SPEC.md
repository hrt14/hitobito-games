# 予定が崩れたら30秒 — SPEC

## Exact use moment
予定どおりに仕事が進まず、想定より長い時間を使ってしまった直後に、残りの仕事へ移る気力が落ちている人が開き、30秒以内に「失った時間」ではなく「残っている時間」へ注意を戻し、次の小さな一手を始められる状態にする。

## Central benefit
予定が崩れた後でも、やる気の回復を待たずに自然と次の一手へ再始動できる。

## Why the problem occurs / design rationale
予定との差に注意が固定されると、残り時間の再評価よりも「取り返す」「原因を考える」「今日はもうだめだ」といった反応が先に起きやすい。そこで本アプリは、原因分析や再計画を増やさず、毎回同じ短い順序で「過去区間を切る → 残り時間を見る → 次の作業サイズを縮める → 長押しで開始を確定する」を反復する。狙いは計画精度ではなく、計画逸脱後の再始動手順を固定すること。

## Core interaction and why it matches the target skill
1. 「ここまでを切る」で予定との差を画面外へ退場させる。
2. 残り時間を 10分以下 / 30分前後 / 60分以上 の3段階で素早く選ぶ。
3. 残り時間に応じて 3分 / 10分 / 20分の着手サイズへ自動的に縮小する。
4. 2秒長押しして「始める」を身体操作として確定する。

単なる選択問題ではなく、注意対象を過去から残りへ移し、作業サイズを縮め、開始を身体操作で確定する一連の操作そのものが再始動の練習になる。

## First-10-second experience
最初の画面で「ここまでを切る → 残りを見る → 1個だけ始める」と全手順が見える。開始後すぐに、崩れた予定を表すカードを切る操作へ入る。

## Success condition
ユーザーが残り時間を選び、提案された小さい着手サイズを確認し、2秒長押しを完了して再始動を確定する。

## Uniqueness vs existing LEVEL UP apps
予定や余力を整理するアプリではなく、「計画が崩れた直後」という特定の失速ポイントに対して、過去区間の切断から開始確定までを30秒の固定手順として反復し、再始動そのものを習慣化する点が独立した役割。

## Repeat-use strategy
再始動を完了した実回数だけをローカル保存し、当日回数と直近7日回数を表示する。活動量を装飾的に増やすのではなく、「崩れても戻れた」という実際の再始動経験の証拠として使う。同じ失速が起きるたびに同じ30秒手順を使える。
