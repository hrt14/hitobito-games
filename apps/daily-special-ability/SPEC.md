# あなたの日常特殊能力診断 — Product Spec

## Exact use moment
自分では「普通にやっているだけ」で強みを言語化しにくい人が、友人との雑談やSNSで「自分には何があるんだろう」と思った瞬間に開き、2分後には自分の行動傾向を覚えやすい能力名として持ち帰り、見せたり比べたりできる状態になる。

## Central benefit
普段の行動に埋もれている強みを、具体的で覚えやすく、人に見せたくなる「日常特殊能力名」に変換する。

## Problem / design rationale
「強みを教えて」と直接聞くと、自己評価・理想像・社会的に良さそうな回答に引っ張られやすく、抽象語（コミュ力、観察力、行動力）では結果も記憶に残りにくい。本アプリでは「会議の違和感」「締切前」「初対面」「予定崩壊」など具体的な12場面を2択で通過し、選択を6つの行動傾向へ加点する。結果は医学・心理検査ではなく、回答傾向を遊びとして再命名したものだと明示する。

6つの行動傾向:
- DETECT: 小さなズレ・違和感を拾う
- BURST: 短時間で出力を上げる
- SOCIAL: 相手や場の緊張をほどく
- CONNECT: 断片情報をつなげて構造化する
- ADAPT: 不測事態で組み替える
- SIMPLIFY: 面倒を減らす最短経路をつくる

## Core interaction
画面中央の「能力スキャナー」に日常シーンが1つずつ表示され、ユーザーは“より自分に近い反応”を左右どちらかへタップする。タップ直後に対応する能力シグナルが一瞬点灯し、スキャンリングが進む。12回答後、上位2傾向の組み合わせから能力名・発動条件・副能力を生成する。

この操作自体が、抽象的な自己評価ではなく「自分は現実の場面でどちらに動くか」を短時間で見直す行為になる。正解・不正解は作らない。

## First 10 seconds
初回画面に以下だけを大きく見せる。
- タイトル「あなたの日常特殊能力診断」
- 約束「普通の強みを、妙にカッコいい能力名にする。」
- 実例3つ「違和感早期検知 / 締切直前超加速 / 初対面警戒解除」
- CTA「12問で能力をスキャン」
- 「入力なし・約2分」

開始後は1問目と2つの大きな選択肢を即表示し、説明チュートリアルを挟まない。

## Success condition
完了時にユーザーが、
1. 自分の能力名を1つ覚えられる
2. その能力が発動しやすい現実場面を1文で説明できる
3. 結果カードを保存・共有、またはもう一度回答して別の結果を見たくなる
のうち最低2つを自然に行えること。

## Uniqueness
他のLEVEL UP診断が「悩みの分類」「成功傾向」「能力値」などを返すのに対し、本アプリは“普通すぎて本人が価値として認識していない行動”を、上位2傾向の組み合わせで固有の能力名へ再命名し、見せたくなる成果物にする点が中心体験である。

## Repeat-use strategy
一回でも完結するが、前回結果をlocalStorageへ保存し、再訪時に「前回の能力を見る」を表示する。再診断時には前回結果との差分を見せる。回答する日の状況で結果が変わるため、友人と比べた後や時間を置いて再訪する理由がある。結果カードはCanvasで1080×1350画像として保存でき、Web Share API対応環境では1タップ共有できる。

## Title rationale
- Main user benefit/motive: 自分だけの目立つ能力名を得て、見せたい・比べたいという好奇心と自己表現。
- Why this title is direct and specific: 「特殊能力診断」だけではファンタジー能力診断と区別しにくいため、「日常」を入れて“普通の強みが対象”だと明示した。
- How it matches the actual app: 全12問が仕事・友人・初対面・予定変更・日常作業など現実場面で、結果も実際の行動傾向を能力名へ変換する。
- Market/uniqueness checks actually performed (if any): 2026-08-30にWeb検索で「あなたの特殊能力診断」という既存の診断・ゲームが複数存在することを確認。完全同名を避け、「あなたの日常特殊能力診断」を採用した。検索確認は名称の不存在や商標非侵害を保証する法的クリアランスではない。

## Safety / interpretation boundary
- 心理検査、適性検査、能力測定、採用評価として扱わない。
- 「上位◯%」「IQ相当」など、実データのない人口比較は表示しない。
- 6つのバーは回答内での相対傾向を可視化するだけで、客観能力値とは表現しない。
