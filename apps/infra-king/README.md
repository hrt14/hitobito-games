# インフラ王 / INFRA KING

ファミコン風のシンプルな都市育成ゲームです。

プレイヤーが設置するのは道路・駅・発電所・浄水場・公園だけ。時間を進めると、インフラ条件に応じて住宅・商店・工場が自動で建ち、街が成長します。

## v0.1

- 14×14マップ
- 道路、駅、発電所、浄水場、公園
- 1年ごとの自動発展
- 住宅、商店、工場、団地、高層化
- 人口、税収、資金
- ブラウザ内の自動セーブ
- スマートフォン対応

静的なHTML/CSS/JavaScriptのみで動作します。
