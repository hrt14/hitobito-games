# TODO RAID — Product Spec

## Core promise
現実のタスクを終わらせるほど、RPGの世界が進む。アプリ内の滞在ではなく、現実の完了行動だけを主要な報酬源にする。

## Before → After
- Before: やることは分かっているが、着手や完了に感情的な勢いが出ない。
- After: まず1個を「敵への一撃」として終わらせ、その勢いでもう1個へ進める。

## Core loop
1. 今日やることをクエスト化
2. 完了ボタンを押す
3. ボスへダメージ + XP + GOLD + 召喚石
4. 3タスクで宝箱
5. ボス撃破で新エリア
6. 召喚石5個で仲間獲得
7. 次の現実タスクへ

## Human KPI
- タスク登録後の完了率
- 1セッションで2個目のタスクまで完了した率
- 大タスクの完了率

## Guardrails
- 課金ガチャなし
- 未達による資産没収なし
- ストリーク断絶ペナルティなし
- アプリ滞在時間を報酬条件にしない
- 現実のタスク完了が最重要入力
