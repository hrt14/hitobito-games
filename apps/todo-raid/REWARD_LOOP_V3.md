# TODO RAID — Reward Loop v3

## 目的
完了だけでなく、ToDoで心理的コストが高い「登録」と「着手」にも即時報酬を置く。

## 三段報酬
1. 登録 — QUEST CREATED
   - その場で +20 XP / +10 GOLD
   - 1日5件まで
   - 大きな報酬演出
   - CTAを「今すぐ始める」にして着手へ直結
2. 着手 — FIRST STRIKE
   - タスクを「攻略中」に変更
   - +10 XP / ボスへ -25 HP の先制攻撃
   - 1日5件まで
   - ボスは着手だけでは撃破できずHP1で止まる
3. 完了 — FINISH
   - 既存の難易度別XP/GOLD/ボスダメージ/召喚石/宝箱進行

## ガードレール
- 登録/着手の恒久報酬は各1日5回まで。削除→再登録の報酬稼ぎを抑える。
- 5回を超えても登録・着手の演出と状態変化は残す。
- 着手だけでボス撃破はできない。最後の一撃は完了に残す。
- 未達ペナルティなし。

## 最初の30秒
タスク追加 → 大報酬 → 「今すぐ始める」 → 先制攻撃 → 攻略中、まで到達できること。
