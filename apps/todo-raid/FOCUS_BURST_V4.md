# TODO RAID — Focus Burst V4

## 目的
タスク追加・着手・完了の間にある「継続」をゲーム上の出来事にする。

## 4段階ループ
1. 追加: QUEST CREATED (+20 XP / +10 GOLD、1日5件まで)
2. 着手: FIRST STRIKE (+10 XP / -25 HP、1日5件まで)
3. 5分継続: FOCUS BURST (+15 XP / -35 HP、1タスク1回・1日5件まで)
4. 完了: 難易度別XP / GOLD / 召喚石 / ボスダメージ / 宝箱進行

## 5分継続判定
- `startedAt` から5分経過した未完了タスクを対象にする。
- タブを閉じたり別アプリへ移動しても、戻った時にタイムスタンプ差分で判定する。
- 画面を開いたままなら1秒ごとに残り時間を更新する。
- 報酬は1タスクにつき1回のみ。
- 5分継続だけではボスを撃破せず、HP1で止める。
- 1日5件まで報酬対象にし、水増しを抑える。

## 体験
攻略中タスクには `FOCUS 04:32` のようなカウントダウンを表示。5分到達時に FOCUS BURST の報酬演出を出し、「5分続いた。ここから本番。」と伝える。
