# 人生、あと何回？ — Product Spec

## Exact use moment
毎日を無限にあるように使ってしまい、今日をどう使うかの実感が薄い人が、数十秒で「この季節・休日・大切な人との時間は有限」と具体的な回数に置き換え、今日ひとつ大切にするものを決める。

## Central benefit
抽象的な「人生は短い」を、今の自分に関係する具体的な残り回数へ変え、今日の優先順位を1つだけ明確にする。

## Problem / design rationale
年数は大きく抽象的で、有限性を感覚として捉えにくい。一方「春はあと約40回」「親と会うのは今の頻度なら約120回」のような反復イベントの回数は具体的に想像しやすい。本アプリは寿命予測をせず、ユーザーが選ぶ「何歳までと仮定するか」と現在の頻度だけで計算する。

## Core interaction
年齢と仮定年齢をスライダーで動かすと、画面上の残り回数がリアルタイムで減る。親と会う頻度もタップで変更する。最後に「今日、大切にする1回」を4項目からタップして固定する。数字を読むだけでなく、自分で時間軸を縮め、1回を選ぶ操作そのものが有限性の理解になる。

## First 10 seconds
最初の画面に「90歳までと仮定すると、あと何回？」と年齢スライダー、その直下に大きな「春 あと50回」を表示する。長い説明なしでスライダーを触れば全数値が変わる。

## Success condition
終了時に、ユーザーが「今日、大切にする1回」を1つ選び、その項目を中心にした共有可能な結果カードが生成される。

## Uniqueness
既存の100-turnsが有限な人生で行動配分を選ぶゲームなのに対し、本アプリは現実の季節・休日・人と会う頻度を具体的な残り回数へ変換し、共有可能な個人結果にする点が独自。

## Repeat-use strategy
基本は強い一回体験だが、誕生日・季節の変わり目・家族との会い方が変わった時に再計算する意味がある。端末に前回の選択と実行回数を保存し、再訪時に「前回から1回使った」を見せる。

## Title rationale
- Main user benefit/motive: 好奇心を満たす / 時間を大切にする
- Why this title is direct and specific: 「人生の出来事があと何回あるか」をそのまま質問形で表す。
- How it matches the actual app: 実際に残りの春・土曜日・親に会う回数などを計算して表示する。
- Market/uniqueness checks actually performed (if any): 今回は外部市場・商標調査は未実施。アプリ内容との一致を優先した仮採用。
