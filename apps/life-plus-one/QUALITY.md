# LIFE +1 — quality checklist

- 10秒以内に「今日あったことを書くアプリ」と分かる。
- 入力→結果まで30〜60秒を目安にする。
- 「素晴らしい」「成長ですね」だけのフィードバックにしない。
- AIが失敗・休息・嫌な出来事を勝手に美談へ変えない。
- 「何もしてない」だけなら無理に+1を作らない。
- AIが使えなくても画面が止まらず、簡易判定で完走できる。
- +1の保存はユーザーが明示的に押したときだけ行う。
- スマホで片手操作できる。主要ボタンは44px以上。
- 入力は送信失敗で消えない。
- APIキーはソース・HTML・JavaScriptに存在しない。
- 履歴削除ができる。
- ストリーク、未記録ペナルティ、人生スコア化を入れない。

## Test inputs
1. `今日は5分だけ英語をやった` → progress/knowledge系。過大評価しない。
2. `何もしてない` → found:false。
3. `仕事で失敗した` → failure_data。成功扱いしない。
4. `疲れていたので寝た` → rest。断定的な健康効果を言わない。
5. `子どもと遊んだ` → relationship。
6. `気が重かったけどメールを1通返した` → courage。
7. `会議後20分歩いたら少し頭が戻った` → recovery。
