# 人生RPGステータス — Product Spec

## Exact use moment
SNSや友人との会話で「今の自分ってどんなキャラなんだろう」と遊び半分で自己分析したくなった人が、文字入力なしの約1分で回答し、見せたくなる1枚のRPGステータスカードを得る。

## Central benefit
今の自分の特徴を、説明しやすく共有しやすい「RPGキャラクター」として1枚に可視化する。

## Problem / design rationale
普通の性格診断は結果文が長く、結果が抽象的で、スクリーンショットしても他人が一目で理解しにくい。そこで、RPGで意味が直感的な LV / HP / 5能力 / 職業 / 二つ名 / 特殊能力へ変換し、結果そのものを会話のきっかけにする。数値は科学的尺度ではなく、回答をゲーム表現へ換算したものと明示する。

## Core interaction
12の具体的な行動・状態について、5段階をタップする。回答が終わると、行動力・知力・社交力・回復力・運・残りHPへ換算され、組み合わせから職業・二つ名・特殊能力が生成される。操作は診断に必要な自己評価そのもので、文字入力は不要。

## First 10 seconds
最初の画面で「人生RPGステータス」と結果カード見本（LV.78 / 暴走する軍師 / 締切直前覚醒 / 5能力 / 残りHP）を見せる。「自分のステータスを見る」を押せば即Q1。説明書は置かない。

## Success condition
約1分で結果カードまで到達し、「自分っぽい／人に見せたい」と感じられる具体的な職業・特殊能力・能力値が1画面に収まり、PNG画像として共有できる。

## Uniqueness
既存LEVEL UPの訓練アプリは特定の思考・行動を鍛えるが、このアプリは「現在の自分を複数軸でキャラクター化し、共有可能な1枚にする」ことが中心価値で代替できない。

## Repeat-use strategy
残りHP・回復力など「今の状態」で変わる軸を含め、前回結果を端末に保存する。再診断時は各能力の前回差分とHP差分を表示し、「今どう変わったか」を見る理由を作る。

## Title rationale
- Main user benefit/motive: 好奇心を満たす / 目立つ / 楽しむ
- Why this title is direct and specific: 「人生」「RPG」「ステータス」で、何をRPG化して何が出るかを短く表す。
- How it matches the actual app: 結果が実際にLV・HP・能力値・職業・特殊能力のRPGステータスカードになる。
- Market/uniqueness checks actually performed (if any): 今回は外部市場検索をタイトル決定条件にはしていない。依頼名を中心にし、内容一致を優先した。
