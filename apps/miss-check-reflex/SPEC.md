# 同じミスを繰り返さない 3秒確認 — Product Spec

## Exact use moment
右左、コピー元/先、日付、宛先、税込/税抜などを「分かったつもり」で確認せず進め、同じ種類の取り違えを仕事で繰り返している人が、次の実作業の直前に30秒だけ開く。終了時には「すぐ押す」前に短い確認動作を挟む具体的な1ルールを持ち帰れる状態にする。

## Central benefit
実行直前に「止まる → 対象を確認する → 実行する」の順番を反射として挟み、思い込み由来の取り違えを減らすための具体的な確認動作を作る。

## Problem / design rationale
対象の知識不足ではなく、見慣れた作業で「分かった」と判断した瞬間に確認工程を飛ばしてしまうことを主対象にする。アプリは注意力や性格を診断せず、実行前に短い摩擦を意図的に作る。

設計根拠として、指差し呼称の安全教育では、対象を指して呼称する動作が単なる黙視よりエラー抑制に使われている。LEVEL UPでは職場安全手順をそのまま一般化するのではなく、「記憶に頼らず、行動直前に確認動作を挟む」という設計原理だけを、日常業務の取り違え防止へ転用する。

## Core interaction
各ラウンドで似た2択が見えていても、ユーザーはすぐ選べない。中央の「確認」を0.7秒長押しすると初めて選択肢が有効になる。その後、対象を指す・声に出す・選ぶ順序を画面で促す。

この操作自体が、現実で身につけたい「分かった瞬間に止まる → 表示を見る → 実行する」を身体的に再現する。知識クイズや3択診断にはしない。

## First 10 seconds
トップ画面で「同じミスを繰り返さない 3秒確認」「0.7秒止まる反射を30秒で練習」と表示し、「自分のミスを選ぶ」ボタンを1つだけ主操作として見せる。次画面で右左・元先・日付・宛先・税込税抜・その他から1つ選び、すぐトレーニングへ入る。

## Success condition
6回すべてで確認長押しを挟み、先走り回数と確認後のミスが減ること。終了画面では確認反射スコア、先走り回数、確認後のミス、実務に持ち帰る1ルールを表示する。

## Uniqueness
既存の先延ばし・感情整理・判断診断系LEVEL UPでは代替できない。「誤操作の直前に確認摩擦を入れる」という操作そのものを反射化し、実務の取り違えに直接持ち帰る点が固有。

## Repeat-use strategy
実際にミスを起こしやすい作業の直前に30秒使う用途。前回の確認反射スコア・先走り回数をlocalStorageへ保存し、同じカテゴリを再訓練したとき改善を比較できる。繰り返し自体が目的ではなく、現実の高リスク作業の直前に再利用する理由を作る。

## Title rationale
- Main user benefit/motive: 怖れから逃れる / 時間損失を減らす / 仕事の再発ミスを減らす。
- Why this title is direct and specific: 「同じミスを繰り返さない」と結果を先に示し、「3秒確認」で方法の短さを伝える。
- How it matches the actual app: 30秒の練習内で、実行前に0.7秒の確認動作を繰り返す。
- Market/uniqueness checks actually performed (if any): タイトルの市場重複調査は未実施。意味の明確さを優先し、独自性を断定しない。
