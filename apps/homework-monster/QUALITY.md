# 宿題モンスター — 固有品質基準

## 主役

主役は **プレイヤーの手で小さくされた「ひとくち」と、それを食べて目の前で育つモンスター**。

宿題の総量でも、こなした問題数でもない。「大きすぎて食べられなかったものが、食べられる大きさになった」という一手ごとの変化が主役である。

## コアループ

1. 宿題を選ぶ
2. モンスターの口に入る大きさまで、プレイヤーが切り分ける
3. そのひとくちだけ、実際にやる
4. できた宿題が食べ物に変わる
5. モンスターに食べさせる
6. その場で外見・反応・機能が変わる
7. もうひとくち、または今日はここまで

できなかったときは 4 へ進まず、「まだ大きい」→ さらに小さい候補 → 3 へ戻る。この回り道も正規の成功として扱う。

## 絶対に崩さない設計原則

仕様書の原則A〜Fをそのまま実装の制約とする。

- **A：最初は本当に1問で育つ。** 最初の10口は1口ごとに必ず別の変化が起きる（`game/growthRules.js` の `MILESTONES`）。経験値バーが伸びるだけの回は作らない。
- **B：1問が無理なら、さらに小さくする。** 最小単位は「机に座る」「鉛筆を持つ」まで下げられる。候補が尽きたら自由入力で自分の言葉のひとくちを作れる。
- **C：できなかった原因を努力不足にしない。** 未完了時の解釈は「このひとくちは、まだ少し大きかったみたい。」に固定する。失敗音・怒る演出・記録の途切れを作らない。
- **D：成長してもノルマを増やさない。** 進化後もデフォルトは常に「ひとくち」。前回たくさんできたことを理由に次回の初期値を大きくしない。
- **E：休んでも失わない。** 連続日数を持たず、表示もしない。数字は増えるだけで減らない。復帰時は「おかえり。今日はどのひとくちにする？」で迎える。
- **F：中心画面は1画面で完結。** コア操作画面は 390×844px で縦スクロールしない。主要選択肢は最大3つ。

## 初見10秒

画面を見ただけで以下が伝わること。

- 目の前の生き物は、宿題を食べて育つ
- いま出ている食べ物は、口に対して明らかに大きすぎる
- 下のボタンを押すと、その大きさが変わる

宿題フードはモンスターと同じ地面に並べて描き、大きさの差そのものを説明文なしで見せる。

## 視覚変化

数字ではなく、画面の出来事で成長を見せる。

- 0口目は暗い部屋。最初のひとくちを食べさせた瞬間に部屋の色が戻る。
- 1口＝卵にヒビと目、2口＝誕生、3口＝体色、4口＝名前、5口＝わざ、6口＝頭のパーツ、7口＝部屋、8口＝模様、9口＝あそぶ、10口＝進化。
- 教科ごとに食べ物の形と色を変える（数字クッキー／ことばの実／アルファベットキャンディ／発光キノコ／世界のかけら／なぞのごはん）。
- いちばん多く食べた教科が、そのまま体の模様になる。
- 切り分けるほど、モンスターの表情が 困る → 期待 → 笑顔 に変わる。

## 操作

主要操作はタップ。給餌だけドラッグもできるが、必ずタップとキーボードでも完了できる。

- 長押し・複雑なスワイプは使わない
- タップ領域は最低44px、主要ボタンは56px以上
- ドラッグ必須の操作を作らない

## テンポ

- 初回起動から最初のひとくち完了まで90秒以内（実測 約10秒）
- 1サイクルは、選ぶ10〜20秒 → 実際の宿題 数秒〜5分 → 給餌と成長 5〜10秒
- タイマーは補助。使わなくても1問単位で遊べる。時間切れでも、できなかった扱いには絶対にしない

## 言葉

- `game/copy.js` に文言を集約し、禁止コピーの混入を防ぐ
- 使わない言葉：サボる／ノルマ／連続記録／お腹をすかせている／頑張りが足りない／失敗／まだ終わっていません／今日の分を全部終わらせよう

## 記録

- 増える数字だけを持つ：たべさせたひとくち、はじめた回数、ちいさくできた数、休んだあと戻れた数
- 連続日数、達成率、未達バッジは作らない
- テストプレイ用イベントは端末内のみ。自由入力の本文は記録しない

## 完了条件

- [x] 初回起動から90秒以内に最初のひとくちを開始できる
- [x] 1口ごとに、目に見えるモンスターの変化がある（最初の10口）

- [x] 最小で「机に座る」「ノートを開く」まで選べる
- [x] 小さな着手行動でも食べ物になり、モンスターが喜ぶ
- [x] 進化後も1問や着手行動を自由に選べる
- [x] 休んでも成長やアイテムが失われない
- [x] ブラウザ更新で進行中の状態が戻る（タイマー切れを未完了扱いにしない）
- [x] コア画面が390×844pxで縦スクロールしない

## 仕様書との差分

- 実装はReact+Viteではなく、リポジトリ標準に合わせた素のESモジュール構成（仕様 14.1 の「既存リポジトリに別の標準構成がある場合は、その構成に合わせてよい」に従う）。成長ルール・分解テンプレートは `game/` にありUIから分離されている。
- S01タイトル画面は初回のみ表示する。2回目以降はホームへ直行し、「おかえり。今日はどのひとくちにする？」で迎える（最初のひとくちまでのタップ数を増やさないため）。
