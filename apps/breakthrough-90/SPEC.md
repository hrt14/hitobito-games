# 八方塞がりで動けないときの90秒｜次の一手を取り戻す — Product Spec

## Exact use moment
新しい挑戦や仕事が思うように進まず、「もう無理かも」「次に何をすればいいか分からない」と八方塞がりに感じている人が、その場で90秒使い、問題そのものの解決ではなく「次の15分にやる一手」が見えている状態へ戻る。

## Central benefit
詰んだ感覚から抜けて、次の15分の一手を決められる。

## Problem / design rationale
八方塞がりのときは、目の前の問題が人生全体と同じ大きさに感じられ、他人の成果や速度を比較材料に足し、さらに「自信が出るまで動けない」という順番になりやすい。そこで、(1)時間軸を10年まで引く、(2)他人比較を物理的に外す、(3)「いずれ突破する」を先に置いて行動を15分へ縮める、という順で認知負荷を下げる。

## Core interaction
- 時間軸スライダーを右へ動かすほど、問題カードが画面上で小さくなる。
- 「同業の売上」「SNSの成功談」などの比較対象をタップで一つずつ消し、最後に「昨日の自分」を出す。
- 7種類の行動タイプから一つ選び、15分でできる具体的行動を入力する。
- タッチでは1秒長押し、キーボードではEnter/Spaceで「この一手に決める」。
- 開始前後の詰まり感を同じ1〜10尺度で測り、結果カードで変化と次の一手を可視化する。

操作そのものが「引く → 比較を外す → 一手に絞る」を再現するため、説明を読むだけのアプリではない。

## First 10 seconds
最初の画面で「詰んだ気分を、次の一手に戻す。」と目的を明示し、その直下に今の問題と詰まり感を入力する。長い説明やチュートリアルを挟まず、問題を書けばすぐ開始できる。

## Success condition
セッション終了時に、ユーザーが「次の15分でやること」を1つ具体化し、BREAKTHROUGH CARDでその一手を確認できる。詰まり感のBefore/Afterも表示するが、数値低下は必須条件にしない。

## Uniqueness
「10年視点だけ」「昨日の自分との比較だけ」「自信を先に置くことだけ」を単独で鍛えるのではなく、八方塞がりの瞬間に3つを連続操作して“次の15分の実行”まで接続する即時リカバリー用途に特化している。

## Repeat-use strategy
問題が変わるたびに同じ90秒フローを使える。前回の「次の一手」を端末内に保存して最初の画面に出し、再訪時に「前回は何を動かしたか」を思い出せるようにする。

## Title rationale
- Main user benefit/motive: 怖れ・停滞感から抜け、すぐ次の一手を得る。
- Why this title is direct and specific: 「八方塞がりで動けないとき」という利用場面、「90秒」という手軽さ、「次の一手を取り戻す」という結果をそのまま書いている。
- How it matches the actual app: 4ステップを短時間で進め、最後に15分の具体行動を確定するため内容と一致する。
- Market/uniqueness checks actually performed (if any): 2026-09-02にWeb検索で「八方塞がり」「次の一手」「動けない」の組み合わせを確認。一般的な表現としての使用はあるが、同一のアプリ名は確認できず、誇張語や無意味な言葉遊びは避けた。Amazon検索では同一タイトルの明確な書籍結果は確認できなかった。
