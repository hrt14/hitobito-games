# LEVEL UP「期待しない」実装仕様

## 目的
人への期待をゼロにするのではなく、「相手がこうするはず」を検出し、自分でできる行動（聞く・頼む・確認する・備える・手放す）へ戻す反射を反復する。

## コアループ
1. 日常イベントを読む
2. 頭の中に生じた「期待」を見る
3. 3択から最も強い「自分側」の行動を選ぶ
4. 即時フィードバック
5. CONTROL / EXPECTATION と赤い糸が変化
6. 15問の通常問題 + 3問のBOSS
7. 選択履歴から期待パターンを返す

## 主役
中央のYOUと、YOUから他人へ伸びる赤い「期待の糸」。
正解時は糸が切れ、YOUがME側へ戻る。誤答時は糸が増える。

## スコアリング
- 最適解: 100 + コンボボーナス
- 部分解: 45
- 期待側: 0
- 最終表示は1800点満点へ正規化

## 期待パターン
- 察して型
- 普通・当然型
- お返し型
- 結果型
- 自分なら型
- やってくれるはず型
- こうあるべき型

## 品質条件
- 開始10秒以内に「期待を自分側の行動へ戻すゲーム」と分かる
- タップ直後に視覚・音・振動のいずれかで反応
- 通常プレイ3〜5分
- スマホ幅320px以上で主要操作が成立
- 進行不能なし
- 18問完走後に必ずレポートへ到達
- 音OFF、reduced-motionに対応
- localStorageにはベストスコアのみ保存

## デプロイ
完全な静的ファイル。`apps/expect-nothing/` をそのまま静的配信可能。ビルド工程・環境変数・外部APIは不要。
