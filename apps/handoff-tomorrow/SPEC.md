# 明日の自分に渡す — Product Spec

## Exact use moment
仕事を終えたいのに、未完了タスクが頭に残って「もう少しだけ」「忘れたら困る」とPCを閉じられない夜・退勤前に開く。

## Central benefit
未完了を今日中に終えるのではなく、**明日の最初の一手まで決めて、今日の脳から仕事を降ろす。**

## Core mechanic — HANDOFF BOX
1. 残っている仕事を1行1件で全部出す（最大10件）。
2. その中から「明日の最初の1件」を1つだけ選ぶ。
3. その1件について、明日最初に行う10秒レベルの物理行動を1文で決める。
4. 残りはすべてTOMORROW BOXへ封印する。
5. `引き継ぎ完了。今日は閉じる。` を表示。

最初の1件は1つだけ。2つ以上の「朝イチ」を作れない。

## Why game
未完了タスクを処理するのではなく、机の上から明日の箱へ移し、1枚だけ一番上に置く“引き継ぎゲーム”。操作そのものが仕事の切り離しになる。

## Persistence
同じ日なら引き継ぎ内容を復元。翌日は「昨日の引き継ぎ」として最初の1件を表示し、開始したら引き継ぎを消化済みにできる。

## Uniqueness
先延ばし対策ではない。仕事を始めるアプリでもない。**終業時に未完了を安全に明日へ移して、今日の仕事を終える**ことだけに特化する。

## Quality target
分かりやすさ9 / 役立ち度9 / 操作8 / 独自性9 / 継続性9。
