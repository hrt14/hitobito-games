# 60秒で使い分ける 5つの知能 — SPEC

## Product name
60秒で使い分ける 5つの知能

## Slug
`five-intelligences`

## 1. Single problem
IQだけを「頭の良さ」と見てしまい、日常の場面で感情・場・身体・つながりの知能を使う発想が出てこない。

## 2. Target moment
仕事や人間関係で「今は何を使えば突破できる？」と迷う人が、1分で5つの見方を体に入れる。

## 3. Desired change
プレイ後、現実の場面で「これはIQではなくEQ」「ここはNQで人を頼ろう」のように、5つの知能を道具として切り替えられる。

## 4. Core benefit
偏差値では見えない5つの知能を、説明を読むのではなく場面判断で使い分けられるようにする。

## 5. Why this must be a game
状況カードを見た瞬間に、EQ / SQ / IQ / BKQ / NQ の5スイッチから「最初に使う1つ」を押す。操作そのものが、知能を切り替える反射の練習になる。

## 6. Primary interaction
5つの知能スイッチをタップして、場面を突破する。

## 7. Session flow
1. 10秒以内で意味がわかるタイトル画面
2. 5種類×2問、合計10シーンをランダム順で出題
3. 回答直後に「なぜその知能か」を1〜2文で返す
4. 正解すると該当する「窓」が点灯する
5. 終了時に正答率、5つの窓の点灯数、分野別の見抜きやすさを表示
6. 次に鍛える1つと、現実で使える一言を返す
7. 再挑戦で各分野3問のうち別問題も混ざる

## 8. Important framing
- 心理検査・知能検査・性格診断ではない。
- 動画で紹介された5つの知能の整理を題材にした学習ゲーム。
- 結果は「能力の高さ」ではなく、このゲーム内での「場面から知能を見抜く力」。
- Harvard Study of Adult Development については、良い人間関係と健康・幸福の関連を示す公式情報の範囲だけを参考表示する。

## 9. Content model
- EQ: 感情を認識し、反応する前に扱う
- SQ: 人と人の間、場の流れを読む・整える
- IQ: 情報を分解し、筋道を立てて問題を解く
- BKQ: 身体・手先・感覚を使って身につける
- NQ: 人とのつながりを作り、支え合い・機会へ接続する

## 10. Quality gate
- 分かりやすさ: 初見で「状況→5スイッチ」が理解できる
- 役立ち度: 各フィードバックが現実の最初の一手になる
- 操作の気持ちよさ: 正解時に窓が点灯し、コンボが伸びる
- 独自性: 5種類の知能そのものを物理的なスイッチとして切り替える
- 継続性: 毎回各分野3問から2問を選ぶため、再挑戦で組み合わせが変わる
