# 未出場 — NO EXIT RECORD / SPEC

## コンセプト
一枚の黒い乗車券から始まる、5〜8分の地下鉄記憶ミステリー。
プレイヤーは終電後の改札で「出場記録のない乗車券」を拾い、存在しない終電を乗り継いで、切符の持ち主と未出場記録の正体を解く。

## コア体験
- 乗車券そのものがUI兼ヒントになる。
- 駅名標・時計・窓の反射・ロッカーなど、地下鉄空間を直接観察して解く。
- 間違えても即ゲームオーバーにせず「同じ場所へ戻る」ループ演出で物語と失敗を統合する。
- 最後に「切符の持ち主 = プレイヤー」という叙述的な反転を置く。

## 進行
1. 黒い乗車券をスワイプして改札を通す。
2. 霞町ホーム：駅番号17と時刻07から10番線を導く。
3. 車内：窓の反射だけが正しいというルールから中央ドアを選ぶ。
4. 忘れもの保管室：刻印10 + 03 = 13でロッカー13を開ける。
5. 駅員日誌から「乗客1名・出場記録なし」を知る。
6. 最後の改札で切符の持ち主を「あなた」と答える。
7. 地上の朝へ出る。

## モバイル操作
- タップ中心。
- 開始時のみ「乗車券を上へスワイプ」という身体的な導入を入れる。
- 振動対応端末では改札・正解・失敗で短いハプティクス。
- Web Audioで電子音を合成し、外部音源なしで軽量化。

## 保存
localStorageに章・ループ回数・刻印・調査済み手がかり・サウンド設定・クリア状態を保存。
