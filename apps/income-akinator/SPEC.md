# 年収アキネーター — Product Spec

## Exact use moment
自分や友人の「仕事と年収を、質問だけでどこまで当てられる？」を遊びとして試したい人が、職業名・年収を入力せず、はい／いいえだけで推理される驚きを楽しむときに開く。終了時には「意外と当たった／そこじゃない」と話題にできる具体的な予想が残る。

## Central benefit
入力なしの二択だけで、自分の職業と年収を推理される短い驚きと会話のきっかけを得る。

## Problem / design rationale
普通の年収診断は職種・年齢・年収帯などを本人に入力させるため、「当てられた」感覚が弱い。本アプリは本人が答えそのものを入力せず、仕事内容・働き方・責任範囲に関する二択から候補を逐次絞り込む。年収値は公的統計の判定ではなく、ゲーム内候補モデルのヒューリスティックとして扱い、事実の給与水準であるかのようには表示しない。

## Core interaction
ユーザーは毎問「はい」「いいえ」のどちらかだけをタップする。回答のたびに職種候補を再採点し、現在の上位候補を最も分けやすい未回答質問を次に選ぶ。候補数・上位候補表示・スキャン演出が回答直後に変化するため、「答える → 推理が進む」が操作そのものとして見える。

## First 10 seconds
タイトル「年収アキネーター」、説明「はい・いいえだけ。12問以内に職業と年収を推理」、開始ボタンが1画面に収まる。開始後は大きな質問カードと同サイズの「はい／いいえ」ボタンだけが主操作として見える。長いチュートリアルは置かない。

## Success condition
10〜12問以内に、職業予想1つ・ゲーム内推定年収・推定レンジ・推理確度・決め手・次点候補が表示され、ユーザーが結果を共有または別の人でもう一度試せる。

## Uniqueness
既存LEVEL UPの職業適性・興味診断は「向いている方向を知る」ことが目的だが、本アプリは本人が職業や年収を入力しないままAI風の絞り込みで「現在の職業と年収を当てる」推理ゲームであり、結果の驚きと共有が中心体験になる。

## Repeat-use strategy
一人で毎日使う習慣アプリではなく、友人・家族・同僚に端末を渡して「当たるか試す」反復を主な再利用理由にする。前回の予想を端末内に保存し、再挑戦時に比較できる。

## Title rationale
- Main user benefit/motive: 好奇心を満たす／楽しむ／自分を見抜かれる驚きを得る。
- Why this title is direct and specific: 「年収」と「アキネーター」で、年収を質問から当てる推理ゲームだと短く伝わる。
- How it matches the actual app: 実際に二択質問を分岐させ、職業と年収を最後に予想する。
- Market/uniqueness checks actually performed (if any): 2026-08-27時点でWeb上の完全一致タイトルを簡易検索。完全一致の明確な既存アプリは確認できなかった。ただし独占性・商標非侵害を保証する調査ではない。
