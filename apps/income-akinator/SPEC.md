# 年収アキネーター — Product Spec

## Exact use moment
自分の働き方が外からどう見えるかを試してみたい人が、休憩中や友人との会話中にスマホで開き、文字入力なしの「はい / いいえ」だけで職業と年収を推理され、最後に自分の仕事の特徴を一段言語化できる状態になる。

## Central benefit
仕事の特徴を質問への反応だけから推理される体験を通じて、自分の働き方を遊びながら客観視できる。

## Problem / design rationale
職業診断は自己申告で職種や年収を直接入力すると、診断ではなく入力内容の言い換えになりやすい。本作では職種名・年収を直接聞かず、雇用形態、働く場所、専門性、成果責任、管理範囲、顧客接点などの周辺特徴だけを「はい / いいえ」で聞き、候補職種の重みを毎回答更新する。推理の過程そのものを体験価値にする。

## Core interaction
1問ずつ大きな「はい / いいえ」をタップする。回答ごとに職業候補の確率を更新し、まだ候補が最も割れる質問を次に選ぶ。固定順のアンケートではなく、回答によって質問順が変わる。操作そのものが「自分の仕事は何によって特徴づけられているか」を切り分ける行為になる。

## First 10 seconds
画面上部に「年収アキネーター」、直下に「はい / いいえだけ。職業と年収を当てます。」を表示する。「推理スタート」を押すと即座に第1問が出て、入力欄や説明ページは出さない。

## Success condition
8〜12問の回答後に、推定職業1位、推定年収レンジ、ピンポイント予想、推理確度、決め手になった回答、次点候補が表示される。ユーザーが「なぜその予想になったか」を理解できること。

## Uniqueness
既存のLEVEL UP職業適性診断は「向いている仕事」を探すが、本作は現在の仕事を周辺特徴だけから当てにいく推理ゲームであり、目的も操作感も異なる。

## Repeat-use strategy
本人だけでなく家族・友人・同僚に端末を渡して再挑戦できる。「別の人で試す」を結果画面の主操作にし、回答履歴は端末内の今回セッションだけで扱う。

## Title rationale
- Main user benefit/motive: 好奇心 / 自己理解 / 遊び
- Why this title is direct and specific: 「年収」と「アキネーター」で、何を当てるゲームかが即座に伝わる。
- How it matches the actual app: はい / いいえの分岐質問で候補を絞り、職業と年収を推理する実体験そのものを表している。
- Market/uniqueness checks actually performed (if any): 今回は外部市場調査は行っていない。ユーザー指定タイトルを採用。
