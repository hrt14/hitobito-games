# 打ち手を増やせ。— Product Specification

## 1. Product promise
困った瞬間に「もっと考える」だけで固まらず、別方向の打ち手をすぐ複数思いつける状態を作るLEVEL UPトレーニング。

知識集ではなく、状況を見た瞬間に「情報を取る / 構造を考える / 知恵を借りる / 小さく試す / 条件を変える / 抱えない」の6つの棚を開く反射を鍛える。

## 2. Before / After
### Before
問題にぶつかると、自分が最初に思いついた1種類のやり方だけで考え続け、詰まる。

### After
問題にぶつかったとき「まだ開けていない棚はどれ？」と考え、少なくとも3方向の打ち手を出してから次の一手を決められる。

## 3. Target user
- 仕事で難題を渡されると何から考えるか分からなくなる人
- 分析・検索など得意な1パターンに偏りやすい人
- コンサル、企画、経営、改善、問題解決で打ち手の幅を増やしたい人
- AIに聞く以前に「何を調べる・誰に聞く・何を試すか」の選択肢を増やしたい人

## 4. Core model: 6 shelves / 24 tactics
### 情報を取る
人に聞く / ネットで調べる / データを見る / 現場を見る

### 構造を考える
分解する / 比較する / 原因を掘る / 逆から考える

### 知恵を借りる
AIに投げる / 専門家に聞く / 経験者を探す / 他業界を見る

### 小さく試す
5分だけ試す / 手作業でやる / 試作品を作る / A/Bで比べる

### 条件を変える
範囲を縮める / 順番を変える / 制約を置く / 目的を言い直す

### 抱えない
任せる / 仕組みにする / やめる / 保留条件を決める

## 5. Training loop
1. 現実にありそうな「困った」状況を1つ表示
2. 6棚から1候補ずつ、合計6枚を提示
3. 15秒以内に3方向を選ぶ
4. 選んだ3つ + 見落としやすい別棚1つの具体例を見る
5. 「まだ開けていない棚はどれ？」を反復
6. 6問後、正答率ではなく「どの棚を使ったか」を展開力スコアで確認

正解当てゲームにはしない。目的は、1本の最適解を当てることではなく、入口を複数持つこと。

## 6. Real-world mode
1. 本当に困っていることを1行入力
2. 6棚から1つずつ、合計6方向を提示
3. 使えそうな方向を1つ選ぶ
4. その戦術固有の問いを使い、現実でやる1手を1行にする
5. その1手をlocalStorageに保存して終了

実戦モードの成功は「読んだ」ではなく、現実の次の一手が1つ決まったこと。

## 7. UX principles
- 初見10秒以内に「打ち手の棚を増やすアプリ」と分かる
- 主要トレーニングは1画面1判断
- 6候補は必ず6棚から1枚ずつ出し、同じ棚への候補偏りを防ぐ
- 何も選ばず答えを見る場合はスコア加点しない
- スコアは正解率ではなく、実際に使った棚の広さを評価する
- 実戦モードの入力は候補引き直しでも失わない
- iPhone縦持ち・片手タップを優先
- ネットワークなしで主要体験が成立する

## 8. Human KPI
第一KPI：未出の困りごとに対して、30秒以内に3種類以上の「異なる棚」の打ち手を出せる率。

補助KPI：
- 6棚の想起率
- 1セッションで使用した棚数
- 実戦モードで「現実の1手」まで作れた率

現版では端末内の体験を優先し、KPIの外部送信は実装しない。

## 9. Data / privacy
- ベスト展開力スコア
- 実戦モードの困りごと
- 最後に決めた1手

上記はlocalStorageのみ。アプリ固有内容を外部送信しない。

## 10. Non-goals
- 問題に唯一の正解を出す
- AIが自動で答えを生成する
- 専門判断の代替
- 24個すべてを丸暗記させる
- 長文の問題分析を要求する

## 11. Completion criteria
- 6棚×4戦術 = 24個がデータ上・画面上で一致
- 6問トレーニングを進行不能なく完走できる
- 各ラウンドの候補は6棚から1枚ずつ
- 3方向を選ぶ行為そのものが反復される
- 見るだけでは展開力スコアが上がらない
- 結果画面で偏っている棚が分かる
- 実戦モードで入力→棚選択→具体的1手→終了まで完走できる
- 候補の引き直しで入力済みの困りごとを失わない
- 主要操作がスマホで押しやすい
- オフラインで主要機能が動く
