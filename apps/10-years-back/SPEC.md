# 10年後から戻ってきた — SPEC

## 1. ユーザーの瞬間

「やった方がいい」「連絡した方がいい」「決めた方がいい」と本人も分かっているのに、今日も止まっている瞬間に開く。

使い終わったときの成功状態は、人生の正解を得ることではない。**今日3分以内に開始できる具体的な一手を1つに絞り、実際に着手すること**。

## 2. 中心ベネフィット

10年後の自分というフィクションの視点を借りることで、目の前の迷いを大きな人生相談にせず、今日の最小行動へ戻す。

## 3. 独自のゲーム構造

このアプリの固有操作は「2036年のカプセルを2026年のNOWまでドラッグする」こと。

- 未来の視点を選ぶだけの診断にはしない。
- 3択の正解当てゲームにはしない。
- ドラッグ操作そのものを「未来の話を今日の行動へ戻す」意味に一致させる。
- ドラッグ後は3分の ACTION WINDOW に入り、現実行動まで接続する。

## 4. フロー

1. **10年後から戻る**
   - 2036年の自分が3分だけ戻ってきた、という設定を最初の10秒で提示。
   - 「未来を予言するアプリではない」ことも明示。
2. **今止まっている分岐を選ぶ**
   - 始める / 連絡 / 予約・申込 / やめる / 決める / 片づける。
3. **FUTURE LOGを見る**
   - 選んだテーマに応じた10年後の短いメッセージ。
   - 未来の断定ではなく、選択を考えるためのフィクションと明示。
4. **今日の一手を選ぶ**
   - 各テーマ3つの、3分以内に開始できるマイクロアクション。
   - 42字以内の自由入力も可。
5. **2036→NOWへドラッグ**
   - カプセルを下へ引き、今日の一手として確定。
   - キーボード / 補助ボタンでも進める。
6. **3分だけ実行**
   - 3:00タイマー。
   - 「できた / もう着手した」で途中終了できる。
   - 無理な日は「今日はここまで」で一手だけ保存できる。
7. **未来変更ログ**
   - この端末に最近の行動を保存。
   - 着手できた回数と最近3件を表示。
   - Web Share / clipboard で結果共有。

## 5. コンテンツ方針

抽象的な励ましではなく、現実に開始できる動詞にする。

### 始める
- 入口だけ開く
- 3分だけ手を動かす
- 最初の1工程だけ終える

### 連絡
- 相手の画面だけ開く
- 1文だけ下書きする
- 「少し話したい」とだけ送る

### 予約・申込
- 候補を1つだけ開く
- 必要な条件を1個確認する
- 入力画面まで進む

### やめる
- 次の1回だけやめる
- 10分だけ離す
- 再開する条件を決める

### 決める
- 選択肢を2つまで減らす
- 決める期限を今日つける
- 今日試せる方を選ぶ

### 片づける
- 1個だけ捨てる・戻す
- 1面だけ空ける
- 3分タイマーで触る

## 6. UI / ビジュアル

- スマホ1画面中心、最大幅560px。
- 黒に近い背景、ミント色の時間軸、CRTスキャンライン、回転するポータルリングで「未来通信」を表現。
- 一般的なAIカードUIではなく、年号・タイムライン・カプセル・ACTION WINDOWで固有世界観を作る。
- 主CTAは常に1つを最優先。
- safe-area対応、最小58pxの主要ボタン。
- `prefers-reduced-motion` 対応。

## 7. 保存・プライバシー

- 入力・結果は `localStorage` のみ。
- 外部API送信なし。
- 保存内容は直近12件に制限。
- 結果画面に端末内保存であることを表示。

## 8. 再訪理由

「未来変更ログ」を積み上げることで、別の分岐を1つずつ処理できる。
単なる連続ログインではなく、実際に着手した小さな行動だけが増える。

## 9. このアプリでなければならない理由

**10年後の自分から今日へ行動を“持ち帰る”ドラッグ操作と、そのまま3分の現実行動へ入る時間旅行フローが、他のLEVEL UPアプリとの違い。**

## 10. 完了条件

- 初見10秒以内に目的・操作・ベネフィットが理解できる。
- 6テーマすべてで一手を選べる。
- カプセルのpointer drag、補助ボタン、keyboard操作が機能する。
- タイマー開始 / 一時停止 / 完了 / 保存が機能する。
- localStorageログが再読込後も残る。
- Web Share非対応環境ではclipboard fallbackがある。
- 390px以下と通常スマホ幅で崩れない。
- 本番 `https://levelup.hitobito.jp/apps/10-years-back/` で実ブラウザ確認する。
