# 星渡りの黎明 / ASTRAL DAWN

Three.js で制作したオリジナル 3D JRPG の縦切り版。

## 体験の一本線

村で目覚める → リナが仲間になる → 青い導光を追う → フィールドシンボル戦闘 → 祠を活性化 → 古代種ボス戦 → 夜明け。

## 操作

- WASD / 矢印キー: 移動
- Shift: 走る
- E / Space: 話す・調べる
- 戦闘: 画面下コマンド / 数字 1〜4
- スマホ: 左スティック + 右アクション / ラン

## 実装済み

- 3D オープンフィールド風探索
- 村、湖、古道、遺跡、遠景ランドマーク、山岳遠景
- 地形起伏への主人公・仲間・NPC・敵・建物の追従
- 昼夜・星空・霧・影・ACES tone mapping
- NPC 会話とアイテム入手
- リナのフィールド追従と戦闘中の自動支援
- シンボルエンカウント
- 攻撃 / MP スキル / 防御 / 回復のコマンドバトル
- 通常戦後のHP/MP回復による冒険テンポ維持
- ボスの赤い予備動作と、防御が有効になる読み合い
- 戦闘専用カメラ、ヒットフラッシュ、画面揺れ、ダメージ・回復表示、消滅エフェクト
- 2体撃破後に祠の青い光柱が出現する視覚誘導
- ボス登場シネマティック
- 全滅後の再挑戦
- PC / スマホ入力と状態別UI切り替え

## 品質基準

ゲーム固有の完了条件と、マージ前に必要な実ブラウザ・実機チェックは [`QUALITY.md`](./QUALITY.md) に定義する。

コードが動くことだけでは完成扱いにしない。開始からボス撃破までの通しプレイ、フィールド・戦闘・ボス登場のスクリーンショット目視、iPhone相当幅での操作確認を必須とする。

## Human Playtest

リポジトリの人間テストプレイ機能は `apps/*/index.html` を自動検出するため、このゲームも追加登録なしでテスト一覧に出る。

ブランチ `feat/astral-dawn-threejs-rpg` をローカルで取得し、リポジトリ標準の `START_HUMAN_TEST.bat` または `npm run human-test` から試遊する。

## 起動

`apps/astral-dawn` を HTTP サーバーで配信して開く。Three.js は jsDelivr の ES module を利用する。

## 方針

既存作品の固有キャラクター、モンスター、ロゴ、UI、マップはコピーせず、現代的な JRPG の品質基準（可読性、密度、カメラ、レスポンス、報酬演出、導線）を目標にする。
