# 星渡りの黎明 / ASTRAL DAWN

Three.js で制作しているオリジナル 3D JRPG の縦切り版。

## 体験の一本線

村で目覚める → リナが仲間になる → 青い導光を追う → 寄り道して宝箱を探す → 特性の異なる魔獣と戦う → 祠を活性化 → 古代種ボス戦 → 夜明け。

## 操作

- WASD / 矢印キー: 移動
- Shift: 走る
- E / Space: 話す・調べる
- 戦闘: 画面下コマンド
- スマホ: 左スティック + 右アクション / ラン

## V5 実装済み

### フィールド

- 村、湖、古道、遺跡、遠景ランドマーク、山岳遠景
- 地形起伏への主人公・仲間・NPC・敵・建物の追従
- 昼夜、星空、霧、影、ACES tone mapping
- 大量のInstancedMesh草、岩、低木
- 柵、樽、道標、村の暖色ローカルライト
- 草 / 土 / 石 / 木 / 漆喰のプロシージャル表面ディテールとbump
- 祠の回転星輪、浮遊破片、動的シアン光
- 2体撃破後に祠の青い光柱が出現する空間内誘導

### キャラクター

- リナの加入、フィールド追従、戦闘中AUTO支援
- アレン / リナはCC0のリグ済みGLBを任意ロード
- 待機 / 歩行 / 走行 / 攻撃 / 被弾 / 魔法をAnimationMixerで切り替え
- アレン専用の赤いクロークと星紋章
- リナ専用の紫マントル、星輪、浮遊光晶
- 外部モデル取得失敗時はプロシージャル造形へ自動フォールバック

### 探索

- 3つの寄り道宝箱
- 薬草雫、最大HP上昇、最大MP上昇の異なる報酬
- 宝箱開封アニメーションと取得エフェクト

### 戦闘

- 攻撃 / 星断ち / 防御 / 回復
- リナ加入後の必殺連携「星環連携・双星断」
- 連携技は1戦1回、MP20を消費する明確な切り札
- ヴァルグ3体に「追撃 / MP侵食 / 自己回復」の異なる行動特性
- 敵特性を戦闘UIに表示
- 通常戦後のHP/MP回復で探索テンポを維持
- ボスの赤い予備動作と、防御が有効になる読み合い
- ヒット粒子、発光リング、会心強調、短い専用カメラカット
- 戦闘専用カメラ、画面揺れ、ダメージ・回復表示、消滅エフェクト

### モンスター

- 灰角のヴァルグを多パーツ四脚獣へ再設計
- 胴 / 胸 / 首 / 顎 / 四肢 / 爪 / 耳 / 角 / 鬣 / 分節尾 / 発光眼
- ボス「星喰らいのオルグ」は追加角、星晶、胸部ルーン、赤い動的光源を持つ別格シルエット
- 呼吸、尾、顎、大技予備動作、攻撃突進の追加アニメーション

### 音 / 演出

- Web Audioによるフィールド環境パッド、風、疎な旋律
- 戦闘時は低音パルスへクロスフェード
- サウンドON/OFF
- ボス登場シネマティック
- ボス撃破後は約6秒の専用「夜明け」シネマティック
- カメラが戦闘距離から祠と遠景へ抜け、光芒、浮遊光、鳥、露出、ゲーム内時刻が同期して朝になる

### パフォーマンス

- AUTO / HIGH / BALANCED / ECO の描画品質プリセット
- AUTOは端末情報と実測FPSを見てpixel ratioと影品質を自動調整
- 高性能端末では高品質を維持し、負荷が高い場合だけ段階的に軽量化

## 品質ゲート

- 全ブラウザモジュールのJavaScript構文
- V5がV4へ差し込む計装ポイント
- `index.html` の全品質レイヤー参照
- 必須品質ドキュメント
- 任意HDモデルの配信先到達性

ゲーム固有の完了条件は [`QUALITY.md`](./QUALITY.md)、辛口評価は [`REVIEW.md`](./REVIEW.md)、外部アセットの由来は [`THIRD_PARTY_ASSETS.md`](./THIRD_PARTY_ASSETS.md) に記録する。

## Human Playtest

リポジトリ標準の人間テストプレイから自動検出できる構成だが、現在のV5非人間テスト工程では実行対象から外している。

## 起動

`apps/astral-dawn` を HTTP サーバーで配信して開く。Three.js は jsDelivr の ES module を利用する。

## 方針

既存作品の固有キャラクター、モンスター、ロゴ、UI、マップ、音楽、テクスチャ等はコピーしない。オリジナルIPのまま、現代的なJRPGの品質基準である可読性、空間密度、カメラ、レスポンス、報酬演出、導線、キャラクター性を引き上げる。
