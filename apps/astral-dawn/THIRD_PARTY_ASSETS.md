## KayKit Character Pack: Adventurers 1.0

- Creator: Kay Lousberg / KayKit Game Assets
- License: CC0 1.0 Universal
- Official repository: `KayKit-Game-Assets/KayKit-Character-Pack-Adventures-1.0`
- Runtime use:
  - `Knight.glb` — optional high-detail visual model for アレン
  - `Mage.glb` — optional high-detail visual model for リナ
- Loading method: jsDelivr mirror of the official GitHub repository.
- Fallback: if either remote model cannot be loaded, the procedural Three.js character remains visible and the game continues normally.

The upstream pack states that the characters are textured, rigged and animated, and that the free assets are licensed CC0 for personal and commercial use without required attribution. This file records provenance even though attribution is not required.

No Dragon Quest character, logo, monster, map, music, texture or other proprietary asset is included.
