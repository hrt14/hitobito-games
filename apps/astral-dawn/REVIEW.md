# 星渡りの黎明 — HARSH REVIEW / V5

実装者とは別の視点で、この縦切り版を「現代の大作JRPGと同じ棚に並べたときに弱く見える点」を優先して評価する。

## 現在の判定

**完成扱い: NO**

v4 の「高密度プロトタイプ」からは大きく進み、現在は **ビジュアル、キャラクターアニメーション、探索報酬、敵差、連携技、建築、音、夜明け演出、性能制御、カメラ安全性まで持つ商用品質志向の縦切り版**。

ただし、ユーザー指示により人間テストプレイは今回の工程から明示的に外している。代わりに Chromium を用いた自動ブラウザ操作を品質ゲートとして使い、実行時バグを検出・修正している。自動検証を通っても、最終的な人間の視覚比較を通過したとは扱わない。

## V5で改善した項目

### 1. キャラクター造形 / アニメーション

- アレンとリナは、CC0のリグ済み・アニメーション済みGLBを任意ロードする層を追加。
- 読み込み成功時は待機・歩行・走行・攻撃・被弾・魔法を AnimationMixer で切り替える。
- 外部モデルをそのまま使わず、アレンには赤いクローク・星紋章、リナには紫のマントル・星輪・浮遊光晶を追加し、Astral Dawn固有のシルエットへ寄せる。
- 外部モデル読込失敗時は従来のプロシージャル造形へ自動フォールバックし、進行不能にしない。

**残る課題:** 完全オリジナルの専用モデル、表情、口パク、指、足IK、髪・衣服物理。

### 2. 敵造形 / 行動差

- 灰角のヴァルグと星喰らいのオルグを、多パーツ四脚獣として再設計。
- 胴、胸、首、頭、顎、四肢、爪、耳、角、鬣、分節尾、発光眼を持つ。
- ボスは追加角、赤い星晶、胸部ルーン、赤い動的光源を持ち、通常敵と明確に格を変える。
- 待機呼吸、尾、顎、予備動作、大技発光、攻撃突進を追加。
- 通常ヴァルグ3体には「裂爪型 / 追撃」「吸星型 / MP侵食」「再生型 / 自己回復」の3特性を割り当て、UIでも明示。

**残る課題:** 本格スケルタルアニメーション、複数の専用攻撃モーション、複数敵編成、より高度なAI。

### 3. 環境密度 / 建築

- 草を InstancedMesh で大量配置。
- 岩、低木、柵、樽、道標、暖色ローカルライトを追加。
- 宿、店、民家に石基礎、露出梁、煙突、庇、花箱、用途別看板を追加。
- 市場屋台と鍛冶場を別シルエットで追加。
- 祠は段状基壇、破損塔、床ルーン、回転星輪、浮遊破片、動的シアン光を持つ目的地へ再設計。
- 遠景側にも壊れた遺構を追加し、世界が画面外へ続く感覚を補強。

**残る課題:** 建物を完全に専用アセットへ置換すること、地形ブレンド、地域別植生、より高度なLOD。

### 4. マテリアル

- 草、土、石、木、漆喰に CanvasTexture 由来の色ムラと bump を追加。
- 金属、星晶、水、石、布などの roughness / metalness / emissive 差を強化。

**残る課題:** 専用制作した高解像度 albedo / normal / roughness / AO セット。

### 5. 探索報酬

- 一本道だけにならないよう、寄り道に3つの宝箱を追加。
- 回復アイテム、最大HP上昇、最大MP上昇を異なる報酬にした。
- 宝箱開封アニメーションと取得粒子を追加。

### 6. 戦闘 / パーティ

- 攻撃ヒット時に星粒子、発光リング、瞬間グロー、短い専用カメラカットを追加。
- ボス大技の予備動作では赤い危険演出を追加。
- 会心は通常攻撃より強い発光・カメラ反応を持つ。
- リナ加入後に1戦1回の必殺連携「星環連携・双星断」を追加。MP20を使う明確な切り札にした。
- リナのAUTO支援と手動連携の両方を持たせ、加入が画面だけでなく戦術を変えるようにした。

**残る課題:** 複数敵、弱点・ブレイク、状態異常、さらに長い専用技カメラ、複数連携技。

### 7. 音

- Web Audioによるフィールド環境レイヤーを追加。
- フィールドは低いパッド、風ノイズ、疎な旋律。
- 戦闘へ入るとフィールド音を落とし、低音パルスとキックへクロスフェード。
- サウンドON/OFFを追加。

**残る課題:** 作曲済みBGM、録音・制作済み足音、武器音、環境音、掛け声、ボイス。

### 8. ボス撃破報酬

- 「時間値を変えるだけ」だった夜明けを、約6秒の専用シネマティックへ変更。
- カメラが戦闘距離から祠・遠景へ抜ける。
- 朝日の光芒、浮遊光、鳥、露出、ゲーム内時刻を同期。
- CHAPTER I COMPLETE / 夜明け を明確な章クリア報酬として表示。

### 9. カメラ / 性能

- 建物コライダーを使った軽量なカメラ遮蔽回避を追加。
- AUTO / HIGH / BALANCED / ECO の4品質プリセットを追加。
- AUTOは端末情報と実測FPSを見て pixel ratio と影品質を段階調整する。

**残る課題:** 全メッシュ遮蔽への高度な対応、屋内カメラ、GPU別調整、実機ごとの描画チューニング。

## 自動品質ループ

- JavaScript各ファイルの構文検査。
- v4へv5のフックを実際に差し込んだ「合成後ランタイム」も構文検査。
- indexの品質レイヤー参照漏れを検査。
- Chromiumでタイトル→会話→移動→宝箱→戦闘→敵特性→星環連携→勝利まで自動操作するブラウザテストを追加。
- 初回ブラウザテストでは `architecture-v1.js` の未宣言変数 `t` を実際に検出し、修正済み。
- 自動テストが失敗した場合は、console/page error、停止ステージ、画面状態、スクリーンショットを診断として残す。
