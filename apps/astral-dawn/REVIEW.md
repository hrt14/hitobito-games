# 星渡りの黎明 — HARSH REVIEW / V5

実装者とは別の視点で、この縦切り版を「現代の大作JRPGと同じ棚に並べたときに弱く見える点」を優先して評価する。

## 現在の判定

**完成扱い: NO**

ただし v4 の「高密度プロトタイプ」からは一段進み、現在は **商用品質へ寄せるためのビジュアル・アニメーション・探索・音の品質レイヤーを実装した縦切り版**。

人間テストプレイは今回の作業対象から明示的に外しているため、実ブラウザの目視・操作・動画評価を通過したとは扱わない。

## V5で改善した項目

### 1. キャラクター造形 / アニメーション

- アレンとリナは、CC0のリグ済み・アニメーション済みGLBを任意ロードする層を追加。
- 読み込み成功時は待機・歩行・走行・攻撃・被弾・魔法を AnimationMixer で切り替える。
- 外部モデルをそのまま使わず、アレンには赤いクローク・星紋章、リナには紫のマントル・星輪・浮遊光晶を追加し、Astral Dawn固有のシルエットへ寄せる。
- 外部モデル読込失敗時は従来のプロシージャル造形へ自動フォールバックし、進行不能にしない。

**残る課題:** 専用の完全オリジナルモデル、表情、口パク、指、足IK、衣服物理は未実装。

### 2. 敵造形

- 灰角のヴァルグと星喰らいのオルグを、旧プリミティブの塊から多パーツ四脚獣へ置換。
- 胴、胸、首、頭、顎、四肢、爪、耳、角、鬣、分節尾、発光眼を持つ。
- ボスは追加角、赤い星晶、胸部ルーン、赤い動的光源を持ち、通常敵と明確に格を変える。
- 待機呼吸、尾、顎、予備動作、大技時の発光、攻撃時のルートアニメーションを追加。

**残る課題:** スケルタルアニメーション、毛並み/皮膚の高密度テクスチャ、敵固有の複数攻撃モーション。

### 3. 環境密度

- 草を InstancedMesh で大量配置。
- 岩、低木、柵、樽、道標、村の暖色ローカルライトを追加。
- 祠に回転する星輪、浮遊破片、シアンの動的光源を追加。
- 前景・プレイ層・遠景ランドマークの差を強化。

**残る課題:** 建築そのものの固有造形、地形ブレンド、地域別植生、LOD、より高度な遮蔽/密度設計。

### 4. マテリアル

- 草、土、石、木、漆喰に CanvasTexture 由来の細かな色ムラと bump を追加。
- 金属、星晶、水、石、布などの roughness / metalness / emissive 差を強めた。

**残る課題:** 専用制作した albedo / normal / roughness / AO の高解像度PBRセットではない。

### 5. 探索報酬

- 一本道の移動だけにならないよう、寄り道に3つの宝箱を追加。
- 回復アイテム、最大HP上昇、最大MP上昇をそれぞれ報酬にし、開封アニメーションと粒子演出を追加。
- 探索した行動が数値だけでなく宝箱の開閉と光で見える。

### 6. 戦闘演出

- 攻撃ヒット時に星粒子、発光リング、瞬間グロー、短い専用カメラカットを追加。
- ボス大技の予備動作では画面周辺にも赤い危険演出を追加。
- 会心は通常攻撃より大きな発光・カメラ反応になる。

**残る課題:** 技ごとの長い専用カメラ文法、複数敵、弱点・ブレイク、パーティ連携技。

### 7. 音

- Web Audioによる常時環境レイヤーを追加。
- フィールドは低いパッド、風ノイズ、疎な旋律。
- 戦闘へ入るとフィールド音を落とし、低音パルスとキックへクロスフェードする。
- サウンドON/OFFを追加。

**残る課題:** 作曲済みBGM、録音/制作した足音・武器・環境・ボイスなど、本格的なサウンドアセット。

## いま本当に大きい残課題

1. **完全オリジナルの高品質キャラクター/衣装モデル**
2. **専用PBRテクスチャと建築アセット**
3. **足IK・表情・髪/布の二次動作**
4. **敵AIと技バリエーション、複数敵戦**
5. **オリジナル楽曲・SE・掛け声**
6. **カメラ遮蔽・LOD・描画負荷の実ブラウザ調整**
7. **実画面での比較レビュー**
