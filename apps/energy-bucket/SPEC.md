# 夕方に電池切れする人の 体力の穴を1個ふさぐ — Product Spec

## Exact use moment
夕方になると頭も体も止まり、「もっと体力をつけないと」と思っている人が、朝から夜までの習慣を30秒で見直し、明日ひとつだけ変える行動を決めるときに使う。

## Central benefit
疲れへの対策を増やすのではなく、毎日エネルギーを減らしていそうな習慣を1つ見つけ、明日実行できる最小の行動に固定する。

## Problem / design rationale
疲れていると、運動・睡眠・食事・休憩など複数の改善を同時に始めたくなる。しかし実行項目が増えるほど、その場で「やるかどうか」を判断する回数も増える。このアプリは体力をバケツに見立て、まず漏れを見つけ、1回のセッションでは1個しか塞がない。最後は「もしXならYする」という事前ルールに変換し、疲れた明日の自分が決断しなくて済む形にする。

食後の軽い歩行については、長時間座り続ける条件より食後の血糖・インスリン反応が小さくなる方向の系統的レビュー・メタ分析を根拠にする。動画中の特定の改善率は固定表示しない。息切れは単純な体力不足と決めつけず、安全確認の分岐を設ける。

## Core interaction
ユーザーは10個の生活上の「穴」をタップする。選ぶたびに画面中央のバケツへ穴が開き、水位が下がる。次に、選んだ穴のうち安全性・小さく実行できること・毎日起こる合図への結びつけやすさを優先して候補を3つに絞り、1個だけ選ぶ。最後にIF（合図）とTHEN（行動）を自分の言葉で微調整して保存する。

操作そのものが「全部直す」から「漏れを見つけて1個だけ塞ぐ」への思考転換になっている。

## First 10 seconds
画面を開くと大きなバケツと「体力を足す前に、漏れを1個ふさぐ。」が見える。その下に10個の具体的な生活項目があり、説明を読まなくても当てはまるものをタップできる。タップするとバケツの水位と穴が即座に変化する。

## Success condition
セッション終了時に、明日1回だけ実行すれば成功となるIF-THENルールが1本保存されている。次回訪問時に「できた／まだ」を記録できる。

## Uniqueness
既存の「疲れたの正体」は今の疲れを体・脳・感情・対人・未完了へ分けて回復策を返す診断型。このアプリは、日々の体力低下を生活上の漏れとして可視化し、改善対象を1個に制限して翌日のIF-THEN実行までつなぐため、役割が異なる。

## Repeat-use strategy
保存した1個のルールを次回「できた／まだ」で確認する。できなければ意志の弱さとして扱わず、合図または行動をさらに小さくする材料にする。一定期間後に同じ10項目を再チェックし、穴が減ったかを見る。

## Title rationale
- Main user benefit/motive: improve health / feel comfortable / save mental effort
- Why this title is direct and specific: 「夕方に電池切れする人」で対象を示し、「体力の穴を1個ふさぐ」でアプリ内の操作と持ち帰る行動をそのまま表す。
- How it matches the actual app: バケツの穴を選び、1個だけ塞ぐIF-THENルールを作る体験と一致する。
- Market/uniqueness checks actually performed (if any): 「体力お化け／体力おばけ」は書籍・動画・記事で既に広く使われているため、タイトルの主語には採用せず、具体的な悩みと操作を優先した。
