# 今日やるのは2つだけ — Product Spec

## Exact use moment
やることが3つ以上頭に浮かび、どれも重要に見えて、結果として全部を抱えたまま仕事を始めている人が、その日の仕事を始める前か、仕事が増えた瞬間にスマホで開く。

## Central benefit
優先順位をきれいに並べるのではなく、**今日やる仕事を物理的に2枠へ制限し、3つ目を入れるなら必ず1つ外す**ことで、その日のWIPを減らす。

## Start state / end state
- Start: 「これも今日やる」が3件以上あり、全部を同時に抱えている。
- End: 今日やる2件が明示され、それ以外が「あと」または「捨てる」に移動している。

## Main mechanic
**TODAYには2席しかない。**

候補タスクを1件ずつ見せ、ユーザーは以下だけを選ぶ。
- 今日に入れる
- あと
- 捨てる

TODAYが2席埋まった状態で3件目を「今日に入れる」と、追加はできない。
必ず「どちらを追い出す？」画面へ進み、既存2件のどちらかを「あと」へ移すか、新しい仕事を「あと」へ送る。

これにより「全部重要だから全部やる」という選択肢をUI上からなくす。

## Why this is a game
通常のToDoリストは足し算だが、本作は席取りゲーム。
- 2席が埋まる
- 新しい候補が来る
- 既存タスクと直接対決する
- 1件が必ずTODAYから落ちる

操作そのものが「同時に抱える仕事を減らす」練習になる。

## First 10 seconds
最初の画面では以下だけを伝える。
- `今日やるのは2つだけ`
- `3つ目を入れるなら、1つ追い出す。`
- `今日を2つにする`

心理学・時間管理の説明は置かない。

## Input
ユーザー自身の仕事を使うため、文字入力を使う。
- 1行1件
- 最大12件
- iPhone等のキーボード音声入力もそのまま使える
- 重複と空行は除外

## Core loop
1. 候補を2〜12件入力。
2. 1件ずつカードが出る。
3. `今日 / あと / 捨てる` のどれかへ送る。
4. TODAYが2席埋まっている状態で新しいタスクをTODAYへ送ろうとすると、入れ替え画面へ進む。
5. 全候補が終わったら、TODAY 2件と「今日はやらない件数」を大きく表示する。
6. 最初の1件を現実で開始したら `始めた` を押し、完了感を返す。

## Feedback
- TODAYに入った: 席が埋まる短いアニメーション + 対応端末では短い振動。
- 3つ目: `満席です。入れるなら、1つ追い出す。`
- あと: 褒めずに `今日から外した。`
- 捨てる: `消した。今日の負荷 -1。`
- 終了: `今日はこれ以外、やらない。`

## Undo
分類中は1手戻せる。
間違えて押した結果の修正コストを下げる。

## Persistence
localStorageに日付単位で以下を保存する。
- 候補
- 今日2件
- あと
- 捨てたもの
- `始めた` 状態

同じ日に再訪した場合は、その日の2件を即座に復元できる。

## Sharing
結果はWeb Share APIで共有し、非対応時はクリップボードへコピーする。
共有内容にはタスク本文を含めるため、共有操作はユーザーが明示的に押した時だけ行う。

## Title rationale
- Title: `今日やるのは2つだけ`
- 得: 仕事量が減る
- 手っ取り早さ: 数字の「2」で制約が即伝わる
- 具体性: 今日 / 2つ / やる、がすべて明示される
- 内容一致: アプリ内のTODAY枠も実際に2席固定
- 無意味な言葉遊びなし

## Uniqueness vs other LEVEL UP apps
`重要なことから` が重要度・緊急度で判断するアプリ、`あと5分` が仕事を小さく分解するアプリなのに対し、本作は**重要度を採点せず、同時に抱える今日の仕事を2件へ物理的に制限する**ことが固有の体験。

## Anti-patterns to avoid
- 無制限にTODAYへ追加できる
- 優先度1〜5を細かく採点させる
- カレンダーや期限管理まで詰め込む
- 3つ目を入れたのに既存2件が残る
- 汎用的な励まし文
- 終了時に単なる「お疲れさま」で終わる

## Quality target
- 分かりやすさ: 9/10
- 役立ち度: 9/10
- 操作の気持ちよさ: 8/10
- 独自性: 9/10
- 継続性: 8/10

完成条件は本番Firebase Hostingへ反映し、スマホ幅の実ブラウザで「2席→3つ目→入れ替え→結果」まで通ること。
