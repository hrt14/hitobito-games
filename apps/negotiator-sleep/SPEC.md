# NEGOTIATOR｜寝かせる — Product Spec

## Exact use moment
夜、寝た方がいいとは分かっているのに「まだ仕事がある」「まだ眠くない」「スマホを見たい」と抵抗して寝る方向へ切り替えられない人が、布団に入る前後の1〜3分で開く。使い終わる時には「寝る」という大きな決断を迫られず、照明・スマホ・体勢・目を閉じる等のうち複数が実際に寝る側へ移っている。

## Central benefit
寝る決断を無理にさせず、拒否しながらでも睡眠前の行動を小さく1つずつ進める。

## Problem / design rationale
「今すぐ寝る」は要求が大きく、やることや覚醒感が残っている時ほど拒否しやすい。そこで本作は、ユーザーのNOを失敗にせず、NOの理由に応じて次の要求を小さくする会話構造にする。大きな要求から小さな要求へ縮める、すでにできた小さな行動を次へつなぐ、抵抗理由を否定せず別条件へ変える、という交渉ゲームとして設計する。診断・治療や睡眠改善効果の断定は行わない。

## Core interaction
ユーザーは最初の「もう寝る？」に対して、寝る／忙しい／眠くないから選ぶ。その後も1つの受諾と2つの拒否から選ぶが、拒否するほど画面上の「要求サイズ」が100%→36%→20%→10%→3%と縮む。受諾した小さな行動はWORK / LIGHT / PHONE / BODYの状態表示へ即反映される。最後は「3秒だけ目を閉じる」を長押しし、押している間に実画面が暗くなる。会話を読むだけでなく、要求が物理的に小さくなり、画面環境も睡眠側へ変化することが中心操作。

## First 10 seconds
最初の画面に「寝る気ゼロのあなたを、寝かせる。」「あなたは断ってください。こちらは、そのたびに条件を下げます。」と表示し、「交渉を始める」だけを主ボタンにする。開始直後に「今夜、もう寝ませんか？」と3つの返答が出るのでチュートリアルなしで目的と操作が分かる。

## Success condition
以下のどちらかを満たせばセッション成功とする。
- ユーザーが最初から「もう寝る」を選ぶ。
- 拒否を続けながら、最終的に3秒または1秒の長押しを完了し「目を閉じる」を実行する。

成功・不成功にかかわらず、最後に何を寝る側へ動かしたかと、要求が何%まで小さくなったかを表示する。ユーザーが最後まで拒否した場合は「不成立」で終え、最終決定権を奪わない。

## Uniqueness
既存の「預けて、寝る。」が就寝時の考え事を明日へ預けるツールなのに対し、本作は「寝たくない／まだ続けたい」という抵抗そのものをゲーム入力として使い、拒否するほど次の要求が小さくなる交渉構造が中核なので代替できない。

## Repeat-use strategy
毎晩同じ大きな決断を迫るのではなく、その日の抵抗理由によって違うルートを通れる。端末内に前回の「断った回数」と最終要求サイズだけを保存し、次回は前回の交渉結果を短く表示する。睡眠を競争化するポイントや連続記録は付けない。

## Title rationale
- Main user benefit/motive: 今夜、寝る側へ切り替えたい／楽に休みたい。
- Why this title is direct and specific: シリーズ名「NEGOTIATOR」と目的「寝かせる」をそのまま並べ、内容を隠さない。
- How it matches the actual app: アプリ側が条件を変え続け、ユーザーと実際に交渉する構造そのものが主体験。
- Market/uniqueness checks actually performed (if any): 今回はユーザー指定のシリーズ名を採用。外部市場調査はタイトル決定条件ではないため未実施。
