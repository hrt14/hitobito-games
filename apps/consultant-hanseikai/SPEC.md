# コンサル後反省会を3分で終わらせる — Product Spec

## Exact use moment

コンサル、商談、定例会議が終わった直後に「相手の反応が微妙だった」「契約が続くか」「準備不足だった」「適当なことを言ったかも」と頭の中で会議を再生し続け、さらに「人の商売ばかり手伝って自分の商売が進んでいない」という自己嫌悪まで混ざっている人が、3分で反省を終え、自分の次の行動へ戻るために開く。

## Central benefit

**考えても情報が増えない不安を頭から下ろし、次回の改善を1個だけ残して、自分の仕事へ戻れる。**

## Problem / design rationale

会議後の反省には、観察できた事実、まだ確定していない相手の評価や未来予測、自分で次回変えられる行動が混ざりやすい。さらに仕事そのものへの違和感や「自分の商売が進んでいない」という別問題まで同時に抱えると、1回の会議評価が自分全体の評価へ膨らむ。

このアプリは安心させることや「大丈夫だった」と結論づけることを目的にしない。扱える対象だけを残し、扱えない対象をいったん閉じる。最後に必ず「自分の商売を1mm進める」へ接続し、他人の評価から自分の時間へ戻す。

## Core interaction

1. 開始時に頭の占有度を0〜100で記録する。
2. 今浮かんでいる内容を具体カードから複数選ぶ。自由入力は任意。
3. カードを **事実 / 想像 / 次に変えられる** の3レーンへドラッグまたはタップで仕分ける。
4. 「想像」レーンのカードを上へスワイプして画面外へ捨てる。捨てるたびに脳内WIPが減る。
5. 「次に変えられる」から持ち帰る改善を最大1個だけ選ぶ。抽象的な改善は具体アクションへ変換する。
6. 「自分の商売を1mm進めるなら？」から1個だけ選ぶ。
7. 終了時に占有度を再測定し、捨てた想像・持ち帰る改善1個・自分の一手を並べて反省会を閉じる。

操作そのものを、混ざった思考を分ける→未確定を捨てる→改善を絞る→自分へ戻る、という実生活で再利用できる順番に一致させる。

## First 10 seconds

最初の画面にはタイトル、短い1行説明、現在の「頭の占有度」スライダー、大きな「3分で終わらせる」ボタンだけを置く。長いチュートリアルは置かない。開始後すぐに具体的な悩みカードが見え、自分に関係するものをタップして進める。

## Success condition

- 「想像」に分類したカードをすべて捨てて0件にできる。
- 改善点は0〜1個に絞られている。
- 自分の商売を進める次の一手が1個決まっている。
- 終了時に「反省会を閉じた」状態が画面上で明確に見える。
- 占有度Before/Afterを表示するが、数値が必ず下がるとは約束しない。

## Uniqueness

`kanji-warukatta` は「失礼だった・嫌われたかも」という対人反芻を事実/気遣い/評価予測に分けるアプリ、`approval-off` は他人評価と自分の行動の領域を分けるアプリ。このアプリは **コンサル終了直後** に限定し、契約継続・提供価値・準備不足・発言への不安を一度に処理したうえで、最後に **自分の商売へ戻る行動** まで必ず接続するため別プロダクトとして成立する。

## Repeat-use strategy

コンサルや商談のたびに使う短い終了儀式として設計する。localStorageには自由入力本文を保存せず、利用回数、開始/終了占有度、今回持ち帰った改善カテゴリ、最後に選んだ「自分の商売」アクション種別のみ保存する。再訪時は前回の「改善1個」と「自分の一手」を軽く表示し、今回も1個だけ持ち帰る。

## Title rationale

- Main user benefit/motive: 会議後の不安から早く抜けて時間を取り戻す。
- Why this title is direct and specific: 「コンサル後」「反省会」「3分」「終わらせる」で対象・瞬間・所要時間・結果が一読で分かる。
- How it matches the actual app: 主要フロー全体を約3分で完了し、終了操作で反省会を閉じる体験そのものを提供する。
- Market/uniqueness checks actually performed (if any): 市場検索結果を根拠にしていない。既存LEVEL UP内の `kanji-warukatta` / `approval-off` との機能重複を確認し、用途をコンサル終了直後＋自分の商売への復帰に限定した。
