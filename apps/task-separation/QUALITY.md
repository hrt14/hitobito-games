# 『それ、誰の課題？』品質チェック

## このゲーム固有の主役
- 主役: 4方向へ課題カードを仕分ける操作そのもの
- 中心フィードバック: 境界線の正誤、コンボ、背負っている他人の課題の増減
- 3分後の到達目標: 「誰がその選択の結果を引き受ける？」という問いが反射的に出ること

## 共通品質基準に対する実装
- 開始10秒以内: タイトル直下のコピーと開始ボタン、ゲーム開始後の「4方向へスワイプ」表示で目的と操作を提示
- 操作即時反応: ドラッグ追従、方向ゾーン発光、スワイプ飛び出し、正誤色、短い効果音
- 因果関係: 他人の課題を「自分」に誤分類するとバックパックが増える。相手/外の課題を正しく返すと軽くなる
- 成長の可視化: 問題レベル、進捗バー、コンボ、荷物量、結果4指標
- スマホ優先: pointer eventsによるスワイプ + 下部タップ操作の両対応
- 進行不能対策: 各問題はスワイプ/ボタン/キーボードの3入力経路を持ち、回答後は自動的に次へ進む
- 説明過多回避: 詳細説明は任意ダイアログ。ゲーム画面には必要最小限のラベルのみ

## セッション設計
- 全32問のプールから18問を抽出
- Level 1 → 5へ段階的に難化
- 分類: 自分 / 共同 / 相手 / コントロール外
- 結果: 境界線精度 / 自分課題回収 / 侵入率 / 背負い込み率

## 注意
課題の境界は実際には役割・責任・契約・合意によって変わるため、結果画面に「判断の練習用」である旨を明記する。
