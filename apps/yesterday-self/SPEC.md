# 昨日の自分に1勝 — Product Spec

## Exact use moment
仕事、SNS、友人、同僚などを見て「自分の方が遅い／劣っている」と他人との比較に意識を奪われた人が、その場で30〜90秒使い、比較対象を他人から昨日の自分へ戻して、今日の具体的な1勝を決める。

## Central benefit
他人との比較で消耗する状態から抜け、今日の自分が動かせる小さな前進へ意識を戻す。

## Problem / design rationale
比較の対象が他人の成果や現在地になると、自分では操作できない条件まで勝敗に含まれやすい。このアプリでは「比較するな」と説教するのではなく、比較対象そのものを操作で入れ替える。

ユーザーが他人カードを物理的に対戦表から外し、その空いた場所へ「昨日の自分」を登場させることで、考え方の切り替えを画面操作として反復する。勝利条件は大きな自己更新ではなく、昨日より一つだけ良い行動に限定する。

## Core interaction
1. 今気になっている比較相手を短く入力する、または入力せず「他人」として扱う。
2. その相手のカードを横へスワイプして対戦表から外す。
3. 画面中央に「昨日の自分」が対戦相手として現れる。
4. 着手、集中、返信、寝る準備、前進量、自由入力から「今日の1勝」を一つ決める。
5. 現実で実行後、「勝った」を押すと 1–0 の結果が残る。まだなら最小の次の一手を表示する。

スワイプで他人を外し、昨日の自分へ置き換える操作そのものが「比較対象の切り替え」を訓練する。

## First 10 seconds
最初の画面には「今、誰と戦ってる？」と、斜線の入った比較相手カードだけを大きく表示する。カードには「横に払って対戦表から外す」と短く表示し、説明を読まずに触れる。スワイプ後すぐ「TODAY'S ENEMY / 昨日のあなた」が中央に現れる。

## Success condition
セッション終了時に、ユーザーが「他人との勝敗」ではなく「昨日より一つ良くする具体的行動」を一つ選び、実行済みなら 1–0 として記録できている。

## Uniqueness
既存の比較・承認系LEVEL UPが「評価と自分の行動を分ける」ことを扱うのに対し、本アプリは比較衝動そのものを否定せず、毎回その競争心の向きを「他人 → 昨日の自分」へ物理操作で差し替える点が独自。

## Repeat-use strategy
他人が気になった瞬間に何度でも「比較リセット」として使える。日ごとの1勝を端末に保存し、昨日の1勝を次回の対戦基準として見せる。連続利用の価値はポイント獲得ではなく、自分の前進履歴が比較対象として蓄積することに置く。

## Title rationale
- Main user benefit/motive: 他人との比較による不快感から離れ、前進感を取り戻す。
- Why this title is direct and specific: 「誰と戦うか」と「何を達成するか」が「昨日の自分」「1勝」で一読できる。
- How it matches the actual app: 実際に昨日の自分を対戦相手として表示し、1つの行動を1–0で記録する。
- Market/uniqueness checks actually performed (if any): 2026-09-02に「昨日の自分に1勝」の完全一致語をWeb検索し、Amazon.co.jpドメインも指定して確認。一般的な「昨日の自分に勝つ／超える」という表現は見つかったが、検索結果上では同名のAmazon商品タイトルは確認できなかった。
