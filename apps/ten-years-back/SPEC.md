# 10歳若返りました。 — Product Spec

## Exact use moment
年齢や時間の経過を意識して「もう遅い」「時間がない」「このままでいいのか」と感じている人が開き、10年後の自分から現在へ戻ってきた視点を体で作り、今日やる一手を1つ決めて終える。

## Central benefit
今を「失った時間」ではなく「10年取り戻した今日」と感じ直し、先延ばししていた行動を今日の一手まで小さくする。

## Problem / design rationale
現在の年齢は毎日連続して増えるため価値を感じにくい一方、10年後から見れば現在は大きな若さと時間の余白を持つ。説明で納得させるのではなく、いったん10年先まで自分で時間を進め、その後いまへ巻き戻す操作で参照点を変える。その直後に「未来で後悔していたこと」を言語化し、今日の行動へ落とす。

## Core interaction
年齢入力後、同じタイムラインを自分の指で現在→10年後へ進め、次に10年後→現在へ巻き戻す。時間を物理的に動かす操作そのものが「10年後から戻ってきた」感覚を作る。続いて、未来の後悔を短く書き、その内容を今日できる一手へ縮める。

## First 10 seconds
最初の画面には大きく「今年、何歳ですか？」と年齢入力欄、「10年後へ行く」ボタンだけを置く。用途説明を長く読ませず、年齢を入れるとすぐタイムライン操作が始まる。

## Success condition
終了時にユーザーが「10年後の自分が後悔していたこと」と「今日やる1つ」を自分の言葉で残し、結果画面で「10歳若返った今日の一手」として確認できる。

## Uniqueness
既存の有限時間・優先順位系アプリが「残り時間を減らして選ぶ」のに対し、このアプリは一度10年後まで進んでから現在へ巻き戻す身体的な操作で、現在の年齢そのものを「取り戻した10年」として再評価させる点が固有。

## Repeat-use strategy
端末内に過去の「今日の一手」を保存し、再訪時は「未来から戻ってきてN回目」と前回の一手を表示する。毎日連続で使うことを強制せず、時間を無駄にしている感覚や迷いが出たときに何度でも参照点を戻すリセット道具にする。

## Title rationale
- Main user benefit/motive: 時間を取り戻した感覚、まだ間に合う感覚、今日動くきっかけ。
- Why this title is direct and specific: 体験の核心である「10歳若返った」をそのまま言い切り、何が起こるアプリかを一読で想像できる。
- How it matches the actual app: 実際に現在年齢+10歳まで進めた後、現在へ巻き戻して「10歳若返りました」と表示する。
- Market/uniqueness checks actually performed (if any): 今回は既存LEVEL UP内での独自性確認のみ。外部市場のタイトル調査は実施していない。
