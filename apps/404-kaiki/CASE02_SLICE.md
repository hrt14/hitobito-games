## 0. なぜ くねくね を次にやるか

CASE 01 と **絵も動詞も逆**にできるため。

| | CASE 01 口裂け女 | CASE 02 くねくね |
| --- | --- | --- |
| 時間 | 夜 | 夏の夕方 |
| 空間 | 狭い・暗い・囲まれている | 広い・明るい・遮るものがない |
| 色 | 紺と街灯のオレンジ | 白い空と金色の田 |
| 怪異 | 追ってくる | **動かない。ただそこにいる** |
| 生還の動詞 | **逃げる** | **見ない** |
| 死因 | 接触 | **理解してしまう** |

§32 が挙げる生還条件のうち「見ない — 怪異を画面内へ入れない状態で移動する」を
初めて実装するCASEにする。同じ engine で違うゲームになることを示す回。

「明るいのに怖い」を作れるのがこの怪異の一番の価値。

## 2. 生還条件と負け条件（§32 §35）

**生還**：祖母の家にたどり着く。

**負け**：**理解度**が満ちる。捕まるのではなく、**分かってしまう**。

### 理解度（Understanding）

- くねくねが **視界に入っている間だけ**上がる
- **遮蔽物の陰にいる間は下がる**
- 距離が近いほど上がりが速い
- 満ちると 「……あ。わかった」 → 暗転 → チェックポイントから再開

これがCASE 02の中心システム。追跡AIは使わない。

### 遮蔽（Cover）

田園に点在する遮蔽物の陰に入ると、視線が切れる。

- 稲架（はさ）
- ビニールハウス
- 軽トラ
- 農具小屋
- 電柱
- 地蔵

**陰は地面に濃い帯として描く。** どこが安全かを文字で説明しない（§20 の思想）。

### プレイの形

遮蔽から遮蔽へ移りながら、家の方向へ進む。
くねくねはゆっくり近づくので、同じ場所に留まり続けることはできない。

> **なぜ「逃げる」を繰り返さないか**
> CASE 01 と同じ動詞にすると、engine の使い回しに見える。
> §31「CASEごとに、その怪異だから成立する逃げ方」を実際にやる回にする。

## 5. くねくねの見せ方

- **常に遠い。** 近づいてこない。ゆっくり距離を詰めるだけ
- 白い。細い。人型ではない
- **不規則に折れ曲がって揺れる**（サイン波の合成＋関節のねじれ）
- 顔は無い。だから見続けると「読もう」としてしまう
- 近いほど、揺れの周期が意味を持って見えてくる（＝理解度の演出）

描画は `world/render-field.js` の `drawKunekune`。骨をベジェで繋ぎ、
時間で歪ませる。CASE 01 の女とは描画系を共有しない。

**理解度が上がるほど、揺れは規則的になる。**
`joints(understanding)` で不規則成分を減らし、周期成分を足す。
「読めてきた」ことを、メーターではなく本体の動きで見せる。

## 10. 実装で仕様から動かしたところ

設計どおりに置いたら成立しなかった箇所と、その理由。

### ① 怪異の「遠さ」は x ではなく y で出す

`show(player, ahead=520)` のつもりだったが、
画面に収まる範囲は世界座標で ±330 程度しかない。520 先は画面外で、
**プレイヤーが自分で見つける余地が消える**（§26）。

→ 前方 `ahead: 210` に立たせ、遠さは `y: -60`（田の向こう）で出す。
CASE 01 の遠景スポーンで踏んだのと同じ穴。

### ② 追ってこないが、離れもしない

「近づいてこない」を素直に実装すると、走れば置き去りにできてしまい、
遮蔽が要らなくなる。

→ `lead`（前方の距離）を保ったまま並走させ、
`driftSpeed` でその距離だけをじりじり詰める。
**どれだけ歩いても同じ距離の田の向こうに居る**ことが恐怖の中身になる。

### ③ 遮蔽は「近づかないと隠れられない」

影を長くすると道のどこにいても陰に入れてしまい、判断が消える。

→ 遮蔽ごとに `reach`（影の届く長さ）を持たせ、B4 以降は短くした。
陰に入るには**田に近い側＝一番よく見える側へ寄る**必要がある。
`Sight.exposure()` は y が小さいほど理解度が速く上がるので、
「隠れるために危ない場所へ行く」という形になる。

### ④ 止まらずに走り抜けたら負けるように調整した

数値を置いただけでは走り抜けられてしまった。
`fillRate 0.27 / fadeRate 0.42 / run 196` で、
**一度も陰で止まらない場合は c9 の手前で理解度が満ちる**。
自動プレイ（陰で待つ）の通しでは理解度の最大が 0.87 前後で、
余裕は残るが油断すると届く。

### ⑤ PHASE の割り込み対策

位置で発火する PHASE が、調査会話の最中に `say()` を上書きすると
調査側の `onEnd` が捨てられて操作が戻らなくなる。

→ `SightMode.updatePhases` は `mode !== 'free'` か会話中なら何もしない。
位置判定なので、手が空いた時点でそのまま発火する。

### ⑥ 帰り道のチェックポイント

Q4 まで戻されると理不尽なので、**陰に入った瞬間**を復帰点にしている
（`CV`）。失敗しても直前の陰から再開する（§35 §36）。
