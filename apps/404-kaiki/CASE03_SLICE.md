## 0. 3本目に何を足すか

CASE を分けるのは舞台ではなく**生還の動詞**（§32）。2本で使った軸はこうなっている。

| | 01 口裂け女 | 02 くねくね | 03 テケテケ |
| --- | --- | --- | --- |
| 時間 | 夜 | 夏の夕方 | 秋の放課後→日没 |
| 場所 | 住宅街 | 田園 | 学校・踏切・線路 |
| 怪異 | 追ってくる | 動かない | **速い。止まらない** |
| 生還の動詞 | 逃げる | 見ない | **上がる** |
| 死因 | 接触 | 理解してしまう | **地面にいた** |
| 緊張の出どころ | 距離 | 空間（どこが安全か） | **時間（いつ来るか）** |

01 と 02 はどちらも「**どこ**にいるか」のゲームだった。
03 は「**いつ**上がるか」のゲームにする。ここが3本目の存在理由。

> テケテケは走って振り切れない。だから逃げるゲームにはできない。
> 上半身しかないので**登れない**。だから上がるゲームになる。
> 怪異の形がそのままルールになっているCASE。

## 2. 生還条件と負け条件（§32 §35）

**生還**：跨線橋の上まで上がりきる。

**負け**：**通過されるときに地面にいた**。

### 通過（Pass）

このCASEの中心システム。追跡AIは持たない。

```
踏切の音が鳴る（警告 約3.2秒）
        ↓
テケテケが画面を横切る（約1.1秒）
        ↓
静かになる。次の音まで歩ける
```

- 高さのあるものの上にいれば、素通りされる
- 地面にいたら負け → 直前の高台から再開（チェックポイント）
- **プレイの形**：音を聞く → 上がる → やり過ごす → 降りる → 進む → また音

CASE 02 の遮蔽は「留まっていれば安全」だった。
ここは**留まっていても次の音が来る**。留まる場所ではなく、留まる**時間**を選ぶ。

### 高さ（Elevation）

engine に3本目の座標 `z` を足す。

- 台の footprint（x, y の矩形）へ**歩いて入るだけ**で上がる。ボタンは無い（§11）
- 出れば降りる
- テケテケが届く高さは `REACH = 26`。**それ以下の台は罠**

| 高さ | 例 | 安全 |
| --- | --- | --- |
| 0 | 地面 | × |
| 〜26 | 縁石・低い花壇・車止め | **×（見た目は台なのに助からない）** |
| 40〜 | 朝礼台・跳び箱・室外機・軽トラの荷台・保線小屋・階段 | ○ |

低い台を混ぜるのは、**「台に乗る」ではなく「高さを見る」**ゲームにするため。
テケテケ自身が手を伸ばす高さを毎回見せることで、文字で説明しない（§12 §17）。

## 3. 5エリア

秋の放課後。日が落ちながら、学校から線路へ降りていく。

| ID | 名称 | 高いもの | 役割 |
| --- | --- | --- | --- |
| A1 | 通学路 | ブロック塀の上・車止め | 歩き方を覚える。音はまだ遠い |
| A2 | 校庭 | 朝礼台・跳び箱・鉄棒・ジャングルジム | **上がるを覚える**。台が多い |
| A3 | 校舎裏と渡り廊下 | 室外機・給食台・階段 | 狭い。台は多いが間が近い |
| A4 | 踏切 | 遮断機の柱・詰所の屋根 | **正面から出る**。通過システム開始 |
| A5 | 線路沿いの土手 | **ほとんど無い**。保線小屋・信号機の台座・跨線橋 | 山場。生還地点 |

**A5 が山場。** 線路の上には登れるものが無い。
台と台の間隔が警告3.2秒でぎりぎり届く距離になっている。

A2 で台を多く与えて「上がれば助かる」を体で覚えさせてから、A5 でそれを奪う。
CASE 02 と同じ構造（B3 でハウスを与えて B4 で奪う）だが、
**奪われるのが場所ではなく余裕**になっている。

### イヤホン（このCASEの装置）

CASE 01 のドア、CASE 02 の双眼鏡に相当する固有装置。
**手に入れた道具が罠**という型は共通、効き方を変える。

- 落とし物箱で**片方だけのイヤホン**を拾う
- 四郎が勝手に耳に入れる（「誰の曲だろ」）
- 以降、**踏切の音が四郎に聞こえない**＝プレイヤーの警告音が遠くなる
- 代わりに**レイとヨツバが叫ぶ**。警告のUIが音から会話に移る（§9 §48）

日常音が「なくなる」ことを恐怖に使う（§51 §52）の直接の実装。
音を消すだけだと理不尽なので、遮断機と画面の縁は残す。

## 5. テケテケの見せ方

- **上半身しかない。** 腕で地面を掻いて進む
- **速い。** プレイヤーの走り（210）に対して通過速度は 3〜4倍
- 通り過ぎるとき、**手を伸ばして高さを測る**（＝REACH を見せる）
- 顔は最後まではっきり描かない。速すぎて見えない、で通す
- 止まらない。振り向かない。**追わない**

くねくねが「動かないから怖い」だったのに対し、
テケテケは「**止まらないから怖い**」。どちらも追跡AIを持たない。

描画は `world/render-school.js` の `drawTekeTeke`。

## 9. 実装で仕様から動かしたところ

### ① 影は地面ではなく足元に落とす

「影を地面に残して、影との距離で高さを見せる」と書いたが、実際に描くと
**台の上に立っているのに浮いて見える**。天板と足のあいだに何も無いため。

→ 影は足元（＝天板）に落とし、地面側に薄いものを重ねる。
高さは「体が持ち上がる」ことと「二つ目の影が下に残る」ことで出す。

### ② 復帰点は「乗った瞬間」ではなく「上がりきった時」

`justOn() && safe()` は永久に成立しない。乗った瞬間は `z` がまだ 0 で、
`z` が上がりきる頃には `justOn()` が false になっているため。
自動プレイでは気づかず、**わざと失敗させて初めて**
チェックポイントが一度も置かれていないことが分かった。

→ 台の id を覚えておき、`safe()` になった時点で一度だけ置く。

### ③ 静寂が短すぎると戦略が一つしかなくなる

A5 の静寂を 1.4 秒にしたら「静かなうちに進む」が成立せず、
**警告中に賭けて走る以外の手が無くなった**。
自動プレイが台のあいだを往復して進まなくなったことで発覚。

→ 2.6 秒へ。短縮率も 0.35→0.22 に緩めた。
「静かなうちに一つ進む」と「鳴っている3.2秒で二つ先へ賭ける」の
二択が成立する幅にしてある。

### ④ 線路を全域に敷いていた

`drawGround` がレールを画面幅いっぱいに描いていたので、通学路にも線路があった。
A4 以降だけに切る。

### ⑤ 空が空っぽ

遠景に何も置いていなかったため画面上半分が無地になった。
遠景の町・校舎・**跨線橋**を低パララックスで置く。
跨線橋は生還地点なので、A1 から見えていること自体が §33 の伏線になる。
