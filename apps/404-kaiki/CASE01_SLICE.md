# CASE 01「口裂け女」 — 5エリア縦切り版 実装仕様

親仕様：[`SPEC.md`](./SPEC.md) §58〜§60 / §72
品質基準：[`QUALITY.md`](./QUALITY.md)

この文書は、完成版（15〜20エリア）ではなく **面白さを確認するための縦切り版** の実装範囲を定義する。

---

## 0. この縦切り版のゴール

説明を読まずに起動した人が、

1. 3人で夜の住宅街を歩き
2. 5個の調査ポイントを踏んで道を広げ
3. 遠くに立っている女を見つけてしまい
4. 前半で見つけていた神社まで逃げ戻って生還する

までを、**5〜7分** で一通り体験できること。

判定は §70 の完成判定と `QUALITY.md` の固有チェックで行う。

## 1. 前提と実装状況

| 項目 | 状態 |
| --- | --- |
| Working Planet の探索エンジン流用 | **行わない**（SPEC §61 で決定）。404の世界は一本道の回廊で、該当部分は合計300行程度にしかならず、経営ゲーム側の前提を分離するほうが高くつくため |
| 共通ログイン | 縦切り版では **実装しない**。進行は `localStorage` に保存し、後で共通IDへ載せ替える（SPEC §65） |
| 描画方式 | Canvas 2D + ES Modules で新規実装した |

`Investigation` / `Anomaly` / `Chase` / `SafeZone` / `Checkpoint` / `Case` / `Log`（§63）は
そもそも Working Planet に存在しないため、いずれにせよ新規実装になる。

将来 Working Planet のエンジンへ載せ替える判断をした場合に備え、以下の境界を守っている。

```
main.js          ループ、シーン管理、会話進行、各システムの結線
core/            404固有ロジック（描画・入力に依存しない）
  case.js          CASE進行、フラグ、エリア開放、チェックポイント、セーブ
  investigation.js 調査ポイントの近接判定と可視判定
  anomaly.js       PHASE管理と出現候補地点の抽選
  chase.js         追跡、先回り、接触判定
  log.js           調査記録の生成
world/           描画・入力・経路・音（後で Working Planet 実装へ差し替え得る層）
  render.js        3レイヤー描画とカメラ
  input.js         可変スティックとキーボード
  path.js          緑ラインの折線生成
  audio.js         環境音の生成（WebAudio）
data/
  case01.js        エリア／調査ポイント／会話／出現候補地点／背景物
```

`core/` は canvas や DOM を参照しない。`world/` の4ファイルを差し替えれば、
`core/` と `data/` はそのまま別の描画・入力系へ載せ替えられる。

セーブの読み書きは `core/case.js` の `load()` / `save()` の2箇所に閉じてある。
共通ログイン統合（SPEC §65）はここを差し替える。

## 2. エリア構成

同じ夜の住宅街を横につないだ1続きの空間として見せる（§19）。エリア境界は画面切り替えではなく、
**通れなかった場所が通れるようになる** ことで表現する（§20）。

```
[A1 住宅街入口] ── [A2 小さな公園] ── [A3 コンビニ裏] ── [A4 細い路地] ── [A5 神社周辺]
       │                                                          │
       └────────────── 逃走ルート（後半のみ・一直線に戻る） ───────┘
```

| ID | 名称 | ランドマーク | 初期状態 | 開放トリガー | 開放時の画面変化 |
| --- | --- | --- | --- | --- | --- |
| A1 | 住宅街入口 | 街灯と電柱の並び、奥の団地 | 開放 | — | — |
| A2 | 小さな公園 | 白いブランコ、給水塔 | 施錠 | `P1` 調査完了 | 公園の門が開く（閉→開のアニメ） |
| A3 | コンビニ裏 | コンビニの緑白の光 | 施錠 | `P2` 調査完了 | 積まれたカゴがどく／店員が中へ入る |
| A4 | 細い路地 | 室外機と自販機の赤 | 施錠 | `P3`（ドア）調査完了 | 裏口のドアが開いたままになる |
| A5 | 神社周辺 | **赤い鳥居**（A1からも遠景で見える） | 施錠 | `P4` 調査完了 | 路地の突き当たりに石段が見つかる |

**A5の鳥居は A1 の背景レイヤーに最初から描く。** プレイヤーが開始直後から
「あの赤いのは何だろう」と思える状態にしておく（§47）。これが終盤の逃走目標になる。

## 3. 調査ポイント

縦切り版では **必須5個 + 任意2個 + 隠し1個**。すべて「近づくだけ」で発火する（§12）。

### 発火条件

- **シロウの座標** が調査ポイントの楕円（横 74 / 縦 58 ワールド単位）に入った時点で発火。
  道は横に長いため真円だと「マークのすぐ手前まで来たのに何も起きない」が発生する。
- 発火時：プレイヤー入力を停止 → 担当キャラが対象へ寄る → 会話 → 世界の変化 → 入力再開（§14）。
- 会話は1〜3往復まで。フィールド上の吹き出しで出す（§50）。

### 必須ポイント

| ID | エリア | 対象 | マーク | 担当 | 内容 | 結果 |
| --- | --- | --- | --- | --- | --- | --- |
| `P1` | A1 | 電柱の貼り紙 | `？` | レイ | 噂の元になった書き込みの現物 | A2 開放 / **CP1** |
| `P2` | A2 | ベンチ横のゴミ箱 | `◎` | シロウ | マスクが大量に捨てられている（公園の奥側） | A3 開放 |
| `P3` | A3 | コンビニ裏口のドア | `◎` | シロウ | **ドア演出**（§22）。中は誰もいないバックヤード | A4 開放 / **CP2** |
| `P4` | A4 | 路地奥の落とし物 | `⌕` | ヨツバ | 割れた手鏡。ここで **PHASE 2（遠景）** 発火 | A5 開放 |
| `P5` | A5 | 鳥居の前 | `◎` | 全員 | **安全地点の伏線**（§33） | **CP3** / PHASE 3 へ |

### 任意・隠しポイント

| ID | エリア | 対象 | 内容 |
| --- | --- | --- | --- |
| `O1` | A2 | ブランコ | 3人の掛け合いのみ。進行に無関係 |
| `O2` | A3 | 自販機 | 肉まんの会話（§9の温度差づくり） |
| `H1` | A4 | 室外機の裏の落書き | `404` に見える落書き。調査記録にのみ残る（§41 の伏線） |

### P3 ドア演出の手順

1. マーク付きドアへ近づく → 3人が止まる
2. 1.2秒 無音
3. ドアノブが動く
4. さらに 0.6秒 遅れて開く
5. 中は **誰もいない**（§23。ここで何も出さないことが後半のドアを怖くする）

### P5 の会話（伏線・§33）

> ヨツバ：「ここだけ静かだね。」
> レイ：「昔から神社の中には入ってこないって話はある。」
> シロウ：「じゃあ怪異出たらここ集合な。」
> ヨツバ：「出る前提なの？」

この会話の直後に **CP3** を打つ。同時に、鳥居の内側を SafeZone として登録する。

| フェーズ | 挙動 |
| --- | --- |

## 5. 怪異出現（PHASE）

### PHASE 遷移

| PHASE | 発火条件 | 内容 |
| --- | --- | --- |
| 0 | 開始時 | 3人がふざけている。環境音（虫・遠くの車・電線）あり |
| 1 | A2 到達 | 街灯が1本消える／犬が鳴いてやむ／NPCが1人いなくなる のうち1つ |
| 2 | `P4` 調査完了 | **遠景出現**。路地の突き当たり、街灯の下に人影 |
| 3 | A5 到達後 | 接近。窓の中／曲がり角／参道の端に、3回まで断続的に見える |
| 4 | `P5` 完了 + 2〜4秒 | 完全出現。ESCAPE へ |

### 3人のリアクション（UIの代わり・§28）

各 PHASE の発火時、画面文字ではなく以下を再生する。

- PHASE 1：レイが振り返る → 「今の、聞こえた？」
- PHASE 2：**ヨツバだけ立ち止まる** → 会話が止まる → 「……ねえ。」 → カメラがわずかに奥へ寄る
- PHASE 3：シロウが強がる → 「い、いや別に普通の人だろ」
- PHASE 4：3人とも黙る → 環境音が全て消える → 足音だけ

### 出現候補地点（§26 / §27）

| PHASE | 候補地点 |
| --- | --- |
| 2 | 路地の突き当たり / コンビニ二階の窓 / 公園の奥のフェンス際 |
| 3 | 参道の端 / 曲がり角 / コンビニの窓の中 / 道の奥 / 団地前の暗がり |

**どの候補が選ばれるかは毎回変わる**（同じ地点を連続では選ばない）。
候補は「どんな場所か・道のどちら側か・高所か」を決め、実際の距離は
プレイヤーから **190〜296 ワールド単位** の帯へ置く。進行方向の先に出す。

> 候補の絶対座標をそのまま使うと縦画面の外に出てしまい、
> 「プレイヤーが先に発見する余地を残す」(§26) が成立しなくなるため、
> 距離は帯で管理する。真横（190未満）には出さない。

遠いほど小さく描画するため、遠景の一体は明確に「遠くに立っている」ように見える。

## 6. ESCAPE フェーズ

### 開始時の変化（§29）

| 要素 | INVESTIGATION | ESCAPE |
| --- | --- | --- |
| 音 | 環境音あり | 環境音消失 → 足音・呼吸・引きずる音のみ |
| キャラ速度 | 歩行 | 走行（約1.6倍） |
| カメラ | やや広い | 寄る + わずかに揺れる |
| 緑ライン | 目的地へ | 神社へ（色・太さ変更） |
| ライティング | 街灯が点いている | 通過した街灯から順に消える |
| 隊列 | シロウが前 | **ヨツバが最後尾**。振り返りモーションあり |

`ESCAPE` の文字は出さない。上の変化だけで伝える。

### 追跡AI（Chase System）

- 怪異の速度はプレイヤーの **0.92倍**。走り続けていれば追いつかれないが、止まると詰められる。
- 経路は最短距離ではなく、プレイヤーが通った経路を遅れて追う。
- プレイヤーが振り返っても停止しない（口裂け女は「見ない」系の怪異ではない）。
- 逃走ルートは PHASE 4 発生地点（A2 付近）→ 鳥居まで一直線。**実測 約20秒**。
  途中で **2回、先回りして道をふさぐ**（後述）ので、体感は約30秒。

> **仕様からの変更**：当初 60〜90秒と書いたが、5エリアの実距離と走行速度では
> 20秒前後にしかならない。速度を落とすか世界を倍にする必要があり、
> どちらもテンポを悪くする。復路の接近フェーズ（約30秒・PHASE 3 の目撃3回）と
> 合わせて「怪異接近＋逃走」で約50秒とし、逃走そのものは短く強くする方針にした。

### 先回り（立ちふさがり）

逃走中の 2 地点で、怪異がプレイヤーの前方へ回り込む。

- **追尾ではなく停止**。2.6秒その場に立ってから追跡を再開する。
- 正面から等速で突っ込ませると、追尾AIの性質上どう動いても接触するため理不尽になる。
  止まっていれば道の奥／手前へ回り込んで抜けられる（§35「捕まっても理不尽ではない」）。
- 発生時：効果音・画面揺れ・レイの「前！前にいる！」で気づかせる。

### 生還条件（§32）

**鳥居をくぐる。** 鳥居の内側に入った時点で怪異は停止する。

- 怪異は鳥居の手前で立ち止まり、そのまま動かない
- 3人は振り返らない
- 数秒間、無音
- 環境音（虫）が戻ってくる

### 捕まった場合（§35）

接触 → 短い恐怖演出（1.5秒以内） → 暗転 → **直前のチェックポイントから再開**。

`GAME OVER` の文字は出さない。理不尽にしない（速度差 0.92 倍と経路遅延で、
正しい方向へ走り続けていれば捕まらない設計にする）。

### チェックポイント

| ID | 位置 |
| --- | --- |
| CP1 | `P1` 調査完了（A2 開放） |
| CP2 | `P3` 調査完了（A4 開放） |
| CP3 | `P5` 調査完了（怪異完全出現の直前） |
| CP4 | ESCAPE 開始時 |

## 8. セーブデータ（縦切り版）

§64 のうち、縦切り版で実際に使うものだけを保持する。キーは `hitobito_404_case01_slice_v1`。

```js
{
  current_case: 'case01',
  case_progress: 'investigation' | 'escape' | 'cleared',
  unlocked_areas: ['A1','A2'],
  investigated_points: ['P1','P2'],
  optional_points: ['O1','H1'],
  checkpoint: 'CP2',
  case_completed: false,
  case_records: { case01: { /* §7 の内容 */ } },
  story_flags: { saw_graffiti_404: true, knows_shrine: true }
```

`knows_shrine`（`P5` 到達）が false の状態では、逃走ラインを再点灯させない。
安全地点を知らないまま逃げる状況は、この縦切り版では発生させない（`P5` が必須のため）。

各段階の後に必ず最初から通しでプレイする（`/GAME_QUALITY.md` の改善ループ）。

### 自動通しプレイで確認済みのこと

Playwright で 390×844 の縦画面を操作し、以下を確認している。

- 必須5個・任意3個すべてが「近づくだけ」で発火する
- 5エリアすべてが調査によって開放される
- CP1 → CP2 → CP3 → CP4 が順に記録される
- PHASE 0 → 1 → 2 → 4 が想定順で発生する
- 逃走で先回り2回を回避して鳥居に到達し、生還 → エピローグ → 調査記録 → `cleared` まで到達する
- 実行時エラーが出ない

### まだ確認できていないこと

- **人が実際に触った時の手触り**（スティックの効き、会話テンポ、詰まる場所）
- 実機のスマートフォンでの表示と性能
- 捕まった時の復帰が「理不尽でない」と感じられるか
- 初見の人が説明なしで緑ラインと調査マークの意味を理解できるか

`GAME_QUALITY.md` の完了条件は、ここを人が確認するまで満たしていない。
