# CASE 01「口裂け女」 — 5エリア縦切り版 実装仕様

親仕様：[`SPEC.md`](./SPEC.md) §58〜§60 / §72
品質基準：[`QUALITY.md`](./QUALITY.md)

この文書は、完成版（15〜20エリア）ではなく **面白さを確認するための縦切り版** の実装範囲を定義する。

---

## 0. この縦切り版のゴール

説明を読まずに起動した人が、

1. 3人で夜の住宅街を歩き
2. 5個の調査ポイントを踏んで道を広げ
3. 遠くに立っている女を見つけてしまい
4. 前半で見つけていた神社まで逃げ戻って生還する

までを、**5〜7分** で一通り体験できること。

判定は §70 の完成判定と `QUALITY.md` の固有チェックで行う。

流用可否が確定するまでは、`Investigation` / `Anomaly` / `Chase` / `SafeZone` / `Checkpoint` / `Case` / `Log` の
**404固有システム側**（§63）から着手する。これらは Working Planet に存在せず、どちらにせよ新規実装になる。

エンジン依存を局所化するため、縦切り版では以下の境界を守る。

```
core/        404固有ロジック（エンジン非依存・移植可能）
  case.js         CASE進行、フラグ、チェックポイント
  investigation.js 調査ポイント判定とイベント発火
  anomaly.js      PHASE管理と出現候補地点の抽選
  chase.js        追跡と接触判定
  log.js          調査記録
world/       描画・入力・経路（Working Planet 流用 or 新規）
data/
  case01.js       エリア／調査ポイント／会話／出現候補地点のデータ
```

`core/` はエンジンAPIを直接呼ばず、`world/` 側が提供するインターフェース越しに座標と距離だけを扱う。

## 2. エリア構成

同じ夜の住宅街を横につないだ1続きの空間として見せる（§19）。エリア境界は画面切り替えではなく、
**通れなかった場所が通れるようになる** ことで表現する（§20）。

```
[A1 住宅街入口] ── [A2 小さな公園] ── [A3 コンビニ裏] ── [A4 細い路地] ── [A5 神社周辺]
       │                                                          │
       └────────────── 逃走ルート（後半のみ・一直線に戻る） ───────┘
```

| ID | 名称 | ランドマーク | 初期状態 | 開放トリガー | 開放時の画面変化 |
| --- | --- | --- | --- | --- | --- |
| A1 | 住宅街入口 | 街灯と電柱の並び、奥の団地 | 開放 | — | — |
| A2 | 小さな公園 | 白いブランコ、給水塔 | 施錠 | `P1` 調査完了 | 公園の門が開く（閉→開のアニメ） |
| A3 | コンビニ裏 | コンビニの緑白の光 | 施錠 | `P2` 調査完了 | 積まれたカゴがどく／店員が中へ入る |
| A4 | 細い路地 | 室外機と自販機の赤 | 施錠 | `P3`（ドア）調査完了 | 裏口のドアが開いたままになる |
| A5 | 神社周辺 | **赤い鳥居**（A1からも遠景で見える） | 施錠 | `P4` 調査完了 | 路地の突き当たりに石段が見つかる |

**A5の鳥居は A1 の背景レイヤーに最初から描く。** プレイヤーが開始直後から
「あの赤いのは何だろう」と思える状態にしておく（§47）。これが終盤の逃走目標になる。

## 3. 調査ポイント

縦切り版では **必須5個 + 任意2個 + 隠し1個**。すべて「近づくだけ」で発火する（§12）。

### 発火条件

- 調査半径 `r = 48px`（ワールド座標）に **シロウの座標** が入った時点で発火。
- 発火時：プレイヤー入力を停止 → 担当キャラが対象へ寄る → 会話 → 世界の変化 → 入力再開（§14）。
- 会話は1〜3往復まで。フィールド上の吹き出しで出す（§50）。

### 必須ポイント

| ID | エリア | 対象 | マーク | 担当 | 内容 | 結果 |
| --- | --- | --- | --- | --- | --- | --- |
| `P1` | A1 | 電柱の貼り紙 | `？` | レイ | 噂の元になった書き込みの現物 | A2 開放 / **CP1** |
| `P2` | A2 | ベンチ横のゴミ箱 | `◎` | シロウ | マスクが大量に捨てられている | A3 開放 |
| `P3` | A3 | コンビニ裏口のドア | `◎` | シロウ | **ドア演出**（§22）。中は誰もいないバックヤード | A4 開放 / **CP2** |
| `P4` | A4 | 路地奥の落とし物 | `⌕` | ヨツバ | 割れた手鏡。ここで **PHASE 2（遠景）** 発火 | A5 開放 |
| `P5` | A5 | 鳥居の前 | `◎` | 全員 | **安全地点の伏線**（§33） | **CP3** / PHASE 3 へ |

### 任意・隠しポイント

| ID | エリア | 対象 | 内容 |
| --- | --- | --- | --- |
| `O1` | A2 | ブランコ | 3人の掛け合いのみ。進行に無関係 |
| `O2` | A3 | 自販機 | 肉まんの会話（§9の温度差づくり） |
| `H1` | A4 | 室外機の裏の落書き | `404` に見える落書き。調査記録にのみ残る（§41 の伏線） |

### P3 ドア演出の手順

1. マーク付きドアへ近づく → 3人が止まる
2. 1.2秒 無音
3. ドアノブが動く
4. さらに 0.6秒 遅れて開く
5. 中は **誰もいない**（§23。ここで何も出さないことが後半のドアを怖くする）

### P5 の会話（伏線・§33）

> ヨツバ：「ここだけ静かだね。」
> レイ：「昔から神社の中には入ってこないって話はある。」
> シロウ：「じゃあ怪異出たらここ集合な。」
> ヨツバ：「出る前提なの？」

この会話の直後に **CP3** を打つ。同時に、鳥居の内側を SafeZone として登録する。

## 4. 緑のガイドライン

| フェーズ | 挙動 |
| --- | --- |
| A1〜A3（PHASE 0〜1） | シロウの足元から次の必須ポイントまで明確に伸びる |
| A4（PHASE 2） | 目的地の手前で **途切れる**。残り数メートルは自分で歩く |
| PHASE 3 | 点滅し、たびたび消える |
| PHASE 4（完全出現） | **完全に消える** |
| ESCAPE 開始（0.8秒後） | 神社（SafeZone）へ向かう **逃走ラインとして再点灯**。色と太さを変える |

再点灯の瞬間は、音を一度落としてからラインを引く。ここが本作の代表演出（§34）。

チュートリアル文言は出さない。開始時にシロウの前から `P1` へラインが伸びているだけにする（§54）。

## 5. 怪異出現（PHASE）

### PHASE 遷移

| PHASE | 発火条件 | 内容 |
| --- | --- | --- |
| 0 | 開始時 | 3人がふざけている。環境音（虫・遠くの車・電線）あり |
| 1 | A2 到達 | 街灯が1本消える／犬が鳴いてやむ／NPCが1人いなくなる のうち1つ |
| 2 | `P4` 調査完了 | **遠景出現**。路地の突き当たり、街灯の下に人影 |
| 3 | A5 到達後 | 接近。窓の中／曲がり角／参道の端に、3回まで断続的に見える |
| 4 | `P5` 完了 + 2〜4秒 | 完全出現。ESCAPE へ |

### 3人のリアクション（UIの代わり・§28）

各 PHASE の発火時、画面文字ではなく以下を再生する。

- PHASE 1：レイが振り返る → 「今の、聞こえた？」
- PHASE 2：**ヨツバだけ立ち止まる** → 会話が止まる → 「……ねえ。」 → カメラがわずかに奥へ寄る
- PHASE 3：シロウが強がる → 「い、いや別に普通の人だろ」
- PHASE 4：3人とも黙る → 環境音が全て消える → 足音だけ

### 出現候補地点（§26 / §27）

PHASE 2 / 3 では、プレイヤーの現在位置から **最低 400px 離れた** 候補地点からランダムに1つ選ぶ。
真横へのスポーンは禁止。

| PHASE | 候補地点 |
| --- | --- |
| 2 | A4 路地の突き当たり / A3 コンビニ二階の窓 / A2 公園の奥のフェンス際 |
| 3 | A5 参道の端 / A4 曲がり角 / A3 コンビニの窓の中 / A1 方向の道の奥 |

同じ地点を連続で選ばない。

## 6. ESCAPE フェーズ

### 開始時の変化（§29）

| 要素 | INVESTIGATION | ESCAPE |
| --- | --- | --- |
| 音 | 環境音あり | 環境音消失 → 足音・呼吸・引きずる音のみ |
| キャラ速度 | 歩行 | 走行（約1.6倍） |
| カメラ | やや広い | 寄る + わずかに揺れる |
| 緑ライン | 目的地へ | 神社へ（色・太さ変更） |
| ライティング | 街灯が点いている | 通過した街灯から順に消える |
| 隊列 | シロウが前 | **ヨツバが最後尾**。振り返りモーションあり |

`ESCAPE` の文字は出さない。上の変化だけで伝える。

### 追跡AI（Chase System）

- 怪異の速度はプレイヤーの **0.92倍**。追いつかれないが、止まると詰められる。
- 経路は最短距離ではなく、プレイヤーが通った経路を遅れて追う。
- プレイヤーが振り返っても停止しない（口裂け女は「見ない」系の怪異ではない）。
- 逃走距離は A5 → A1方向へ戻り、途中で A5 の石段へ折り返す構成。**約60〜90秒。**

### 生還条件（§32）

**鳥居をくぐる。** 鳥居の内側に入った時点で怪異は停止する。

- 怪異は鳥居の手前で立ち止まり、そのまま動かない
- 3人は振り返らない
- 数秒間、無音
- 環境音（虫）が戻ってくる

### 捕まった場合（§35）

接触 → 短い恐怖演出（1.5秒以内） → 暗転 → **直前のチェックポイントから再開**。

`GAME OVER` の文字は出さない。理不尽にしない（速度差 0.92 倍と経路遅延で、
正しい方向へ走り続けていれば捕まらない設計にする）。

### チェックポイント

| ID | 位置 |
| --- | --- |
| CP1 | `P1` 調査完了（A2 開放） |
| CP2 | `P3` 調査完了（A4 開放） |
| CP3 | `P5` 調査完了（怪異完全出現の直前） |
| CP4 | ESCAPE 開始時 |

## 8. セーブデータ（縦切り版）

§64 のうち、縦切り版で実際に使うものだけを保持する。キーは `hitobito_404_case01_slice_v1`。

```js
{
  current_case: 'case01',
  case_progress: 'investigation' | 'escape' | 'cleared',
  unlocked_areas: ['A1','A2'],
  investigated_points: ['P1','P2'],
  optional_points: ['O1','H1'],
  checkpoint: 'CP2',
  case_completed: false,
  case_records: { case01: { /* §7 の内容 */ } },
  story_flags: { saw_graffiti_404: true, knows_shrine: true }
}
```

`knows_shrine`（`P5` 到達）が false の状態では、逃走ラインを再点灯させない。
安全地点を知らないまま逃げる状況は、この縦切り版では発生させない（`P5` が必須のため）。

## 9. 実装順（§72 に対応）

| 順 | 内容 | 完了判定 |
