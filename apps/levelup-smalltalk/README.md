# LEVEL UP — 雑談力アップ

スマホ向けブラウザゲーム。相手の一言から会話の「枝」を見つけ、共感・質問・深掘り・自己開示・話題転換を反射として覚える。

## 実装済み
- 24シチュエーションから毎回8つをランダム出題
- 返答4択を毎回動的生成
- 会話の枝表示（後半は補助を隠す）
- 会話の火 / FLOWコンボ / 尋問モード判定
- 7種類の雑談スキル集計
- プレイ結果に応じたコーチフィードバック
- XP / LEVEL / BEST FLOW / PLAY回数をlocalStorage保存
- 話題発見ラッシュ（5問）
- スマホ縦画面・セーフエリア対応
- 効果音ON/OFF

## デプロイ
静的ファイルのみ。VercelではRoot DirectoryをこのフォルダにしてFramework PresetをOtherにすれば公開可能。
