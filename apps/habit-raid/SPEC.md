# 習慣レイド — 仕様書

## 目的
Habiteggの「習慣登録・時間計測・完了・7日履歴」という基本の習慣管理を残し、1回の実行直後にゲーム報酬を返すことで、継続の初速を上げるLEVEL UP版。

## Before / After
- Before: 習慣は大事だと分かっているが、記録だけでは刺激が弱く、数日で開かなくなる。
- After: 「1回やる → 敵が削れる → XP/コイン → ミッション/宝箱/仲間」という短い報酬ループがあるため、次の1回を始めやすい。

## 基本習慣管理
- 習慣の追加・編集・削除
- 名前、グループ、アイコン、目標時間
- 目標時間0分でも「できた！」で即完了可能
- タイマー開始 / 一時停止 / 再開 / 完了 / 取消
- 1日複数回記録
- 過去7日ドット
- 7日間の回数・取り組み時間・習慣別集計
- localStorage保存

## ゲームループ
1. 習慣を完了
2. 今日のボスへダメージ
3. XP / コイン獲得
4. 3完了ごとにFEVERで報酬増
5. ボス撃破で宝箱
6. 仲間を抽選してコレクション
7. レベルアップでも宝箱

## 継続設計
- ストリークは表示するが、未達による罰・資産没収はなし
- 復帰後すぐゲームループへ戻れる
- ガチャは課金なし。習慣実行だけで回る
- 7回SR以上が出ない場合、次の宝箱はSR以上の救済抽選
- デイリーミッションは 3回完了 / 2種類 / 10分

## Human KPI
「アプリを開いた日のうち、1つ以上の習慣を完了した率」を最重要指標にする。

## 絶対に守ること
ゲーム演出のために習慣登録・完了が面倒にならないこと。ホームで最重要操作「できた！」まで1タップ。
