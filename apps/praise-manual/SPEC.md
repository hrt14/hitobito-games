# 私の褒め方 取説 — SPEC

## 目的
「褒められるのは嬉しいはずなのに、褒め方によっては居心地が悪い」「自分でも、どう褒められると嬉しいのか説明しづらい」人が、10問で自分の好みを言語化し、相手へそのまま渡せる状態にする。

## 中央体験
性格ラベルではなく、相手が次に実行できる「褒め方の取扱説明書」を作る。

## 診断軸
- 人前 / 1対1
- 結果 / 努力・工夫
- 短い一言 / 具体的
- 言葉 / 行動・信頼
- あとで / その場で
- 盛大に / 静かに
- 称賛 / 感謝・役立ち

## 結果
- タイプ名
- 7軸の傾向表示
- 3ステップの褒め方レシピ
- 仕事でそのまま使える例文
- パートナー・友達向け例文
- 刺さりにくい褒め方
- タイミング・温度・意味の細かい取扱メモ

## 共有ループ
本人が10問回答 → 取説完成 → URL共有 → 相手が「この人を褒めるなら」を読む → 自分の取説も作る。

## プライバシー
回答・名前はサーバー保存しない。共有URLには完成した結果のみをエンコードし、各質問への回答そのものは表示しない。

## 表示上の注意
％は10問への自己回答から算出した「好みの傾き」。一般人口での順位、能力、心理学的な標準化得点ではないことを明記する。

## モバイル
390px幅を主対象。1画面1質問。主要タップ領域は十分な高さを取り、説明を読まなくても二択を進められる。
