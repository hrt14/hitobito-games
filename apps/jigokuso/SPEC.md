# 地獄荘 — SPEC

## コンセプト
「下町の廃墟アパートを歩く」こと自体を遊びにした短編探索ホラー。取り壊し前夜の木造アパートで、203号室に残された赤い缶を回収する。

## 体験
怖さの中心は怪物ではなく、残された生活の具体性。家賃袋、鍋、見取り図、子どもの落書き、解体通知など、ごく普通の物を調べるほど建物全体の矛盾が増える。

## コア操作
- 廊下: 扉をタップして入室。
- 部屋: 画面を指でなぞり、懐中電灯の光を動かす。
- 光に入った調査点をタップして残置物を確認。
- 気配が最大になると操作停止イベント。数秒何も触らずやり過ごす。

## 進行
101 / 102 / 103 / 201 / 202 に主要手がかりを1つずつ置く。5つ集めると203が開く。調べる順序は自由。

## 物語
明日取り壊される地獄荘の203号室から「赤い缶」を回収してほしい、と頼まれる。しかし、各部屋の記録は203号室が昔から建物の矛盾の中心だったことを示している。最後の缶に入っている写真は、取り壊し後の日付で地獄荘を写している。

## エンディング
写真の裏には主人公自身の筆跡で「203を、開けたらだめだ。」と書かれている。時間の矛盾だけを残して終了する。
