# 分厚い自分をつくる — Product Spec

## Exact use moment
仕事・人間関係・比較・成功・失敗などで簡単に揺さぶられ、知識としては「反応しない方がいい」と分かっていても現実では反射してしまう人が、1日約3分開き、7種類の短いシミュレーションを反復し、刺激と反応の間に余白を作る型を少しずつ自動化する。

## Central benefit
嫌な感情や欲を消さずに持ったまま、即反応せず、自分で次の行動を選び、取り乱しても日常へ戻れる反応の型を身につける。

## Problem / design rationale
本を読んで「受容」「レジリエンス」「反応しない」などを知るだけでは、強い刺激が来た瞬間の反射まで変わりにくい。そこで、心の厚みに近い複数の研究領域を1つの独自モデルへまとめ、毎日同じ型を異なる現実場面で反復する。

このアプリの「心の厚み」は検証済みの単一心理尺度ではない。以下7領域の研究概念を統合した独自のトレーニングモデルである。

1. 余白 — Equanimity / Non-reactivity
2. 受容 — Acceptance
3. 距離 — Decentering / Defusion
4. 曖昧さ — Tolerance of Uncertainty（Negative Capabilityの実証側の近縁概念として扱う）
5. 奥行き — Wise Reasoning / Intellectual Humility
6. 軽やかさ — Nonattachment / Psychological Flexibility
7. 復元 — Resilience

## Core interaction
1セッションで7種の操作を1回ずつ行う。

- 余白: 3秒間、反応ボタンを押さず待つ。その後に行動を選ぶ。
- 受容: 嫉妬・恥・見栄などの感情を「消す」のではなく「ここに置く」。
- 距離: 文を「事実 / 頭が足した物語」に分類する。
- 曖昧さ: 今はまだ分からないものだけを選び、未確定のまま置く。
- 奥行き: 相反して見えるが同時に成立する2つの見方を残す。
- 軽やかさ: 欲を0にせず、握りすぎない位置へスライダーを動かす。
- 復元: 気持ちが完全に戻るのを待たず、日常へ戻る最小の一歩を選ぶ。

操作そのものが対象スキルを模倣するため、理論の長い解説を毎回読ませない。

## First 10 seconds
トップに「分厚い自分をつくる」「取り乱さない人ではなく、取り乱しても戻れる人へ」と表示し、主ボタンは「今日の7つを稽古する」の1つだけ。説明を読まなくても、1日3分の反復トレーニングだと分かる。

## Success condition
アプリ内では、各スキルの最近7回の実行安定度が上がること。現実では、セッション後に1つだけif-then型の実戦課題を持ち帰り、翌日の自己報告で「できた / 気づいた」を増やすこと。

## Uniqueness
既存LEVEL UPアプリが1つの思考法や特定場面を鍛えるのに対し、このアプリは「反応しない・受容・脱中心化・不確実性耐性・賢い推論・非執着・回復」を1セッションで横断し、同じ人格的な反応パターンとして統合・反復する。

## Repeat-use strategy
毎日7能力すべてを別シナリオで反復し、最近7回の実行を層として可視化する。最後に最も弱い能力から現実世界の1アクションを出し、翌日に実行を振り返る。知識ではなく反射を変えるため、再訪そのものがプロダクト価値になる。

## Title rationale
- Main user benefit/motive: 簡単に揺さぶられない、奥行きと回復力のある自分になる。
- Why this title is direct and specific: ユーザー自身が目指す状態をそのまま「分厚い自分」と表現し、診断名や抽象的な心理用語を前面に出さない。
- How it matches the actual app: 7つの心理的スキルを「層」として毎日反復し、画面上でも厚みとして蓄積する。
- Market/uniqueness checks actually performed (if any): 今回はタイトルの市場検索を完成条件にせず、ユーザーが指定した中核概念を優先した。
