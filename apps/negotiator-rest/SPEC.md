# NEGOTIATOR｜休ませる — Product Spec

## Exact use moment
仕事・家事・勉強を止めた方がよいと頭では分かっているのに、「忙しい」「やることがある」「今止まる方が不安」と反射的に休息を拒否している人が開く。ユーザーは休むことに同意しなくてもよく、会話の中で要求を小さく交渉しながら、終了時には少なくとも数十秒の身体的・注意的な中断を実際に経験している状態を目指す。

## Central benefit
**休む気がない状態のままでも、最小の休息を実際に始められる。**

## Problem / design rationale
「休んだ方がいい」という正論は、忙しさや未完了感が強い場面では大きすぎる要求になり、ユーザーは内容より先に拒否しやすい。本アプリは拒否を失敗扱いせず、交渉材料として扱う。

設計に使うのは、要求サイズを変える交渉、段階的コミットメント、自律性を守る選択、実行可能な最小行動への分解、明示的な選択内容だけを反映する会話である。

- 最初はわざと大きな要求を出し、NOのあとに要求を急激に小さくする。
- 小さなYESを積み、実際の身体行動へつなげる。
- 「休む」という言葉自体への抵抗が強ければ、水を一口飲む、肩を落とす、画面から目を外す、息を吐く、という別名の小行動へ切り替える。
- ユーザーが押していない属性・感情・事情を推測して断定しない。
- いつでも終了できる。拒否を無視して拘束する設計にはしない。

本アプリは医療的な診断・治療を目的にしない。体調不良や強い症状がある場合の判断を代替しない。

## Core interaction
主役は「要求カード」である。ユーザーが抵抗を選ぶたびに、画面上の要求サイズが物理的に縮み、交渉条件が「2週間 → 5分 → 1分 → 水一口 → 肩を落とす → 画面から10秒離れる → 一呼吸」のように小さくなる。

通常の会話では毎回、原則として1つの受諾と2つの自然な抵抗を提示する。これは単なるクイズではなく、**拒否理由そのものが次のカウンターオファーを決める操作**として機能する。

会話の途中に、読むだけではない実行フェーズを挟む。

- 水を飲んだら「飲んだ」を押す。
- 肩・あごの力を抜く短いホールド操作。
- 画面を暗くして視線を外す短いカウント。
- ゆっくり吐く時間をリングで可視化する。

この実行時間は「休息残高」として積み上がる。ユーザーが「休む」と言わなくても、結果として仕事・画面・緊張から離れた秒数が増える。

## First 10 seconds
初回表示で以下だけを見せる。

- `NEGOTIATOR`
- 「あなたを休ませます。NOで構いません。」
- 最初の大きな要求カード「2週間、全部休みませんか？」
- 3つの選択肢
- 小さな「終了」

説明画面は置かない。最初のNOを押した瞬間に要求カードが縮み、「では5分だけ。」へ変化することで遊び方を理解させる。

## Success condition
セッション成功は、以下のどちらかを満たした時。

1. ユーザーが1分以上の休息タイマーを自分で開始する。
2. 休むことへの明示的な同意がなくても、水・脱力・視線オフ・呼吸などのマイクロ休息を合計30秒以上実行する。

終了画面では「YESの数」ではなく、実際に仕事・画面・緊張から外れた秒数と、最初の要求からどこまで小さく交渉したかを表示する。

## Uniqueness
他のLEVEL UPが「休息の必要度を診断する」「疲れを分類する」「境界線を引く」ことを主にするのに対し、本アプリは**休息を拒否している最中のユーザーとその場で交渉し、NOを材料に要求サイズを変え続けて、実際の数十秒の休息まで連れていく**点が固有である。

## Repeat-use strategy
毎回同じ心理テストを繰り返すのではなく、開いた時の抵抗理由に応じて交渉ルートを変える。セッション後に「今回どこまで値切ったか」「実際に休めた秒数」「前回の最小合意」をローカル保存し、次回は前回より小さい入口も選べる。

このアプリは毎日ログインするためのものではなく、**止まれない瞬間のレスキューツール**として再訪価値を持たせる。

## Title rationale
- Main user benefit/motive: 心地よくなるため／健康を守るため／忙しさから短時間離れるため。
- Why this title is direct and specific: シリーズ名 `NEGOTIATOR` と、実際に起きる結果「休ませる」をそのまま組み合わせている。
- How it matches the actual app: アプリは助言記事ではなく、ユーザーの拒否に対して条件を変えながら休息を交渉する。
- Market/uniqueness checks actually performed (if any): 今回はシリーズ名をユーザーが明示的に決定しているため、新たな市場タイトル調査は行っていない。
