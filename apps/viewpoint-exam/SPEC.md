# 物の見方検定 — 実装仕様

## コンセプト
「ポジティブ思考を学ぶ」のではなく、どんな出来事にも別の見方を瞬時に作れる反射を鍛える。
キャッチコピー: **不幸は選べない。見方は選べる。**

## 10種類の見方の型
- 残ったものを見る
- 比較の幅を広げる
- 時間を伸ばす
- 学びに変える
- 機会に変える
- 制約を利用する
- ネタにする
- 次の一手を見る
- 相手側から見る
- 今あるものを見る

## セッション
- 10ラウンド
- 1ラウンド10秒
- 1〜3問: 初級
- 4〜6問: 中級
- 7〜9問: 上級
- 10問: 達人級

## 1ラウンド
- 画面中央に「起きたこと」と、事実を否定しないための短いアンカー文。
- 8個の候補を2列で表示。
- 6個は有効な別視点、2個は罠。
- 有効な候補をタップすると VIEW +1、得点、見方の型をその場で開示。
- 罠は「事実否定」「根拠のない楽観」「他責」「全か無か思考」など。-80点 + 残り1.25秒。
- 時間切れ後、使った型と見逃した見方を1つ表示。

## 得点
- 有効な見方: 100点 + 残り時間ボーナス + 多様性ボーナス
- 無効な見方: -80点 + 1.25秒ペナルティ
- 5 VIEW以上かつミス0: +300点
- ランク判定は SCORE / VIEW / 正確さ / 使った型数を複合評価。

## 継続
localStorage に以下を保存:

## 非目標
- 「何でもポジティブ」と判定すること
- 重大な出来事の痛みを軽視すること
- AI APIがないと遊べない自由記述採点
