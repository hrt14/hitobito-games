# 十分やった — Product Spec

## Exact use moment
資料・メール・企画・分析などがすでに使える状態なのに、80点→100点へ直し続け、提出・送信・終了が遅れている時に開く。

## Central benefit
雑に妥協するのではなく、**目的達成・致命的な穴・追加30分の改善幅を3問で判定し、止める条件を満たしたら終了させる。**

## Core mechanic — LAST PATCH
対象を1件入力して3問。
1. いまの状態で本来の目的を満たす？
2. 出したら困る致命的な穴がある？
3. 次の30分で結果が大きく変わる？

`目的YES / 致命穴NO / 大改善NO` → `十分やった。出す。`
それ以外 → 修正を無限追加させず、**最後に直す1件だけ**を決める。1件を直したら再判定へ戻る。

## Why game
完成度スコアを上げるゲームではなく、STOP条件を通過して作業を終えるゲーム。修正券は1枚だけ。

## End state
- 終了判定が出る、または最後の修正1件が決まる
- 終了時に `これ以上は改善ではなく追加作業。` と表示
- 「出した／送った／閉じた」の現実行動ボタンで完了

## Uniqueness
品質を下げるアプリではない。**追加時間に見合う改善がもうない仕事を検出して、終わらせる**ことに特化。

## Quality target
分かりやすさ9 / 役立ち度9 / 操作8 / 独自性9 / 継続性8。
