# 見えない残高 — Product Spec

## Exact use moment
日常の中で誰かに渡せた親切・感謝・手助けを忘れず積み上げたい人が、行動の直後や一日の終わりに10〜30秒だけ開き、「今日も少し残せた」と確認しつつ、言葉や見せ方で崩した部分にも責めずに気づける状態になる。

## Central benefit
人に渡した小さなプラスと、自分の言葉・見せ方への気づきを、ひとつの「残高」として毎日見える化する。

## Problem / design rationale
親切や感謝は実行しても記憶に残りにくく、逆に失言や愚痴だけが印象に残ることがある。そこで、正の行動は残高へ積み、気づきが必要な言動は残高が半分になるという強いが単純なルールで、日常の行動を観察しやすくする。

背景として、小林正観氏が「不平不満・愚痴・泣き言・悪口・文句」の5つを「五戒」と呼んでいたことは、本人名義の書籍内容を紹介するダイヤモンド・オンラインの記事で確認できる。

- https://diamond.jp/articles/-/305563

一方、「五戒を言うと残高が半分」「人に見せると残高が半分」という厳密な半減ルールは、今回確認できた信頼できる一次・準一次資料では確認できなかった。そのため、本アプリでは**小林正観氏の公式ルールとして扱わず、気づきを行動に結びつけるための独自ゲームルール**として明示する。

本アプリは特定の人物・宗教・団体の公式サービスではない。宇宙、神、徳、波動、集合意識などの断定的な語彙は前面に出さず、「見えないところにも行動は残る」という比喩だけを採用する。

## Core interaction
### 積む
中央の残高の下にある「ひとつ積む」を押し、次の具体的な行動カテゴリから1つ選ぶ。

- 助けた
- 頼まれごとをした
- 感謝を伝えた
- 譲った
- 整えた
- 笑顔にした
- その他

選ぶと残高が +1 され、画面中央の「見えない場」に光の粒が落ちて波紋が広がる。数字だけでなく、空間の密度が少し増えることで蓄積を感じる。

### 気づく
主操作より一段弱い「気づいたことがある」を押すと、次を選べる。

- 不平不満
- 愚痴
- 泣き言
- 悪口
- 文句
- 積んだことを人に見せた・自慢した

確定すると現在残高を `floor(残高 / 2)` にする。赤い罰演出や失敗音は使わず、場の光が静かに半分へまとまり、「気づけた。ここで区切り。ここからまた積める。」と返す。

この操作は「罰」ではなく、自分の言葉・見せ方に気づいて区切るためのもの。

### 残す
現在残高とは別に、減らない「積んだ総数」と「気づいた回数」を保存する。残高が減っても、過去の実践と気づき自体は消えない。

データはブラウザの localStorage のみに保存し、自由記述や個人情報は収集しない。

## First 10 seconds
最初の画面には以下だけを主役として表示する。

1. タイトル「見えない残高」
2. 一言「今日、人に渡したものを積む。」
3. 大きな現在残高
4. 光の粒が漂う場
5. 主ボタン「＋ ひとつ積む」
6. 小さな副ボタン「気づいたことがある」

説明を読まなくても「積むと残高が増える」ことが分かる。初回のみ主ボタンの近くに「親切・感謝・手助けを1つ記録」と短く表示する。

## Success condition
1回の利用で、ユーザーが少なくとも1つ「人に渡せた行動」を記録する、または1つ「言って／見せてしまったこと」に気づいて区切れる。

継続利用では、現在残高だけでなく「積んだ総数」「気づいた回数」「今日の積み上げ」が残り、正の行動への注意が日常で増えることを目指す。

## Uniqueness
既存の「ありがとう探し」は日常にすでにある支えを見つける観察トレーニング。本アプリは、**自分が外へ渡した行動を残高化し、さらに言葉・見せ方への気づきで現在残高が変動する自己観察システム**なので、同じ感謝テーマでも操作・目的・継続理由が異なる。

## Repeat-use strategy
親切・感謝・手助けは毎日起こるため、行動直後に10秒で積める日次ツールとして使う。現在残高は増減する一方、「積んだ総数」と「気づいた回数」は長期で残る。日付が変わっても残高は継続し、「今日 +N」だけをリセットする。

## Title rationale
- Main user benefit/motive: 自分の小さなプラスを見える形で積み上げ、気分よく続ける。
- Why this title is direct and specific: 「残高」で蓄積、「見えない」で物質的なお金ではないことを短く示す。
- How it matches the actual app: 画面中央の現在残高が、積む／気づく操作で実際に増減する。
- Market/uniqueness checks actually performed: Web検索で「見えない残高」完全一致のアプリ名・書名を確認したが、同名の主要アプリ／書籍は確認できなかった。一般語として記事本文等での使用例はあるため、独占性を断定しない。
