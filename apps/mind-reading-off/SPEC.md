# 考えすぎストップ。— Product Spec

## Exact use moment
相手の短い返信・表情・沈黙を見て「怒っているかも」「嫌われたかも」と意味を読みすぎ、まだ確認できないことを頭の中で反芻して疲れた人が、2〜3分で観察事実と推測を分け、必要なら確認できる一言まで戻す。

## Central benefit
相手の気持ちを推測してしまっても、それを事実扱いせず、取り越し苦労を小さくする。

## Problem / design rationale
曖昧な出来事に意味を足した時、その意味を観察可能な事実と混同すると不安が膨らみやすい。NHSのCBT thought recordで用いられる「状況・思考・別の見方」を分ける考え方を、日常会話向けの短い仕分け操作にした。医療診断・治療の代替ではない。

## Core interaction
具体的な対人シーンで、文を「見えた事実」「推測・ストーリー」へタップ仕分けする。実戦モードでは自分の出来事を「事実→推測→別の可能性→確認」の4枠に分ける。分類操作そのものが、対象スキルである認知の切り分けと一致する。

## First 10 seconds
「相手の気持ちは見えている事実と同じではない」と一文で示し、すぐ「5シーン練習する」「今の出来事を整理する」を選べる。

## Success condition
15文の仕分け後に再利用ルールを言語化でき、自分の出来事でも4枠を埋められる。

## Uniqueness
`approval-off` や `kanji-warukatta` は他者評価と自分の行動を分けるが、このアプリは曖昧な対人手掛かりから「相手の内面を読んだことにする」瞬間を、観察事実と推測へ直接仕分けることに特化する。

## Repeat-use strategy
シーン練習で反射を作りつつ、実際に気持ちを読みすぎた瞬間にREAL MODEを何度でも使う。

## Title rationale
- Main user benefit/motive: 取り越し苦労から抜けて楽になる。
- Why this title is direct and specific: 問題である「考えすぎ」を止める用途をそのまま示す。
- How it matches the actual app: 事実と推測を分け、思考の暴走を止める操作と一致する。
- Market/uniqueness checks actually performed: LEVEL UP既存カタログで `approval-off`, `kanji-warukatta`, `boundary`, `levelup-control` を確認し、対象行動が異なることを確認。
