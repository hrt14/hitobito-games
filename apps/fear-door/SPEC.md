# 恐怖のドア — 実装仕様

## コンセプト
ドアを上下左右へスワイプして進む1本指ホラー迷路。開ける方向で次の道が変わる。プレイヤーは脱出を目指していると思うが、主人公は最初から研究所の主任研究員であり、最深部へ実験を再開しに戻っている。

## 1プレイ
約3〜5分。13枚のドア。各ドアは4方向に結果を持ち、安全ルート、行き止まり、ゾンビ遭遇を混在させる。

## 操作
- ドアを少しドラッグ: 隙間から向こう側を覗く。
- 閾値以上へスワイプ: その方向へ開けて進む。
- ゾンビ出現: 開けた方向と逆へ素早くスワイプして閉める。
- キーボード: 矢印キーでデバッグ・PCプレイ可能。

## 物語構造
1. 主人公は状況を知りすぎているが説明しない。
2. 管理者認証が自然に通る。
3. 「主任を止めろ」という記録に主人公が不自然に冷たい。
4. 実験体を番号で呼ぶ。
5. システムが CHIEF として認証する。
6. 被験者側の音声が主人公を「先生」と呼ぶ。
7. 終盤、生存研究員が「博士」と呼ぶ。
8. 主人公が「そのために来た」と答え、脱出ではなかったことが確定する。
9. 最終室で CHIEF RESEARCHER 黒瀬 仁 と表示し、「第47回を始めよう」で締める。

## 技術
依存ライブラリなしの静的 HTML / CSS / JavaScript。Pointer EventsでiPhone Safariを含むタッチ操作に対応。音はWeb Audio APIによる簡易効果音のみで外部音源不要。
