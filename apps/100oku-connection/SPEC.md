# 目の前の人が100億円 — Product Spec

## Exact use moment
仕事や日常で会った人・小さな依頼・雑談を「今すぐ役立たないから関係ない」と即座に切りそうな人が、3分で「全部に深く関わらなくていいが、低コストの接点は残せる」という判断へ切り替えるために開く。

## Central benefit
価値がまだ見えない出会いを、0か100かで扱わず「細い接点を残す」選択肢を持てるようになる。

## Problem / design rationale
人は時間と注意が限られているため、目先の目的に関係しないものを切るのは合理的である。一方で、偶然の出会いは会った瞬間に将来価値を判別できない。本アプリは「全員に深く関わる」ことを勧めず、限られた注意10の中で、0（切る）・1（糸を残す）・3（深く聞く）を配分させる。中心原則は、深掘りは選ぶが、未来から戻れる細い道は安く残せる、という非二択化。

100億円の事業展開は、考え方の変化を可視化するためのフィクションであり、実際の利益を保証・予測するものではない。

## Core interaction
6つの出会いが順番を変えて現れ、ユーザーは1本のスライダーを動かして接点への注意を配る。

- 0: ここで切る
- 1: 一言返す・連絡先を残す
- 3: 深く聞き、次の約束を決める

操作すると、中央の自分と相手を結ぶ線が「消える / 細く残る / 太く残る」に変わる。全員を深掘りすると注意が足りなくなるため、ユーザーは「全部切る」でも「全部深掘る」でもない配分を身体的に練習する。最後に残った線同士が数年後の事業連鎖として接続される。

## First 10 seconds
最初の画面に「目の前の人が100億円」「6つの偶然に、限られた注意を配る」「全員に深く関わる余裕はない。でも、全部切る必要もない。」を表示し、主ボタンは「偶然の連鎖を始める」の1つだけにする。開始後は最初の出会い、残り注意、3点スライダーが同一画面に出る。

## Success condition
セッション終了時に、ユーザーが「0か3だけでなく1の糸を残す」というルールを理解し、6接点中5〜6本を残しながら一部だけを深掘りできること。結果画面では、残した接点・深掘り数・フィクション上の連鎖額を可視化する。

## Uniqueness
既存の10x-thinkingが「目の前の仕事を量・質・波及で拡張する」訓練なのに対し、本アプリは「価値の見えない人・偶然との接点を、限られた注意の中でどの濃さで残すか」をネットワークとして体験するため、代替できない。

## Repeat-use strategy
出会いの順番を毎回シャッフルし、誰が後の何につながるかを最初は伏せる。同じ10の注意でも配分によって連鎖が変わり、100億円ルートに届くまで再試行できる。端末内にセッション数と最高到達額を保存する。

## Title rationale
- Main user benefit/motive: お金を儲けるため / 好奇心を満足させるため。ただし実際の金銭成果を約束するのではなく、機会を見落とさない考え方を体験する。
- Why this title is direct and specific: 「目の前の人」「100億円」という具体的な距離と桁を並べ、アプリの中心ストーリーをそのまま表す。
- How it matches the actual app: 目の前の6人との接点を残すほど、数年後のフィクション上の事業連鎖が最大100億円まで育つ。
- Market/uniqueness checks actually performed (if any): 2026-08-25にWeb検索で完全一致「目の前の人が100億円」および site:amazon.co.jp の完全一致検索を実施。検索結果には同名のAmazon商品は表示されなかった。ただしAmazon内部検索の完全な重複保証ではない。
