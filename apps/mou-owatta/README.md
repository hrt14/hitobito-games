# もう終わった。

「クヨクヨしない」を、前向きな気分ではなく**思考の終了動作**として反射化する3〜5分のスマホ向け訓練ゲーム。

## ゲームループ

1. 小さな嫌な出来事が起きる
2. 頭に浮かぶ言葉を「事実 / 想像 / 次にできること」に分類
3. 「変えられる / もう変えられない / 自分では決められない」を判断
4. 次回に使える行動を1つだけ保存
5. 再生ボタンの誘惑を止めて「これはもう終わった。」で閉じる

後半ほど、返信がない・沈黙の意味など、物語を作りやすい曖昧な状況になる。

## 狙い

- 反省と反芻を分ける
- 事実と想像を高速で分ける
- コントロール可能性を判断する
- 改善案を1個だけ残す
- 新情報のない再生を止める

## 実装

依存なしの静的HTML/CSS/JavaScript。`index.html` をHTTPサーバーで配信すれば動作する。

## ローカル確認済み

- 390pxスマホ幅で横スクロールなし
- 10ステージ完走
- 事実 / 想像 / 次の一手のカード順を毎ステージシャッフル
- 誤分類、誤ったコントロール判定から復帰可能
- 再生を繰り返すほど思考スロットが埋まり、終了力スコアが下がる
- 最終画面で現実用の4手を再提示
