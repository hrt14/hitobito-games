# 『ありがとう探し』実装品質チェック

## 初見
- [ ] タイトルから観察ゲームだと伝わる
- [ ] 1画面目に「10秒で支えを見つける」と出る
- [ ] 操作はタップだけ
- [ ] 説明を閉じなくても開始できる

## コアループ
- [ ] 10秒タイマーが正確に進む
- [ ] 正解候補を押すと即座にノードが増える
- [ ] 同じ候補を二重加点できない
- [ ] ミスはコンボだけ切り、得点を奪わない
- [ ] 候補が枯れて進行不能にならない
- [ ] 3ラウンドで必ず結果へ進む

## 見た目
- [ ] 開始時と10発見後のスクリーンショットが明確に違う
- [ ] 中央の生活シーンが主役として大きい
- [ ] 支えノードはカテゴリごとに見分けられる
- [ ] 文字が小さすぎない
- [ ] 320px幅で横スクロールしない
- [ ] ボタンのタップ領域は44px以上

## ゲーム感
- [ ] 3連続、7連続、10連続で演出差がある
- [ ] ×10以上で達成感がある
- [ ] 1正解ごとに音・動き・光のうち2つ以上が返る
- [ ] 終了画面で発見の幅・深さが見える
- [ ] 結果から次のラウンドへ1タップで進める

## 思想
- [ ] 「感謝しなさい」と書いていない
- [ ] 苦痛・喪失を無理に肯定する問題を入れていない
- [ ] 人格を褒めたり評価したりしない
- [ ] 観察した事実・種類・連鎖をフィードバックする

## 技術
- [ ] 外部APIなし
- [ ] 外部CDNなし
- [ ] JavaScript構文エラーなし
- [ ] コンソールエラーなし
- [ ] localStorage失敗時もプレイ可能
- [ ] 音OFFが保存される
