# 90%は、もうある。 — SPEC

## 目的
「残っている不満・不安」に視線を奪われて、すでにある充足が見えなくなる状態から、まず“あるもの”を認識し、そのうえで残る不快を1%単位に小さく扱える状態へ変える。

## Before
暗い10%が頭の中の100%を占めているように感じ、すでにあるものが視界から消えている。

## After
すでにあるものを3つ具体的に認識し、残る不快を「全部解決」ではなく「次の1%」として扱える。

## 最小ループ
1. 100マス中90マスが最初から明るい世界を見る
2. 今日すでにあるものを3つ選ぶ
3. 残る10%に名前をつける
4. 1%だけ軽くする一手を選ぶ
5. 暗い1マスを上へスワイプする
6. 90→91%の画面変化を見る
7. 最大3回まで1%ずつ繰り返す

## 重要な設計ルール
- 90/100は幸福度の測定値ではなく、視線切り替えの比喩と明記する。
- 不快を扱う画面でも、明るい90マスを消さない。
- 「全部解決」を要求しない。
- 1セッション最大3%まで。100%化をゲームの勝利条件にしない。
- “あるもの”はユーザーが当てはまるものだけ選ぶ。押し付けない。

## Human KPI
- 1セッションで「すでにあるもの」を3つ選べた率
- 不快を1%単位の行動へ変換できた率
- 90→91%以上の体験完了率

## データ
端末内 localStorage のみ：セッション回数、前回選んだ「すでにあるもの」、最終パーセント。
