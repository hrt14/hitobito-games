# 境界線マップ — Product Spec

## Exact use moment
頼まれごとを引き受けた後、または誰かに振り回された後に「なんでまた引き受けたんだろう」と感じている人が、SNSや友人との会話の合間、あるいは寝る前に、自分の傾向を確かめたくなって開く。

## Central benefit
自分がどの領域（時間・お金・感情・価値観）で頼みごとを断りにくいかを、20個の具体的な頼まれごとへの反応から可視化し、次に同じ状況が来たときに使える一言を持ち帰る。

## Problem / design rationale
「断れない」は抽象的な自己認識として語られがちで、どの領域で・なぜ起きているかが本人にも見えていないことが多い。20個の異なる現実的な頼まれごとに素早く反応させることで、内省ではなく実際の判断パターンからすり減りやすい領域を検出する。自己申告（このアプリを開く前の主観的な断れなさ）と、実際の反応から出た数値を対比することで、思い込みとのズレそのものが気づきになる。

## Core interaction
頼まれごとカードをスワイプ（またはボタンタップ）で「引き受ける」か「断る」に振り分ける。スワイプという物理的な仕分け動作が、日常で頼まれごとに直感的に反応する瞬間そのものを模している。各カードへの反応直後に、その選択がどの境界線にどう効くかの短い洞察を返すことで、判定ではなく認識のフィードバックにしている。

## First 10 seconds
見出し「頼まれると断れず、気づけば疲れている。」と20問への導入文、4つの軸の一覧、自己申告スライダーが最初に見える。スライダーを動かすかボタンを押せばすぐ最初のカードが表示され、迷わず始められる。

## Success condition
20問に答え終えると、4軸のバー・タイプ診断・持ち帰るルール・自己申告とのギャップが表示される。ユーザーが「自分がどこですり減りやすいか」を具体的な言葉で言えるようになれば成功。

## Uniqueness
既存のLEVEL UPには「課題の分離」「アサーティブ」「揉めそうでも必要なお願い」など個別シーンの練習アプリはあるが、時間・お金・感情・価値観という4軸を横断して自分の傾向を数値化し、シェア可能な診断結果として提示するアプリは無い。単一シーンの練習ではなく、20個の多様な状況からパターンを検出する診断設計がこのアプリ固有の価値。

## Repeat-use strategy
セッションごとの結果をlocalStorageに保存し、前回との軸別の変化を提示する。またすり減りやすい軸だけを再確認する5問のミニリトライを用意し、全20問をやり直さなくても弱点の変化を追える。

## Title rationale
- Main user benefit/motive: 頼まれると断れず疲れている自分の傾向を、具体的な軸で理解したい
- Why this title is direct and specific: 「頼まれると断れず疲れる人の」で対象読者を明示し、「境界線マップ」で得られる成果物（可視化された地図）を明示している
- How it matches the actual app: 実際に4軸のマップ（バーチャート）が結果として出る
- Market/uniqueness checks actually performed (if any): リポジトリ内の既存 `apps/boundary`（仕事の集中/休息の切り替えゲーム）とは扱う問題・インタラクションが異なることを確認済み
