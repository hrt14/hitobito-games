# 30問でわかる 市場年収診断 — Product Spec

## Exact use moment
今の自分の市場価値がどのくらいか気になるが、現在の年収を入力したり長文を書いたりせず、スマホで数分だけ客観視したい人が、30個の選択肢をタップして「会社員としての市場年収レンジ」と、そのレンジを押し上げている要因・次に伸ばしやすい要因を持ち帰る。

## Central benefit
現在年収を入力せずに、自分の市場年収の目安と「何が年収を押し上げているか」を3〜4分で把握できる。

## Problem / design rationale
年収は単一要因で決まらず、経験年数だけでも役職だけでも説明できない。厚生労働省の賃金構造基本統計調査は、賃金実態を雇用形態・職種・年齢・学歴・勤続年数・経験年数等で明らかにする調査であり、年収を考える際には複数要因を見る必要がある。国税庁「令和6年分 民間給与実態統計調査」では、1年を通じて勤務した給与所得者の平均給与は478万円、正社員（正職員）は545万円とされている。

本アプリは求人票データや個別企業の報酬テーブルを使う査定サービスではない。正社員平均545万円を中間基準に置き、回答を「キャリア」「責任範囲」「専門性」「事業インパクト」「希少性」「市場反応」の6軸へ変換し、広いレンジとして返すヒューリスティック診断とする。性別・家族構成など、能力・仕事内容と関係しない属性は質問しない。

Sources:
- 国税庁「令和6年分 民間給与実態統計調査」 https://www.nta.go.jp/publication/statistics/kokuzeicho/minkan/gaiyou/2024.htm
- 厚生労働省「令和7年賃金構造基本統計調査 結果の概況：調査の概要」 https://www.mhlw.go.jp/toukei/itiran/roudou/chingin/kouzou/z2025/gaiyo.html

## Core interaction
30枚の質問カードを1枚ずつ見て、自分に最も近い選択肢をタップする。自由入力欄・数値入力欄・スライダーは一切置かない。選択すると即座にカードが進み、6セクションを通過していく。

これは「自分の市場価値を、年収そのものではなく構成要素に分解して棚卸しする」という診断目的に一致する。現在年収を先に入力させないため、現年収に診断結果が引っ張られる体験も避ける。

## First 10 seconds
最初の画面に以下だけを大きく見せる。
- 「30問でわかる 市場年収診断」
- 「年収入力なし / すべてタップ / 約3分」
- 「診断する」ボタン

開始後は質問文と選択肢だけが主役。選択肢タップで自動的に次へ進むため、説明書を読まなくても操作が分かる。

## Success condition
終了時にユーザーが以下を3点とも把握できること。
1. 推定市場年収レンジ
2. 自分の年収を押し上げている上位2要因
3. 次に年収を上げるなら、どの要因を伸ばす余地が大きいか

結果は端末に保存し、再訪時には前回レンジと今回レンジを比較できる。

## Uniqueness
既存LEVEL UPは思考・習慣・感情・行動の反射トレーニングが中心だが、このアプリは「仕事の市場価値を6軸に分解し、現在年収を聞かずに市場年収レンジへ変換する」職業価値の棚卸しに特化しているため代替できない。

## Repeat-use strategy
毎日使うアプリではない。役割変更・転職検討・大きな成果・昇進・スキル獲得など、キャリアの状態が変わった時に再診断する。前回結果をローカル保存して比較し、変化が見えることを再訪理由にする。

## Title rationale
- Main user benefit/motive: お金を儲けるため / 知識を得るため / 好奇心を満たすため
- Why this title is direct and specific: 「市場年収」「30問」「診断」で、何が分かるアプリかを一読で示す。
- How it matches the actual app: 実際に30問すべて選択式で、市場年収レンジを返す。
- Market/uniqueness checks actually performed: 一般的な検索語として「年収診断」「市場価値診断」が使われることを前提に、奇抜な造語は採用しない。タイトルの独自性そのものは主目的ではないため、誇張表現やNo.1表現は使わない。
