# やらないことを決める — Product Spec

## Exact use moment
仕事や私生活の「今日やること」が増えすぎて、全部重要に見え、どれから手を付けるか決められない人が開く。終了時には「今日守る1つ」と「今日はやらないもの」が明文化され、着手先が1つに絞れている。

## Central benefit
全部を抱える状態から抜け、今日いちばん重要な1つに集中できる。

## Problem / design rationale
選択肢が多いほど、魅力的な候補同士を比較し続けて決められなくなる。さらに「やらない」を決めない限り、選ばなかった候補も脳内では未完了の仕事として残る。本アプリは、重要なものを追加するのではなく、先に「守る基準」を1つ選び、候補を物理的に捨て、最後の1つだけを残す構造にする。

既存の `zenbu-yaranai` は仕事量が破綻しそうな場面で、守る・縮める・逃がす・捨てるを使って最低限へ圧縮する緊急避難ツール。本アプリは破綻回避ではなく、魅力的な候補の中から積極的に優先順位をつけ、1つへ集中する意思決定ツールとする。

## Core interaction
1. 今日やろうとしている候補を3〜7件入れる。入力が面倒な場合は日常の候補チップを1タップで追加できる。
2. 今回守る基準を「成果・締切・健康・家族・余白・納得」から1つ選ぶ。
3. 候補カードを1枚ずつ見て、右の「残す」か左の「今日はやらない」へスワイプ／タップする。残せるのは最大3件。
4. 3件以下になったら最終ラウンドで残した候補同士を比較し、1件だけを「今日の一番」にする。
5. 終了時に「今日の一番」「今日はやらない」「後で見直す」を1画面で固定し、コピーできる。

カードを実際に画面外へ捨てる操作そのものが「やらないと決める」練習になる。選択肢を追加するゲームではなく、減らすほど画面が静かになる体験にする。

## First 10 seconds
最初の画面で「今日、全部はできません。1つ守るために、やらないことを決める。」と表示し、その直下に候補追加欄と日常チップを置く。説明を読まなくても「候補を入れる → 絞る」が分かる。過去の結果があれば前回の「今日の一番」を小さく表示する。

## Success condition
セッション終了時に候補が1件の「今日の一番」まで絞れ、少なくとも1件が「今日はやらない」に移動している。開始前後で「全部やらなきゃ感」を0〜10で取り、下がったかどうかも可視化する。

## Uniqueness
`important-first` は重要度×緊急度の4象限判断、`zenbu-yaranai` は破綻回避、`suteru-yuki` 本作は魅力的な候補を実際に削除し、最後の1件まで絞ること自体が主役。既存アプリでは代替できない。

## Repeat-use strategy
タスクが増えて頭が散った瞬間に何度でも使える短時間ツール。前回の「今日の一番」と、これまで何件を「今日はやらない」にできたかを端末内に保存する。ログインボーナス等は付けない。

## Title rationale
- Main user benefit/motive: 時間を節約し、重要なことに集中する。
- Why this title is direct and specific: 「優先順位」「集中力」のような抽象語ではなく、ユーザーが実際に行う行動をそのままタイトルにした。
- How it matches the actual app: 候補を削り、最後に「今日はやらない」リストを確定する体験そのもの。
- Internal uniqueness check: 既存LEVEL UP内を確認し、同目的の新規アプリを増やさず既存 `suteru-yuki` を全面改修した。`zenbu-yaranai` / `important-first` とは利用場面と主操作を分離している。
- External title check (2026-08-27): WebおよびAmazon.co.jpドメイン検索を実施。書籍では完全一致タイトルは確認できなかったが、2026-04-28発売の大平信孝『やらないことを決める技術　仕事も人生も「戦略的先送り」でうまくいく』（ソシム、ISBN 978-4-8026-1538-9）という近似タイトルを確認した。Amazon Musicには「やらないことを決める」という同名エピソードも確認した。したがって「同名書籍なし／近似書名あり」と記録し、書籍名そのものを借用したタイトルではない状態を維持する。
