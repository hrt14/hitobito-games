# 何もしないコスト — Product Spec

## One-line promise
先延ばししていることについて、「今やる痛み」だけでなく「待つことで失う可能性」も同じ画面に並べ、待つことが準備のための「滑走路」なのか、不快感を避けるための「麻酔」なのかを自分で判断できるようにする。

## Exact use moment
やった方がいいのは分かっているが、面倒・不安・失敗への怖さ・気まずさなどから、決める／始めることを先延ばししている瞬間。

## Desired outcome
- 行動する側のコストだけを見ていた状態から、何もしない側の機会損失も比較材料に入れられる。
- 「今すぐやるべき」と一律に押さず、待つことに意味がある場合は具体的な準備期間として設計できる。
- 単なる回避なら、今できる最小の一手を1つ決めて終えられる。

## Core distinction
### 滑走路
待つことで情報・準備・選択肢などが具体的に増え、判断し直す条件や時点を言える待ち方。

### 麻酔
主な目的が、いま感じている不快感や不安を一時的に避けることになっている待ち方。

この二分はユーザー自身が判断するためのフレームとして使い、アプリが診断結果を断定しない。

## Core loop
1. いま先延ばししていることを1つ入力する。
2. 「今やると嫌なこと」を最大3つ選ぶ。
3. 天秤で「今やる痛み」と「何もしない未来」を比較する。
4. 1週間 → 3か月 → 1年と時間を進めると、待つ側の見落としやすい比較材料が現れる。
5. 「これは滑走路？ 麻酔？」を自分で選ぶ。
6. 滑走路なら、待つことで何を増やすか／いつ判断し直すかを具体化する。
7. 麻酔なら、負担の小さい次の一手を1つ決める。
8. 最後に「今見えていたもの／見えていなかったもの／決めたこと」を1画面で確認する。

## First 10 seconds
ファーストビューに長い説明を置かない。

- タイトル: 「何もしないコスト」
- サブコピー: 「やる痛みだけ見て、決めてない？」
- 入力: 「いま先延ばししていること」
- 例チップ: 返信する / 企画に着手 / 予約する / 人に連絡 / 応募する
- CTA: 「公平に比べる」

## Interaction design
### Step 1 — 入力
自由入力1件。入力は外部送信・保存しない。

### Step 2 — 今見えている痛み
選択肢:
- 面倒
- 怖い
- 失敗したくない
- 断られたくない
- 時間が足りない
- 気まずい

最大3つ。選択結果は天秤の左側に置く。

### Step 3 — 天秤
左: 「今やる痛み」
右: 「何もしない未来」

開始時は右側を「まだ見えていない」にする。時間ボタンを押すたびに、以下の比較材料を追加する。

#### 1週間
- 頭の片隅を占有し続けるかもしれない
- 最初の一歩で得られたはずの情報が、まだない

#### 3か月
- 試して修正できたかもしれない回数
- 積めたかもしれない経験
- 別の選択肢を知る機会

#### 1年
- 積み上げられたかもしれない経験
- 出会えたかもしれない機会
- 方向転換に使えた時間

未来の結果を断定しない。「〜かもしれない」「〜できたはずの可能性」という表現を使う。

天秤の傾きは比較材料が増えたことを視覚化する演出であり、客観的な重さ・点数を意味しない。画面上にもその旨を短く表示する。

### Step 4 — 滑走路 / 麻酔
カードを2枚表示。

- 滑走路: 「待つほど、準備や選択肢が増える」
- 麻酔: 「待つ主目的が、今の嫌さを避けること」

ユーザー自身がどちらかを選ぶ。

### Step 5A — 滑走路を選んだ場合
必須入力:
- 「待つことで何を増やす？」
- 「いつ／何が揃ったら判断し直す？」

空欄のまま終了できない。曖昧な先送りを、条件つきの準備期間に変える。

### Step 5B — 麻酔を選んだ場合
「今できる一手」を1つ選ぶ。

候補:
- 対象を開く
- 必要なものを1つ出す
- 1文だけ書く
- 5分だけ触る
- 自分で決める

自分で決める場合は短い自由入力を出す。

## Result screen
見出し: 「比較して、決めた。」

- 今見えていたもの: 選んだ即時コスト
- 見えていなかったもの: 時間を進めて確認した未来側の比較材料
- 今回の判断: 滑走路 / 麻酔
- 決めたこと: 再判断条件 または 次の一手

偽のスコア、成功率、損失額は出さない。

## Share
共有文には、ユーザーが入力した先延ばし内容を初期状態では含めない。

例:
「先延ばしを『滑走路か麻酔か』で見直しました。何もしないコスト — LEVEL UP」

Web Share APIが使えない環境ではクリップボードコピーへフォールバックする。

## Privacy
- 入力内容をネットワーク送信しない。
- localStorage等へ永続保存しない。
- URL、共有文、analyticsイベントのラベル等へ自由入力を含めない。

## Accessibility / mobile
- 片手で押しやすいタップ領域。
- キーボード操作可能。
- `:focus-visible` を用意。
- エラーは `aria-live` で伝える。
- `prefers-reduced-motion` では天秤などの移動アニメーションを抑える。
- 色だけで選択状態を伝えない。

## Why this app is distinct from 3sec-action
「3秒で動け」が着手そのものを小さくするアプリなら、本作は「やるコストしか見えていない比較」を組み替える意思決定アプリ。待つことも有効な選択として残し、「滑走路」にできる場合は行動開始を強制しない。

## Completion criteria
- 初見10秒以内に何を入力し何が得られるか分かる。
- 入力 → 痛み選択 → 天秤 → 時間比較 → 滑走路/麻酔 → 分岐 → 結果までスマホで完走できる。
- 滑走路分岐・麻酔分岐の両方を完走できる。
- 戻る／やり直す操作で破綻しない。
- 自由入力が共有・保存・URLへ漏れない。
- 数値化できない機会費用を偽の点数で表現しない。
- 本番URLで実操作確認する。
