# 正観スイッチ 仕様書

## 目的
小林正観の著作・公式管理サイト等で確認できる考え方を、「知っている」から「日常の出来事が起きた瞬間に使える」へ移すためのLEVEL UP総合トレーナー。

## 身につける5つの型
1. 五戒を増やさない：不平不満・愚痴・泣き言・悪口・文句に気づき、事実と次の行動へ戻る。
2. 受容：起きたことを好きになるのではなく、現実を起点に次を選ぶ。
3. 感謝：感情を強制せず、日常を支えている人・仕組み・道具・自然を見つける。
4. 喜ばれる存在：安全と余力の範囲で、頼まれごとや小さな親切を行動にする。
5. そ・わ・か：掃除・笑い・感謝を、頭で考え続けないための小さな行動として使う。

## コアループ
- 5問1セット。
- 各型から1問ずつランダム出題。
- 日常場面 → 3択 → 即時フィードバック → 次へ。
- 反応時間は測るが制限時間は設けない。自動遷移は禁止。
- 正誤より「型を現実で一度使う」ことを最終導線にする。

## 現実モード
「今、起きた」から以下を選び、10〜30秒の行動へ変換する。
- イラッとした
- 予定外・損した
- 当たり前に見える
- 頼まれた
- 空気・気分が重い

既存の専用ゲームへ必要に応じて接続する。
- 予定外・損した → もう払った。
- 当たり前に見える → ありがとう探し
- 断る必要がある → 断る力

## 安全設計
- 「受け入れる」を危険・虐待・違法・健康問題の放置へ使わない。
- 「頼まれごと」を無条件服従として教えない。安全、健康、法令、契約、余力を先に確認する。
- 感謝や笑顔を感情の強制にしない。
- 科学的・医学的効果を主張しない。

## UX
- モバイル優先。
- 問題と3択を主要画面で読みやすくする。
- タイムアウトで読めなくなることは禁止。
- 選択後の解説はユーザーが「次へ」を押すまで残る。
- キーボード入力なし。
- localStorageのみ。

## データ
- セッション数
- 判断数
- 正解数
- 型別正答数
- 現実モード実行数

ストリーク、ランキング、課金、外部APIは使わない。

## 完了条件
- 5つの型が1セッションで一巡する。
- 40問以上。
- 5種類の現実モード。
- 320px幅で主要操作可能。
- 音OFF可能。
- リロードで記録が壊れない。
- 現実モードから専用トレーニングへ遷移できる。
