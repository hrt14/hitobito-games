# まとまる。 — SPEC

## 目的
散らかった情報を見た瞬間に「要するに → なぜ → だから」の3点へ落とし、結論・根拠・次の一手を短時間で作れる反射を鍛える。

## Before / After
- Before: 情報を全部同時に考え、説明も判断も長くなる。
- After: まず結論を1つ置き、根拠を1つ選び、次の一手まで短くまとめられる。

## コアループ
1. 仕事・会議・企画・生活などの散らかった状況を読む。
2. 制限時間内に「要するに」を4択から選ぶ。
3. 「なぜ」を選ぶ。
4. 「だから」を選ぶ。
5. 3点にまとまった完成形を3秒見る。
6. 7問繰り返す。

## 難易度
- 0〜2セッション: 20秒
- 3〜6セッション: 15秒
- 7セッション以降: 10秒

## 実戦モード
現実の案件を「要するに / なぜ / だから」の3行へ30秒で整理する。自由記述は保存しない。コピーのみ可能。

## Human KPI
- 7問の平均整理時間
- 3要素の正答率
- 継続セッション数

## 完了条件
- 初見10秒以内に型が分かる。
- 1問目から説明書なしで進める。
- 正解・不正解が即座に分かる。
- 7問後に速度と正答率が見える。
- 実戦モードへ自然につながる。
