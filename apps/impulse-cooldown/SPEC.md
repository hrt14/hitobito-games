# 24時間、寝かせる。 — Product Spec

## Exact use moment

ネットショッピングで欲しいものを見つけ、カートに入れた瞬間、指がすぐ「購入」ボタンに伸びる人が、実際に決済する前にこのアプリを開く。商品名と価格を入力し、なぜ欲しくなったか・無くても今日困るか・1週間後も欲しいかを数十秒でチェックし、「今すぐ買う／24時間だけ寝かせる／やめておく」を自分でタップして決める。終了時には、衝動のまま購入ボタンへ向かっていた状態から、時間を置く・見送るという選択肢を自分で選んだ状態に変わっている。

## Central benefit

衝動買いによる後悔を減らし、本当に欲しいものだけにお金を使えるようにする。

## Problem / design rationale

衝動買いは、SNS・セール・「今日だけ」といった外部トリガーが引き起こす即時的な感情反応であり、その強さは数時間〜1日で大きく弱まることが多い。問題は「意志の弱さ」ではなく、購入までの摩擦（時間差）が無さすぎることにある。

このアプリは、購入前に強制的な摩擦（24時間の時間差）と、3つの短い判別質問（動機・必要性・持続性）を挟み、System 1（即断）からSystem 2（検討）へ判断を引き戻す。24時間後にもう一度同じ商品について問う「見直し」フローが、時間経過による感情の減衰を実際に体験させる。

## Core interaction

1. カートに入れた商品の名前と価格を入力する（実際の買い物の代理入力）。
2. 「今、なぜ欲しくなった？」を5つの理由チップから1つ選ぶ（SNS・セール・今日だけ・気分転換・ずっと欲しかった）。
3. 「無くても今日困る？」「1週間後もまだ欲しい？」に1問ずつ即答する。
4. 商品カードと「衝動サインの強さ」のヒントを見ながら、「今すぐ買う／24時間だけ寝かせる／やめておく」の3つの箱へ商品を仕分ける（タップで確定）。
5. 「24時間だけ寝かせる」を選んだ商品はロッカーに入り、24時間後にホーム画面の「見直す」に浮上する。同じ商品についてもう一度「今も欲しい？」と問われ、「買う／やめる／もう24時間だけ」を選ぶ（延長は1回まで）。

質問に正解・不正解はなく、最終判断は常に自分の指でどの箱に入れるかを選ぶタップ操作で行う。これは「診断結果に従う」のではなく、「時間を置いてから自分で選び直す」という行動そのものを反復して身につけるための設計。

## First 10 seconds

初期画面はチュートリアルなしで、タイトル「24時間、寝かせる。」直下に「＋ 今ほしいものを追加」の大きなボタンを最上部に置く。ユーザーは説明を読まずに、今まさに欲しいものの名前と金額を入力してすぐ判定フローへ入れる。

## Success condition

セッション終了時に以下が成立すること。

- 商品が「買う／寝かせる／やめる」のいずれかに明確に仕分けられている。
- 「やめる」を選んだ場合、浮いた金額が合計節約額に加算され、画面に表示される。
- 「寝かせる」を選んだ場合、24時間後に再判断する予定がロッカーに記録され、ホームで確認できる。
- 24時間経過後の見直しフローで、最初の判断と異なる結論（買う⇄やめる）に変わることがある＝時間差が実際に判断へ影響したことが確認できる。

## Uniqueness

既存のLEVEL UPアプリはタスク・感情・人間関係・キャリアの反射訓練が中心で、実際のお金の使い方・購入判断を扱うアプリは存在しない。suteru-yuki（すでにある選択肢から残すものを選ぶ）やzenbu-yaranai（仕事の仕分け）とは対象と目的が異なり、「これから使うお金」を対象にした唯一のアプリであるため、他アプリに置き換えられない。

## Repeat-use strategy

このアプリは一回で終わる診断ではなく、ネットショッピングで何かを欲しくなるたびに実際に使う実務ツール。さらに「24時間だけ寝かせる」を選ぶと24時間後に強制的な見直しトリガーが発生するため、ログインボーナスのような人工的な仕掛けなしに自然な再訪が生まれる。累計節約額と「よく手放す理由」の傾向は、使うほど意味が増す成長指標になる。

## Title rationale

- Main user benefit/motive: お金を節約する／衝動買いの後悔から逃れる。
- Why this title is direct and specific: アプリの中心メカニクスである「24時間待つ」をそのままタイトルにしており、何をするアプリか一目で分かる。
- How it matches the actual app: 中心操作である「24時間だけ寝かせる」ボタンと直接対応している。
- Market/uniqueness checks actually performed: この実装セッションではライブのWeb検索を実行していない。「24時間ルール」自体は一般的な消費者行動の知恵として広く知られた表現であり、固有名詞としての独占は主張しない。本番公開前に改めて完全一致タイトルの衝突有無を確認することを推奨する。
