# 友達から見たあなた — Product Spec

## Exact use moment
「自分ではこういう人間だと思っているけれど、周囲からも同じように見えているのか？」が気になった人が、約1分で自己評価を終え、その場で友達3人へ同じURLを送って答えを待つ。

## Central benefit
自分の自己評価と、実際の友達3人から見た印象の差を5項目・0〜100で並べて見られる。

## Core viral loop
1. 本人が10問に回答する。
2. サーバーが公開用session idと、本人専用owner tokenを発行する。
3. 本人は公開用URLを友達3人へ送る。
4. 友達は本人の自己評価を見ずに、同じ5項目について10問回答する。
5. 回答は個票として保存せず、5項目の合計値だけをsessionへ加算する。
6. 本人ページは0/3 → 1/3 → 2/3 → 3/3を自動更新する。
7. 3人目の回答時点で、自己評価 vs 友達3人平均の比較結果を解放する。
8. 回答した友達には「自分も3人に聞いてみる」CTAを出し、次の共有ループへつなぐ。

## Questions / dimensions
10問、5項目。各項目2問ずつ。
- 冷静さ
- 親しみやすさ
- 自己主張
- 信頼感
- 気づかい

回答は4段階（かなり違う / やや違う / ややそう / かなりそう）。文章入力、氏名、メール入力はない。

## First 10 seconds
ファーストビューで「友達から見たあなた」と、結果例「冷静さ 自分81 → 友達46」を見せる。主要CTAは「まず自分で10問に答える」1つ。直下で「自分で10問 → 友達3人へURL → 差分を見る」の3ステップを見せる。

## Result gate
比較結果は友達3人が揃うまで表示しない。本人回答後は0/3のロック画面を表示し、友達用URL共有を主操作にする。1人・2人時点では個別スコアも平均スコアも表示しない。

## Privacy / security
- 友達用URLには本人の自己評価を埋め込まない。
- 本人結果の取得にはowner tokenが必要。
- owner tokenはURL hashと本人端末localStorageに保持し、友達用共有URLには含めない。
- 友達の個別回答はFirestoreへ保存しない。sessionには5項目の累計値、回答人数、重複防止用response hashだけを保持する。
- 4人目以降の回答はサーバー側で拒否する。
- 同一response idの再送は重複加算しない。

## Backend
Firebase Functions v2 `howSeenApi` + Firestore `howSeenSessions`。
- `POST /session`: 本人session作成
- `GET /session/:sid/public`: 受付状況のみ取得
- `POST /session/:sid/response`: 友達回答を集計
- `GET /session/:sid`: owner tokenを検証して本人用集計結果を返す

## Success condition
本人が10問を完了し、1つの専用URLを友達へ共有できる。3人の回答後、本人画面が手動の返却URL取り込みなしで自動的に3/3へ進み、5項目比較と最大差分が表示される。

## Uniqueness
他のLEVEL UPアプリが基本的に一人で完結するのに対し、このアプリは「友達3人の実回答」がないと結果が完成しない。共有ボタンを宣伝機能ではなく、プロダクトの必須工程にしている。

## Repeat / acquisition loop
友達側の完了画面に「自分も3人に聞いてみる」を置くため、1 sessionあたり最大3人が次の本人ユーザー候補になる。結果画面からは別の3人で新しいroundを開始できる。

## Title rationale
タイトルは「友達から見たあなた」。内容をそのまま表し、意味のない言葉遊びを避ける。「他人」よりも実際の参加者である「友達」を明示し、誰の評価なのかを具体化した。
