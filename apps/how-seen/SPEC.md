# 他人からどう見えてる？診断 — Product Spec

## Exact use moment
自分が周囲からどう見られているか気になった人が、SNSや会話の流れで60秒だけ使い、自己イメージと友人の見え方の差を具体的な4軸で知る。

## Central benefit
「自分が思う自分」と「他人から見える自分」のズレを、友人の実回答で可視化する。

## Problem / design rationale
人は自分の内面・意図は知っていても、他人が観察しているのは主に行動であるため、自己認識と他者認識は一致しないことがある。このアプリは、診断ロジックが「他人からこう見える」と断定するのではなく、まず本人の自己像を出し、その後に実際の友人へ同じ4軸を別質問で評価してもらう。結果を共有しないと体験が完成しないため、共有自体がプロダクト機能になる。

## Core interaction
本人は8つの「どちらが自分に近い？」二択を即断する。結果後、友人用URLを送る。友人は本人の自己評価を見ずに、観察可能な行動について8つの二択で評価する。返却URLを本人が開くと、その回答が端末内に追加され、複数人の平均と自己像を並べて比較する。二択の内容は抽象的な性格語ではなく、相談、初対面、トラブル、断り方、ミス対応など具体場面にする。

## First 10 seconds
ファーストビューに「他人からどう見えてる？」と「自分が思う自分と、他人から見える自分。いちばんズレているのはどこ？」を表示し、主要操作は「8つの二択で診断する」1つだけ。所要時間と入力不要も同時に見せる。

## Success condition
本人が自己像の4軸を確認し、少なくとも1人に判定URLを共有できること。友人回答が返った場合は「ズレ / 100」と最大差分軸が表示され、本人が自分の見え方について1つ具体的な発見を得ること。

## Uniqueness
既存LEVEL UPが主に本人の思考・行動を一人で変えるのに対し、このアプリは「他人の実回答」を入力として初めて完成し、共有行動そのものを診断プロセスにしている。

## Repeat-use strategy
友人の回答が増えるほど平均値が更新されるため、2人目・3人目に送る理由がある。同じ返却リンクを開くたび端末内に回答が蓄積される。サーバーに個人評価を保存しない。

## Title rationale
- Main user benefit/motive: 好奇心を満たす／他人からどう見られているか知る／自分を語りたい
- Why this title is direct and specific: 「他人からどう見えてる？」というユーザー自身の疑問をそのままタイトルにした。
- How it matches the actual app: 実際に友人回答を取り込み、自己評価と比較するため、単なる推定診断よりタイトルとの整合性が高い。
- Market/uniqueness checks actually performed (if any): 今回は市場サジェスト・Amazonタイトル検索は未実施。タイトルはユーザー提供のタイトルチェックリストに沿って、得・好奇心・簡単さ・率直さ・具体性・内容整合を優先した。
