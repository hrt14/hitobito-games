# 寝る前3分 全部うまくいくイメトレ — Product Spec

## Exact use moment
寝る直前、「成功した場面をイメージするといい」と思っていても、目を閉じた瞬間に何を考えるかが曖昧で、仕事・明日・人間関係・お金・やりたいことなど別々の考えへ散ってしまう人が開く。2〜3分の操作で、今夜見る未来を「始まり → 最高の瞬間 → 安心の余韻」の3カットに固定し、アプリを閉じた後はその3場面を順番に再生するだけの状態にする。

## Central benefit
目を閉じてから「何をイメージすればいい？」と迷わない。今夜見る3つの具体的な成功シーンを完成させる。

## Problem / design rationale
「全部うまくいく場面を想像する」という指示だけでは自由度が高すぎ、寝る直前に新しく内容を考え続ける余地が残る。本アプリは、目標や願望の長文を書かせるのではなく、未来を3つの短い映像キューへ圧縮する。

設計上の重要点は、最後を興奮のピークで終わらせず、「全部終わったあとの安心」にすること。アプリの役割は未来を保証したり睡眠を治療したりすることではなく、就寝前に再生するイメージ内容を具体化・整理することに限定する。

## Core interaction
1. 「今夜、何をうまくいかせる？」から、明日／仕事／人間関係／お金／やりたいこと／人生全体を選ぶ。必要なら一言だけ補足する。
2. 3コマのフィルムストリップが表示される。ユーザーは順番に、各コマへ短い映像素材を入れる。
   - CUT 1 始まり: 「全部うまくいく日の最初の1秒。どこにいて、何が見える？」
   - CUT 2 最高の瞬間: 「何が起きたら『全部うまくいった』と確信する？」＋必要なら「誰かの一言」
   - CUT 3 安心の余韻: 「全部終わったあと、どこで、どんな安心を感じている？」
3. 各回答を「カットに入れる」操作でフィルムストリップへ収める。入力を続けるのではなく、曖昧な未来を視覚的な3枠へ固定する操作自体が目的と一致する。
4. 3カット完成後、「もっと鮮明にする」で任意のディテールを1つだけ追加できる（見えるもの／聞こえる一言／体の感じ）。強制しない。
5. 「目を閉じる準備」で画面を低刺激な暗色へ落とし、3カットを1枚ずつ大きく表示する。最後に「準備できました。ここから先は、うまくいくところを見るだけです。」と表示し、「画面を伏せる」でほぼ黒い画面にする。
6. 完成した3カットは端末内に保存し、次回は「昨夜の3シーンをもう一度」「もっと鮮明にする」「新しく作る」から選べる。

## First 10 seconds
暗い低刺激画面にタイトル「寝る前3分 全部うまくいくイメトレ」、短い説明「目を閉じてから迷わない。今夜見る3シーンを先に作る。」、そして「今夜、何をうまくいかせる？」の6つの大きな選択肢を同時に表示する。説明を読まなくても、テーマを1つタップすれば始まることが分かる。

## Success condition
終了時にユーザー自身の言葉で3つのカットが画面上に並び、目を閉じたあとに「始まり → 最高の瞬間 → 安心の余韻」の順で何を再生するかが一目で確認できる。最後の消灯モードまで進める。

## Uniqueness
既存の「預けて、寝る。」は就寝時の複数の未解決事項を明日の枠へ外部化して反芻を止めるアプリであり、本アプリの目的は逆に「今夜あえて残す1本のポジティブな未来映像を具体化する」こと。「成功マインド診断」は12の意思決定から成功関連の判断パターンを診断するアプリで、就寝前の映像編集機能は持たない。本アプリだけが、寝る直前に3カットの脳内映画を作り、画面を消した後の再生順まで固定する。

## Repeat-use strategy
毎晩テーマを変えて新しい3カットを作れる。前回のシーンが今も大事なら、そのまま再生するか、ディテールを1つだけ追加して鮮明にできる。日記のように長文を蓄積するのではなく、「今夜見る3カット」を更新し続ける軽い夜のルーティンにする。

## Title rationale
- Main user benefit/motive: 心地よくなる／幸せな未来を具体的にイメージしやすくする／時間をかけずに寝る前のイメトレを準備する。
- Why this title is direct and specific: 「寝る前3分」で使用タイミングと短さ、「全部うまくいく」で作る世界のルール、「イメトレ」で実際の行為をそのまま示す。抽象的な造語や言葉遊びを使わない。
- How it matches the actual app: 実際に寝る前約3分で、全部うまくいった前提の3シーンを作り、目を閉じて再生する準備をする。
- Market/uniqueness checks actually performed (if any): 2026-08-31にWebで「寝る前3分 全部うまくいくイメトレ」を完全一致検索し、同一タイトルの明確なサービス・商品は確認できなかった。Amazon.co.jp対象の完全一致Web検索でも同一タイトルの明確な商品は確認できなかった。ただし、これは商標・著作権等の法的クリアランスを意味しない。「寝る前3分」「イメージトレーニング」は一般的に使われる表現として扱う。
