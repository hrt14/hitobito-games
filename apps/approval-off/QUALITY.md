# 他人軸OFF — Quality Checklist

## Purpose
- [x] 「承認欲求ゼロ」ではなく「判断のハンドルを自分へ戻す」が目的になっている。
- [x] 相手の評価と自分の行動を、実際の操作で分ける。
- [x] 個人リセットと反射訓練が同じ原則でつながる。

## First 30 seconds
- [x] タイトル直下で「承認はもらっていい。判断のハンドルだけ渡さない。」と目的が分かる。
- [x] メインCTAが1つ明確。
- [x] 個人リセットは長い説明を読まず開始できる。

## Interaction
- [x] 評価カードは右スワイプ + ボタン + キーボードで完了できる。
- [x] 反射訓練は左右スワイプ + 2ボタン + キーボードで回答できる。
- [x] スワイプ失敗時はカードが自然に戻る。
- [x] 正誤フィードバックが即時に出る。

## Mobile
- [x] safe-area対応。
- [x] 主ボタンは52px以上。
- [x] 360px幅でも2列カードが崩れない。
- [x] 短い端末高さ向けレイアウトあり。
- [x] prefers-reduced-motion対応。

## Privacy
- [x] 自由入力をlocalStorageへ保存しない。
- [x] 共通計測へ自由文を送らない。
- [x] 永続保存はトレーニング集計のみ。

## Product integrity
- [x] 他人を無視することを推奨しない。
- [x] フィードバックと「評価そのもの」を混同しない。
- [x] 精度・速度はトレーニング結果としてのみ表示する。
- [x] 共有文に個人入力を含めない。
