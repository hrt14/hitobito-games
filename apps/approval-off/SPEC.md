# 他人軸OFF — Product Spec

## Product promise

承認欲求を「なくす」と約束しない。人の評価が気になった瞬間に、**他人が決める評価**と**自分が決める行動**を分け、意思決定のハンドルを自分側へ戻しやすくする。

## Before / After

- Before: 「どう思われるか」が判断基準になり、自分が本当にやりたい行動と他人から欲しい評価が混ざっている。
- After: 「評価は相手。行動は自分。」と切り分け、今日の自分の行動を1つ選べる。

## Core flows

### 1. 今すぐ自分軸に戻す
1. 誰の評価が気になるか選ぶ。
2. 必要なら「どう思われたいか」を短く入力する。
3. 評価カードを相手側へスワイプして返す。
4. 自分で決められる行動基準を1つ選ぶ。
5. 「評価は相手。行動は自分。」で終了する。

入力した自由文は保存しない。

### 2. 30秒反射トレーニング
日常の具体例を「自分が決める / 相手が決める」に左右スワイプまたはボタンで8問仕分ける。

例:
- 自分が次回、準備を増やすか → 自分
- 上司が「できる人」と評価するか → 相手
- 自分が投稿するか → 自分
- 何件いいねが付くか → 相手

## Training target

「人の評価を気にしない」ではなく、次の順番を反射化する。

1. 承認を取りにいっていることに気づく。
2. 評価・反応は相手の領域だと分ける。
3. 自分の価値基準・行動を残す。
4. 相手の反応を待たず行動へ戻る。

## Non-goals

- 他人の意見を無視させない。
- フィードバックを拒絶させない。
- 承認欲求が悪いものだと断定しない。
- 心理状態を診断しない。

## Privacy

- 自由入力は永続保存しない。
- localStorageにはトレーニング回数・最高精度・最速平均だけ保存する。
- 共通LEVEL UP計測には個別の自由文を送らない。

## Completion condition

初見ユーザーが説明を読まなくても、10秒以内に「他人の評価を相手側へ返し、自分の行動を選ぶアプリ」だと理解できること。
