# NEGOTIATOR｜動かす — Product Spec

## Exact use moment
やるべき仕事・勉強・家事・運動があるのに、「忙しい」「やる気がない」「今じゃない」と考えて着手できない人が、スマホで開く。ユーザーはアプリの要求を何度断ってもよく、断るほど要求が小さく再交渉され、最後に現実の1動作または10秒だけ着手できる状態になる。

## Central benefit
やる気を作ろうとせず、抵抗をそのまま交渉材料にして「今できる最小の一歩」まで条件を下げ、現実の着手を起こす。

## Start state / end state
- Start: 「やらなきゃ」と分かっているが、30分・5分と考えるだけで重く、まだ何も触っていない。
- End: 対象を開く・道具を持つ・立つなどの1動作を行い、さらに10秒だけ実際に着手した記録が残る。

## Core loop
1. ユーザーが「仕事 / 勉強 / 家事 / 運動」から動かしたい対象を選ぶ。
2. NEGOTIATORが最初は大きめの要求（30分）を提示する。
3. ユーザーは「忙しい」「やる気がない」などの抵抗2択、または受諾1択から選ぶ。
4. 抵抗を選ぶたびに、NEGOTIATORは理由を否定せず要求を 30分 → 5分 → 60秒 → 10秒 → 1動作へ縮小・再定義する。
5. 途中で小さなYESが出たら、そのYESを使って次の具体動作へ進む。
6. 最後は画面内の回答だけで完結させず、現実で10秒だけ行動して「やった」を押す。
7. 結果画面で「最初の要求 → 成立した要求」「断った回数」「実際に動いた回数」を見せる。

## Main mechanic
**断るほど要求額が下がる交渉テーブル。**

一般的な3択診断と違い、拒否は不正解ではない。拒否すると中央の「要求」表示が物理的に縮み、NEGOTIATORの提案内容もその抵抗理由に合わせて変わる。ユーザーは交渉で勝っている感覚のまま、結果的に着手しやすいサイズまで行動を小さくする。

会話設計では以下の型を、効果を保証する表現を避けたうえでゲーム構造として使う。
- 大きな要求から小さな要求へ下げる再交渉（door-in-the-face型）
- 小さなYESの後に次の小さなYESを提示する（foot-in-the-door型）
- 「やらなくてもよい」と選択権を明示して抵抗を下げる
- 抽象的な「頑張る」を、対象を開く・道具を持つ等の具体動作へ変える
- 2つの小さな行動候補＋拒否を提示し、ユーザー自身に入口を選ばせる

## First 10 seconds
最初の画面で以下だけを伝える。
- `NEGOTIATOR / 動かす`
- `やる気はいりません。断ってください。こちらが条件を下げます。`
- `交渉を始める`

開始後すぐに対象選択へ進み、長い心理学解説やチュートリアルは出さない。

## Content coverage
4カテゴリで現実の最初の動作を変える。
- 仕事: ファイルを開く / 机に座る / 10秒だけ1行触る
- 勉強: 教材を開く / ペンを持つ / 10秒だけ1問を見る
- 家事: 対象に触る / 1個だけ片づける / 10秒だけ続ける
- 運動: 立つ / 靴やウェアに触る / 10秒だけ身体を動かす

抵抗理由も最低限分岐させる。
- 時間がない
- やる気がない
- しんどい / 面倒
- ちゃんとやれないなら始めたくない

## Feedback
- 拒否時: 「了解。30分は撤回。」のように拒否を受理してから要求を縮小する。
- 受諾時: 大げさに褒めず、「成立。では次の条件。」と短く返す。
- 要求表示: 30 MIN → 5 MIN → 60 SEC → 10 SEC → 1 MOVE と視覚的に縮小。
- 端末対応時は短い振動を使うが、必須にしない。

## Growth / ending / return
localStorageに以下のみ保存する。
- 交渉成立回数
- 実際に10秒動いた回数
- 前回選んだカテゴリ

終了時に「抵抗3回 / YES 1回 / それでも10秒動いた」のように今回の変化を可視化する。
結果はWeb Share API、非対応時はクリップボードで共有できる。
再訪時は累計成立回数を表示し、同じ対象でももう一度交渉できる。

## Agency / safety guardrails
- 「今日は交渉終了」を常時選べる。拒否や終了を責めない。
- 医療・精神状態の診断や、行動科学の効果保証はしない。
- ユーザーを欺く事実主張をしない。テクニックはゲーム内の会話構造としてのみ使用する。
- 危険・違法行為を促す用途には使わず、対象カテゴリを日常の安全な行動に限定する。

## Title rationale
- Series brand: `NEGOTIATOR`
- App title: `動かす`
- Benefit: 着手できない自分を、会話で最初の一歩まで動かす。
- Directness: シリーズ名＋目的語だけで、何をするアプリか短く伝える。
- Match with product: アプリが一方的に励ますのではなく、ユーザーの拒否と条件交渉を繰り返すため `NEGOTIATOR` が実体験と一致する。

## Uniqueness vs other LEVEL UP apps
`3秒で動け` が瞬間判断の反射を鍛えるゲーム、`あと5分` がタスク分解のトレーニングなのに対し、本作は**「ユーザーの抵抗そのものを受け取り、会話で要求条件を下げ続ける交渉体験」**がコアループであり、別アプリで代替できない。

## Anti-patterns to avoid
- 同じ3択文を言い換えるだけの一本道
- 「素晴らしい選択です」など汎用AI励まし
- 長い心理学用語の解説
- 拒否を不正解扱いする
- 画面内で「やる」を押して終わり、現実行動を要求しない
- 強制的に次へ進み、交渉終了手段を隠す
