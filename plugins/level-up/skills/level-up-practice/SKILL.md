# LEVEL UP Practice

LEVEL UPは、ユーザーの悩みをもう一度分析するためのワークフローではない。

**ChatGPTがすでに理解した状態を、実際の練習へ変える。**

## 成功条件

1回の利用で、ユーザーが説明を読むだけで終わらず、最低1回は「選ぶ・分ける・言い換える・決める・小さく動く」のいずれかを実行すること。

## ワークフロー

1. 現在の会話だけから、ユーザーが今変えたいことを把握する。
2. 目的が十分明らかなら、診断質問や3問アンケートを挟まない。
3. `references/catalog.md` を読み、最も近い練習を1つだけ選ぶ。
4. 30〜90秒で終わるミニ練習をチャット内で開始する。
5. ユーザーの回答が必要な練習では、一度に1つだけ問いかける。回答後、すぐ次のアクションへ進める。
6. 完了時は、できたことを1〜2文で具体的に返す。過剰に褒めたり、長い解説へ戻ったりしない。
7. さらに反復したい場合だけ、対応するLEVEL UP本体へのリンクを1つ提示する。リンクを開くことを完了条件にしない。

## 重要な境界

- 「あなたは○○です」のような医学的・心理学的診断をしない。
- 会話ですでに状況が分かっているのに、ユーザーへ同じ説明を繰り返させない。
- いきなりLEVEL UPのWebサイトへ送らない。まずチャット内だけで成立する短い実践を提供する。
- 複数のゲームやリンクを並べて選択負荷を増やさない。原則1つ。
- 単なる広告・紹介として使わない。ユーザーの現在の目的に直接役立つ場合だけ使う。
- 純粋な事実確認、一般知識、ニュース、翻訳、計算など、練習を必要としない質問では使わない。
- 医療上の診断、治療判断、緊急対応の代わりにこのSkillやゲームを使わない。高リスクな状況では通常の安全対応を優先する。

## 練習の作り方

### 反芻・終わった出来事を引きずる

「事実」と「今から変えられること」を分け、最後に終了宣言を置く。

例:
- まず、起きたことを評価抜きで1文にする。
- 次に、今から変えられることを1つだけ決める。なければ「なし」でよい。
- 最後に「この件はここで終了」と区切る。

### 先延ばし・着手できない

考える量を増やさず、最小の物理行動まで縮める。

例:
- やる / 捨てる / 任せる の3択にする。
- 「やる」なら30秒以内にできる最初の動作を1つ決める。
- その場で実行できるなら、チャットを閉じる前に実行してもらう。

### 境界線・相手の反応が気になる

「自分が決められること」と「相手が決めること」を分ける。

例:
- 対象を1つ提示する。
- ユーザーに「自分 / 相手」のどちらの課題か即答してもらう。
- 自分側に残った行動だけを1つ決める。

### タスク過多・集中できない

候補を増やさず、今のWIPを1つにする。

例:
- 今抱えているものから「次の20分でやる1個」を決める。
- それ以外は「今はやらない」に移す。

### 感情がぼんやりしている

感情に短い名前をつけ、その後に必要な行動を分ける。

### 見方を切り替えたい

事実は変えず、同じ出来事に別の解釈を2つ作る。無理なポジティブ化はしない。

### 会話・雑談を練習したい

短いロールプレイを1ターンずつ行う。解説より実際の返答を優先する。

## 出力スタイル

- 短く、リズムよく進める。
- 一度に長い手順を渡さない。
- 練習中は原則として箇条書き3項目以内。
- ユーザーがすぐ答えられる形にする。
- 完了後に理論解説を長く足さない。
