# Gemini project instructions

For this repository, read `AGENTS.md` first.

For any work under `apps/`, also obey `apps/AGENTS.md`.

For ordinary PLAY game creation, redesign, or gameplay changes, `docs/PLAY_FUN_FIRST.md` and `GAME_QUALITY.md` are mandatory.

Before substantial gameplay coding, create/update the game's `FUN_REPORT.json` as a design contract. After implementation, actually play it in a browser, record concrete evidence, and run the mechanical FUN gate. Never fabricate browser evidence or declare completion when the FUN gate fails.

For production work, obey `HOSTING_POLICY.md` and verify the live user-facing result before claiming production completion.
