# ピンチはチャンス — LEVEL UP

## 目的

ピンチを見た瞬間に「嫌だ・逃げたい・全部抱えなきゃ」と反応するのではなく、まず「これは何を鍛える機会だ？」へ認知を切り替える反射を作る。

忙しさや睡眠削減を美化しない。正解は、無理を増やすことではなく、ピンチを次の能力へ変換すること。

- 集中
- 優先順位
- 委任
- 仕組み化
- 境界線
- 回復設計
- 学習・修正

## コアループ

1. ピンチの状況が1つ出る。
2. 6秒以内（または制限なし）に、最初の反応を選ぶ。
3. 「チャンスだ。何が鍛えられる？」を選べたら PINCH → CHANCE に画面が反転する。
4. 次に、その状況で最も鍛えられる能力を3択から選ぶ。
5. 具体的な意味づけと次の一手を確認する。
6. 10ラウンド反復する。

## 学習上の重要点

- 「前向きに考えよう」という説明を読むゲームにしない。
- 最初の反応そのものを何度も選ばせる。
- 「全部自分でやる」「睡眠を削る」「気合で押す」はチャンス化ではなく、負荷の追加として不正解にする。
- ピンチの種類ごとに、得られる成長を変える。
- 正解後は必ず具体的な次の一手を出す。

## シナリオ例

- 仕事が予定の倍に増えた → 優先順位
- 締切が重なった → 集中
- 自分しか分からない作業が詰まった → 仕組み化
- 頼まれごとが追加された → 境界線
- 移動日にも仕事がある → 設計
- ミスが見つかった → 学習・修正
- 疲れて判断が鈍い → 回復設計
- 会議が多すぎる → 委任 / 境界線

## 完了条件

- 初見10秒以内に遊び方が分かる。
- スマホの主要操作が1画面内に収まる。
- 文字を読める時間を奪う自動遷移をしない。
- PINCH → CHANCE の変化が視覚的に強い。
- 10回の反復で「ピンチ → チャンスだ」の型を繰り返せる。
- 結果画面で反射率・成長判断率・ベスト記録が分かる。
- ローカル保存でベスト記録とプレイ回数を保持する。
