# スッキリノート — 仕様メモ

## 目的
「やることが多すぎて困っている」状態から、頭の中の未完了を外部化し、同時に抱えず一つずつ消化して、実際に未完了数を減らす。

## 身につける反射
1. 多いと感じたら、まず全部を頭の外へ出す。
2. 優先順位を完璧に決める前に、次の一つを選ぶ。
3. 大きすぎるなら、最初の5分まで小さくする。
4. 一つが閉じるまでWIPを増やさない。
5. 「完了」だけでなく「任せる」「やらない」も片づけとして扱う。

## コアループ
頭の中を入力 → ノート化 → 一つ選択 → 必要なら小さくする → 開始 → 完了/委任/やらない → 残数が1つ減る → 次の一つ。

## 1回の最小成功体験
ノートに3件以上出し、そのうち1件を閉じて「残り件数」が減ること。

## UX原則
- 最初の画面に入力欄を置き、説明画面を挟まない。
- 10秒以内に「出す→一つ選ぶ→消す」が理解できる。
- フォーカス画面では他タスクの本文を隠し、WIP=1を視覚化する。
- 完了画面は自動で消さず、ユーザーが読んで次へ進む。
- スマホでは主要操作を1画面に収め、文字を小さくしすぎない。
- 入力内容はlocalStorageに保存し、通信なしでも利用できる。

## データ
localStorage: `levelup:sukkiri-note:v1`
各タスク: text, firstStep, status(open/done/delegated/dropped), createdAt, startedAt, accumulatedMs, closedAt, closedDay。

## 完了条件
- 入力した複数行がタスクになる。
- 再読み込みしても残る。
- 任意の一つだけをフォーカス表示できる。
- 開始/停止の経過時間が記録される。
- 最初の一歩を保存できる。
- 完了・委任・やらないで残数が必ず1減る。
- 最後の1件を閉じると空のノート画面になる。
- iPhone幅で横スクロールせず主要操作ができる。
