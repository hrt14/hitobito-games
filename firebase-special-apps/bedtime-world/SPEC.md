# 寝る前が楽しみになるイメトレ — Product Spec

## Exact use moment
夜、まだスマホや仕事を続けられるが、本当は早く布団に入りたい人が開く。睡眠を義務として終わらせるのではなく、「昨日の頭の中の世界の続きを見たいから、そろそろ布団へ行こう」と思える状態に変える。

## Central benefit
布団に入ること自体を、毎晩の楽しみに変える。

## Problem / design rationale
「早く寝なければ」は将来の利益のための制御であり、その場のスマホ・作業などの即時報酬に負けやすい。本アプリは睡眠を治療・保証するのではなく、就寝直前にだけ開く“続きものの想像世界”を作り、布団へ移動する理由を未来の義務から今夜の楽しみへ置き換える。

既存の `bedtime-best-case` はその日の成功イメージを3カットに整理する。新アプリは成功場面を作らず、同じ架空世界を夜ごとに少しずつ進める。中心は「何を想像するかの整理」ではなく「続きを見たいという再訪欲」を就寝行動へ結びつけること。

## Core interaction
1. 初回のみ、4つの世界から「毎晩通う世界」を1つ選ぶ。
2. ホームでは今夜新しく開く場所だけを見せ、先の場所は伏せる。
3. 「布団に入った。入口を開く」で今夜の場所へ入る。
4. 3つの入口から1つを選ぶ。
5. 視覚・音・触感・匂い・細部・動きから、頭の中へ持っていく手がかりを3つだけ選ぶ。
6. 最終画面で入口と3つの手がかりを短く提示し、「画面を伏せる」でアプリを終える。
7. 1日1回だけ世界が1つ先へ進み、翌晩の新しい場所が見える。

操作は「読む→次へ」ではなく、毎晩の入口を自分で選び、想像素材を3つ集める。選んだ素材はスロットに入り、今夜の脳内体験そのものを構成する。

## First 10 seconds
初回は「今夜から、寝る前に続きがある。」と4つの世界だけを表示。再訪時は「今夜も、続きがある。」と今夜開く場所、「布団に入った。入口を開く」を最も大きく表示する。説明を読まなくても、布団に入ったら今夜の続きを開くアプリだと分かる。

## Success condition
ユーザーが今夜の入口と3つの感覚手がかりを選び、「画面を伏せる」まで到達する。翌晩には前夜と連続した世界の次の場所が表示され、もう一度開く意味が残る。

## Uniqueness
- `bedtime-best-case`: 成功イメージを3カットに編集する。毎晩続く架空世界は持たない。
- `azukete-neru`: 考え事を明日に預け、反芻を止める。楽しみを作るアプリではない。
- 本アプリだけが「架空世界の未完了の続き」を就寝の即時報酬として使い、布団へ向かう動機そのものを作る。

## Repeat-use strategy
同じ世界を夜ごとにひとつずつ進める。次の場所は完全には見せず、今夜の完了後に名前だけ予告する。毎回入口の選択と感覚素材が変わるため、同じ場所でも脳内の展開はユーザーごとに変わる。ポイントやログインボーナスではなく、「世界の続き」が再訪理由になる。

## Title rationale
- Main user benefit/motive: 楽しむ／心地よくなる／早く布団に入りたくなる。
- Why this title is direct and specific: 「寝る前が楽しみになる」で欲しい変化を直接言い、「イメトレ」で実際の行為を示す。
- How it matches the actual app: 毎晩、同じ想像世界の続きを作り、目を閉じてから再生するための入口を作る。
- Market/uniqueness checks actually performed (if any): 2026-09-01にWebで「寝る前が楽しみになるイメトレ」「寝る前の続き イメトレ」を検索。同一タイトルの明確なアプリ・商品は確認できなかった。一方「寝る前が楽しみになる」という一般表現は他商品の訴求文でも使われているため、独占性は主張しない。Amazon.co.jpドメイン対象の完全一致検索でも同一タイトルの明確な商品は確認できなかったが、法的な商標・著作権クリアランスを意味しない。
